## 1. 项目简介

ComfyUI 是目前世界上最优化、最模块化的扩散模型推理引擎之一,核心特性包括:

- **可视化节点图**:通过拖拽节点构建工作流,支持图像、视频、音频、3D、文本生成。
- **极致本地优化**:支持异步队列、部分图重执行、智能 VRAM/RAM 管理、模型卸载与量化模型,最低可在 4GB VRAM + 8GB RAM 上运行大型开源模型。
- **广泛的原生模型支持**:涵盖 Stable Diffusion 1.5/SDXL/SD3.5、Flux.1/Flux.2、Qwen Image、Wan 2.1/2.2、HunyuanVideo、LTX-Video、CogVideoX 等主流模型。
- **离线运行**:核心默认不做任何联网请求。使用 `--offline` 可彻底关闭前端联网与付费 API 节点。
- **跨平台**:Windows、Linux、macOS 均可运行,支持 NVIDIA、AMD、Intel、Apple Silicon、华为昇腾 (Ascend)、寒武纪 (Cambricon)、天数 (Iluvatar) 等多种加速设备。
- **可扩展**:通过自定义节点 (Custom Nodes) 扩展功能。

## 2. 系统要求

### Python 版本

| Python 版本 | 支持情况 |
|-------------|---------|
| 3.13 | 推荐版本,支持最好 |
| 3.12 | 兼容,部分自定义节点依赖更友好 |
| 3.14 | 可用,但部分自定义节点可能存在问题;free-threaded 变体并非完全支持 |

### PyTorch 版本

- 最低支持 torch 2.7,**强烈建议使用更新版本**。
- NVIDIA 20 系及以上显卡必须使用 cu130 或更新版本的 PyTorch。
- 一般建议使用最新主版本 PyTorch + 最新 CUDA 版本(发布不足两周的除外)。
- 超过 6 个月的 PyTorch 请及时更新。

### 硬件

- **最低**:4GB VRAM + 8GB RAM(借助异步权重流式传输技术可运行大型模型)。
- **推荐**:8GB+ VRAM,16GB+ RAM,SSD/NVMe 磁盘。
- 支持的加速设备:NVIDIA、AMD (ROCm)、Intel Arc (XPU)、Apple Silicon (MPS)、华为昇腾 NPU、寒武纪 MLU、天数 Corex。

## 4. 启动运行

最简启动:

```bash
python main.py
```

启动后浏览器访问 <http://127.0.0.1:8188> 即可使用 ComfyUI 界面。

### AMD 显卡兼容性

若 ROCm 未正式支持你的 AMD 显卡,可尝试设置环境变量:

```bash
# RDNA2 及更早(如 6700、6600)
HSA_OVERRIDE_GFX_VERSION=10.3.0 python main.py

# RDNA3(如 7600)
HSA_OVERRIDE_GFX_VERSION=11.0.0 python main.py
```

### AMD ROCm 性能调优

启用 TunableOp 可能在首次运行较慢的情况下提升后续性能:

```bash
PYTORCH_TUNABLEOP_ENABLED=1 python main.py
```

### 4.1 一键启动脚本(start.sh)

仓库根目录提供了 `start.sh` 脚本,封装了环境检测、依赖修复、设备选择和启动流程,适合在本机一键启动 ComfyUI。

#### 基本用法

```bash
# 默认启动(自动检测 GPU,开启预览,自动打开浏览器)
./start.sh
```

启动后浏览器访问 <http://127.0.0.1:8188> 即可使用 ComfyUI 界面。

#### 透传参数

脚本将 `--` 之后的所有参数原样传递给 `main.py`,因此可以直接追加 ComfyUI 命令行参数:

```bash
# 局域网访问 + 自定义端口
./start.sh --listen 0.0.0.0 --port 9000

# 强制 CPU 模式
./start.sh --cpu

# 离线模式
./start.sh --offline

# 指定 VAE 精度
./start.sh --fp16-vae

# 组合多个参数
./start.sh --listen 0.0.0.0 --port 9000 --fp16-vae --preview-method taesd
```

完整可用参数见[第 5 节](#5-命令行参数详解)。

#### 环境变量

脚本支持以下环境变量进行配置(优先级高于默认值):

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `COMFYUI_PORT` | `8188` | 监听端口 |
| `COMFYUI_HOST` | `127.0.0.1` | 监听地址(设为 `0.0.0.0` 可局域网访问) |
| `COMFYUI_PYTHON` | 自动检测 | 指定 Python 可执行文件路径 |
| `COMFYUI_NO_DEPS` | (未设置) | 设为 `1` 跳过依赖检查 |
| `COMFYUI_NO_BROWSER` | (未设置) | 设为 `1` 不自动打开浏览器 |
| `COMFYUI_OFFLINE` | (未设置) | 设为 `1` 离线启动(等同 `--offline`) |

示例:

```bash
# 指定端口和监听地址
COMFYUI_HOST=0.0.0.0 COMFYUI_PORT=9000 ./start.sh

# 跳过依赖检查(适合已确认依赖完整时加速启动)
COMFYUI_NO_DEPS=1 ./start.sh

# 不自动打开浏览器
COMFYUI_NO_BROWSER=1 ./start.sh

# 同时设置多个环境变量
COMFYUI_PORT=9000 COMFYUI_NO_BROWSER=1 COMFYUI_OFFLINE=1 ./start.sh
```

#### 仅修复依赖

使用 `--setup` 参数可以只执行依赖检查与修复,不启动 ComfyUI:

```bash
./start.sh --setup
```

适合在首次安装后或更新仓库后用来修复依赖环境。

#### 脚本功能说明

脚本按以下流程执行:

1. **选择 Python** — 按优先级检测:venv → conda → 系统 `python3`/`python`,也支持通过 `COMFYUI_PYTHON` 手动指定。
2. **版本检查** — Python 低于 3.10 报错退出;低于 3.12 给出建议(部分依赖如 `comfyui-workflow-templates` 需要 3.11+)。
3. **依赖检查与修复**:
   - 检查 PyTorch 是否安装,未安装则提示安装命令。
   - 检查 torch 版本,低于 2.4(comfy-kitchen 需要 `torch.library.custom_op`)自动升级。
   - 检查全部核心依赖(comfy-kitchen、comfy-aimdo、SQLAlchemy、pydantic-settings 等),缺失则自动安装。
   - Python 3.10 下 `comfyui-workflow-templates` 的某些子依赖要求 3.11+,安装失败时自动用 `--no-deps` 分步安装绕过。
   - 检查 `pydantic-settings`、`comfy_kitchen`、`SQLAlchemy` 的导入兼容性,版本过旧自动升级。
4. **GPU / 设备检测** — 按 CUDA → ROCm → MPS → XPU → CPU 顺序检测;CUDA 检测到但初始化失败(常见于沙箱/容器环境)时回退 CPU 并提示。
5. **模型文件检查** — 扫描 `models/checkpoints`、`models/diffusion_models`、`models/unet`,提示放入模型文件。
6. **端口检查** — 端口被占用时自动递增到下一个可用端口。
7. **构建启动参数** — 根据设备类型、预览模式、浏览器、离线模式、监听地址等组装参数,与用户透传参数合并。
8. **启动** — `exec` 调用 `main.py`,打印访问地址、设备信息、Python/PyTorch 版本和最终参数。

#### 沙箱 / 容器环境注意事项

在沙箱或容器环境中,CUDA 初始化可能报错 304(`OS call failed or operation not supported on this OS`),表现为 `nvidia-smi` 不可用、`torch.cuda.is_available()` 返回 `True` 但实际初始化失败。此时脚本会回退到 CPU 模式并提示。

要使用 GPU,请在非沙箱终端中运行,或使用:

```bash
sudo bash start.sh
```

#### 默认启动参数

脚本默认附加以下参数(除用户透传参数外):

| 参数 | 说明 |
|------|------|
| `--preview-method auto` | 自动预览,低成本查看生成进度 |
| `--auto-launch` | 启动时自动打开浏览器(可通过 `COMFYUI_NO_BROWSER=1` 关闭) |
| `--port $PORT` | 监听端口(默认 8188,或 `COMFYUI_PORT` 指定的值) |
| `--cpu` | 仅在未检测到可用 GPU 时附加 |
| `--listen $HOST` | 仅在 `COMFYUI_HOST` 不为 `127.0.0.1` 时附加 |
| `--offline` | 仅在 `COMFYUI_OFFLINE=1` 时附加 |

## 5. 命令行参数详解

所有参数定义在 `comfy/cli_args.py` 中。以下按功能分组说明。

### 5.1 服务器与网络

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--listen [IP]` | `127.0.0.1` | 监听 IP。不带参数时监听所有地址 `0.0.0.0,::`;可逗号分隔多个 IP |
| `--port` | `8188` | 监听端口 |
| `--tls-keyfile` | - | TLS 私钥文件路径,启用 HTTPS,需配合 `--tls-certfile` |
| `--tls-certfile` | - | TLS 证书文件路径,启用 HTTPS,需配合 `--tls-keyfile` |
| `--enable-cors-header [ORIGIN]` | - | 启用 CORS,不带参数时允许所有源 `*` |
| `--max-upload-size` | `100` | 最大上传体积(MB) |
| `--enable-compress-response-body` | - | 启用响应体压缩 |
| `--auto-launch` | - | 启动时自动打开浏览器 |
| `--disable-auto-launch` | - | 禁止自动打开浏览器 |
| `--dont-print-server` | - | 不打印服务器输出 |
| `--log-stdout` | - | 将正常输出发送到 stdout 而非 stderr |
| `--verbose [LEVEL FILE]` | - | 设置日志级别,可重复指定以输出到文件 |

### 5.2 目录配置

| 参数 | 说明 |
|------|------|
| `--base-directory PATH` | 设置 ComfyUI 基础目录(模型、custom_nodes、input、output、temp、user) |
| `--output-directory PATH` | 输出目录,覆盖 `--base-directory` |
| `--temp-directory PATH` | 临时目录,覆盖 `--base-directory` |
| `--input-directory PATH` | 输入目录,覆盖 `--base-directory` |
| `--user-directory PATH` | 用户目录(绝对路径),覆盖 `--base-directory` |
| `--models-directory PATH` | 模型目录,覆盖 `--base-directory` 下的 models |
| `--extra-model-paths-config PATH [PATH ...]` | 加载一个或多个 `extra_model_paths.yaml` |

### 5.3 设备选择

| 参数 | 说明 |
|------|------|
| `--cuda-device DEVICE_ID` | 指定 CUDA 设备 ID,逗号分隔(如 `0` 或 `0,1`),或 `all` 保留全部可见设备 |
| `--default-device ID` | 设置默认设备 ID,其余设备仍可见 |
| `--directml [DEVICE]` | 使用 torch-directml,不带参数时使用默认设备 |
| `--oneapi-device-selector STRING` | 通过 oneAPI 选择 Intel 设备 |

### 5.4 数据类型与精度

| 参数 | 说明 |
|------|------|
| `--force-fp32` | 强制全部使用 fp32 |
| `--force-fp16` | 强制全部使用 fp16(等同于 `--fp16-unet`) |
| `--fp32-unet` / `--fp64-unet` / `--bf16-unet` / `--fp16-unet` | 扩散模型精度 |
| `--fp8_e4m3fn-unet` / `--fp8_e5m2-unet` / `--fp8_e8m0fnu-unet` | 扩散模型权重存储为 fp8 格式 |
| `--fp16-vae` / `--fp32-vae` / `--bf16-vae` | VAE 精度(`--fp16-vae` 可能导致黑图) |
| `--cpu-vae` | VAE 在 CPU 上运行 |
| `--fp8_e4m3fn-text-enc` / `--fp8_e5m2-text-enc` / `--fp16-text-enc` / `--fp32-text-enc` / `--bf16-text-enc` | 文本编码器精度 |
| `--fp16-intermediates` | 实验性:节点间中间张量使用 fp16 而非 fp32 |
| `--force-channels-last` | 强制 channels last 内存格式 |
| `--supports-fp8-compute` | 让 ComfyUI 视设备支持 fp8 计算 |

### 5.5 CUDA 与显存管理

| 参数 | 说明 |
|------|------|
| `--cuda-malloc` / `--disable-cuda-malloc` | 启用/禁用 cudaMallocAsync(torch 2.0+ 默认启用) |
| `--reserve-vram GB` | 为系统/其他软件预留的 VRAM(GB) |
| `--vram-headroom GB` | DynamicVRAM 维持的额外空闲 VRAM(GB) |
| `--disable-nvml-pressure` | 使用 CUDA 而非 NVML 检测显存压力 |
| `--async-offload [NUM_STREAMS]` | 异步权重卸载,默认 2 流(NVIDIA 默认启用) |
| `--disable-async-offload` | 禁用异步权重卸载 |
| `--disable-dynamic-vram` / `--enable-dynamic-vram` | 禁用/启用 DynamicVRAM |
| `--fast-disk` | 强制使用磁盘后备的动态加载(适合快速 NVMe) |
| `--disable-fast-disk` | 禁用磁盘后备动态加载 |
| `--disable-cuda-graphs` | 禁用 CUDA Graphs |
| `--disable-comfy-compiler` | 禁用 Comfy 模型编译器(含 CUDA Graph 子功能) |
| `--assert-graph-breaks` | 模型编译器图断时直接报错 |
| `--force-non-blocking` | 强制所有适用张量使用非阻塞操作 |
| `--disable-pinned-memory` | 禁用 pinned memory |
| `--disable-smart-memory` | 激进卸载到 RAM,而非尽量保留在 VRAM |

### 5.6 显存模式(互斥)

| 参数 | 说明 |
|------|------|
| `--gpu-only` | 所有内容(文本编码器/CLIP 等)都在 GPU 上存储与运行 |
| `--highvram` | 模型使用后保留在 GPU 内存 |

## 7. 额外模型路径配置

如果你已有其他 UI(Automatic1111 等)或独立的模型存储目录,可通过 `extra_model_paths.yaml` 共享模型,避免重复下载。

### 使用方法

1. 复制 `extra_model_paths.yaml.example` 为 `extra_model_paths.yaml`。
2. 编辑文件,取消注释并修改 `base_path` 为你的路径。
3. 启动 ComfyUI 时通过 `--extra-model-paths-config` 加载(默认会自动加载同目录下的 `extra_model_paths.yaml`)。

### 示例配置

```yaml
# 与另一套 ComfyUI 安装共享模型
comfyui:
    base_path: /path/to/another/comfyui/
    # is_default: true   # 设为默认目录(列表优先、下载默认位置)
    checkpoints: models/checkpoints/
    vae: models/vae/
    loras: models/loras/
    text_encoders: |
        models/text_encoders/
        models/clip/
    diffusion_models: |
        models/unet/
        models/diffusion_models/
    controlnet: |
        models/controlnet/
        models/t2i_adapter/
    # ... 其余目录同上

# 与 Automatic1111 WebUI 共享模型
a1111:
    base_path: /path/to/stable-diffusion-webui/
    checkpoints: models/Stable-diffusion
    vae: models/VAE
    loras: |
        models/Lora
        models/LyCORIS
    upscale_models: |
        models/ESRGAN
        models/RealESRGAN
        models/SwinIR
    embeddings: embeddings
    hypernetworks: models/hypernetworks
    controlnet: models/ControlNet
```

## 9. 使用技巧

### 9.1 高质量预览

默认安装包含一个快速但低分辨率的潜空间预览。如需更高质量预览(TAESD):

1. 从 [TAESD](https://github.com/madebyollin/taesd/) 下载 `taesd_decoder.pth`、`taesdxl_decoder.pth`、`taesd3_decoder.pth`、`taef1_decoder.pth`。
2. 放入 `models/vae_approx/` 目录。
3. 重启 ComfyUI 并使用 `--preview-method taesd` 启动。

也可用 `--preview-method auto` 自动选择预览方式。

### 9.2 从生成图恢复工作流

将生成的 PNG 图片拖到网页上,或通过加载图片功能,可恢复完整的工作流(包括种子)。ComfyUI 会将 prompt 元数据写入支持的生成媒体。

### 9.3 提示词语法

- **权重调整**:用 `()` 调整词或短语的权重,如 `(good code:1.2)` 或 `(bad code:0.8)`,默认权重 1.1。需要在提示词中使用字面的 `()` 请转义为 `\(` 或 `\)`。
- **动态 / 通配提示词**:`{day|night}` 会在每次入队时随机替换为其中一个。需要字面 `{}` 请转义为 `\{` 或 `\}`。
- 动态提示词还支持 C 风格注释:`// 注释` 或 `/* 注释 */`。

### 9.4 Textual Inversion / Embeddings

将 concepts/embeddings 文件放入 `models/embeddings/` 目录,在 CLIPTextEncode 节点中按以下格式使用(可省略 `.pt` 扩展名):

```
embedding:embedding_filename.pt
```

### 9.5 启用 TLS/SSL

生成自签名证书(仅供本地/测试,不适合生产):

```bash
openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -sha256 -days 3650 -nodes \
  -subj "/C=XX/ST=StateName/L=CityName/O=CompanyName/OU=CompanySectionName/CN=CommonNameOrHostname"
```

启动时指定:

```bash
python main.py --tls-keyfile key.pem --tls-certfile cert.pem
```

应用将改为通过 `https://...` 访问。

> Windows 用户可使用 [docker-openssl](https://github.com/alexisrolland/docker-openssl) 或 [第三方二进制](https://wiki.openssl.org/index.php/Binaries) 执行上述命令。

### 9.6 部分图执行

- 只有所有输入都已就绪的输出部分才会被执行。
- 图中只有发生变化的部分及其依赖项才会在下次执行时重新运行;连续提交同一张图只会执行第一次。
- 修改图的末尾部分时,只会执行你修改的部分及依赖它的部分。

### 9.7 离线运行

```bash
# 完全离线:阻止前端联网,禁用付费 API 节点
python main.py --offline

# 仅禁用付费 API 节点,前端保留联网
python main.py --disable-partner-nodes
```

## 11. 量化模型

ComfyUI 原生支持量化模型,可在更低显存下运行更大模型。详见仓库中的 `QUANTIZATION.md`。

### 核心概念

- **QuantizedTensor**:torch.Tensor 子类,在 `comfy/quant_ops.py` 中定义,用于表示带缩放因子的低精度张量。
- **Layout**:定义量化格式的行为(所需参数、量化方法、反量化方法)。
- **两层注册系统**:通用注册处理跨格式通用操作(`.to()`、`.clone()`、`.reshape()` 等);布局特定注册实现快速路径(如 `nn.Linear`)。
- **MixedPrecisionOps**:支持按层量化决策,敏感层保持高精度,计算密集层使用低精度。

### 检查点格式

量化检查点以标准 safetensors 文件存储,包含:
- 量化后的权重张量(可能使用不同的存储 dtype,如用 uint8 容器存 fp8)。
- 每个量化权重对应的缩放参数(`weight_scale`、`weight_scale_2`、`pre_quant_scale`、`input_scale`)。
- 元数据中的 `_quantization_metadata` JSON,描述各层的量化格式。

支持的缩放参数:

| 格式 | 存储 dtype | weight_scale | weight_scale_2 | pre_quant_scale | input_scale |
|------|-----------|--------------|----------------|-----------------|-------------|
| float8_e4m3fn | float32 | float32(标量) | - | - | float32(标量) |

完整格式定义见 `comfy/quant_ops.py` 中的 `QUANT_ALGOS`。

### 创建量化检查点

只要输出遵循上述格式并使用 `QUANT_ALGOS` 中定义的 layout,即可用任意量化工具创建兼容检查点。

### 扩散注意力偏好

可在注意力模块路径下添加 `.comfy_attention.config` 条目(uint8 张量,内容为 UTF-8 JSON),指定注意力实现:

```json
{"attention": "comfy_kitchen_int8"}
```

或有序偏好列表:

```json
[
  {"attention": "comfy_kitchen_sol", "tau": 1.0},
  {"attention": "comfy_kitchen_int8"}
]
```

仅接受 `comfy_kitchen_int8` 与 `comfy_kitchen_sol`。`comfy_kitchen_sol` 仅支持可选的 `tau` 字段(路由阈值,默认 1.0,值越大精确路由的块越少)。ComfyUI 在加载时选择第一个可用的偏好。

## 13. 安全策略

详见 `SECURITY.md`。要点如下:

### 威胁模型

- ComfyUI 设计为本地运行,默认绑定 `127.0.0.1`,仅本机可访问。
- 假设用户通过官方渠道(桌面应用、便携版、按 README 手动安装)安装。
- 假设用户未安装不可信的自定义节点(自定义节点是任意 Python 代码,等同于用户主动安装的软件)。
- 访问 ComfyUI URL 的人都是受信任的。
- PyTorch 等依赖使用 ComfyUI 推荐的版本。

### 视为漏洞

使用内置节点加载并运行的工作流导致**不可信代码执行、目录外任意文件读写、凭据/数据外泄**等问题,属于漏洞范畴。

### 不视为漏洞

- 需要 `--listen` 或非默认网络暴露才能触发的问题(用户自行负责部署安全)。
- 旧版 PyTorch 的 `torch.load` 反序列化问题(上游问题,请升级 PyTorch)。
- 依赖 ComfyUI 未推荐/未提供的过旧库版本。
- 需要特定自定义节点才能触发的问题(请向该节点维护者报告)。
- 加载工作流导致的崩溃、挂起、资源耗尽(普通 bug,非安全问题)。

### 报告

符合上述范围的问题,请通过 GitHub 的 [Report a vulnerability](https://github.com/comfyanonymous/ComfyUI/security/advisories/new) 私下报告,不要开公开 issue。报告内容应包含:漏洞描述与受影响组件、复现步骤(最好附最小工作流或 PoC)、ComfyUI 版本与安装方式与操作系统、对典型本地用户的影响说明。

### Q: 生成图为黑色?

可尝试 `--fp32-vae`,或 `--force-upcast-attention`。`--fp16-vae` 可能导致黑图,请避免使用。

### Q: 显存不足?

- 默认启用 DynamicVRAM 与异步权重卸载,可在 4GB VRAM 上运行大型模型。
- 进一步节省:`--reserve-vram`、`--vram-headroom`、`--cache-none`、`--novram`、`--cpu-vae`。
- 使用量化模型(见[第 11 节](#11-量化模型))。

### Q: 如何完全离线?

```bash
python main.py --offline
```

### Q: 如何在浏览器自动打开?

```bash
python main.py --auto-launch
```

### Q: 默认端口被占用怎么办?

```bash
python main.py --port 8189
```
