## 0. 你将做出什么

一个 `ComfyUI-PromptLab` 包，包含 4 个可运行节点：

| 节点 ID | 干什么 |
|---|---|
| `PK_DynamicPrompt` | 把 `{a|b|c}` 内联通配符随机展开，再编码成 conditioning |
| `PK_PromptSchedule` | 多行 `提示词 :: 占比`，按去噪进度分时段生效 |
| `PK_RegionPrompt` | 给 conditioning 打"区域"标记（area），实现分区提示词 |
| `PK_ConditioningMerge` | 把多条 conditioning 拼成一个列表（等价于 ConditioningCombine） |

学完你会彻底搞懂：**CONDITIONING 不是张量，而是一个 `[cond_tensor, dict]` 列表**，dict 里装着 `pooled_output`、`start_percent`/`end_percent`、`area`、`mask` 等控制信息。

---

## 1. CONDITIONING 的数据结构（最重要的一节）

很多人卡在 conditioning 上，是因为把它当成单个张量。实际上：

```python
CONDITIONING = [
    [ cond_tensor,  { "pooled_output": pooled_tensor, "start_percent": 0.0, "end_percent": 1.0, ... } ],
    [ cond_tensor2, { "pooled_output": pooled_tensor2, "area": (...), ... } ],
    ...
]
```

- **第 0 项** `c[0]`：文本编码后的条件张量（`[B, seq_len, cond_dim]`）。
- **第 1 项** `c[1]`：一个 dict，关键键：
  - `pooled_output`：CLIP pooled 向量，横向条件（如 SDXL 风格）用。
  - `start_percent` / `end_percent`：该条件在去噪进度的哪一段生效（0~1）。
  - `area`：区域提示词用，格式见第 6 章。
  - `mask` / `mask_strength`：蒙版提示词用。
  - `control`、`model_conds`、`aesthetic_embed` 等：高级用途。

### 1.1 正确做法：让 CLIP 替你构造

你**几乎永远不该手写**这个结构 —— 调 `clip.encode_from_tokens_scheduled(tokens)` 它直接返回符合格式的 CONDITIONING。只有要做"分时段 / 分区 / 蒙版"等变换时，才用 `node_helpers.conditioning_set_values` 在其上增删键。

```python
tokens = clip.tokenize(text)
cond = clip.encode_from_tokens_scheduled(tokens)   # 返回标准的 CONDITIONING 列表
return io.NodeOutput(cond)
```

### 1.2 合并 = 列表相加

`ConditioningCombine.combine` 的整个实现就是 `return (conditioning_1 + conditioning_2, )`。要拼多条，直接 `list_a + list_b`。

**area 键的格式**（来自 `nodes.py` 内置 `ConditioningSetArea`）：
- 绝对像素：`"area": (height // 8, width // 8, y // 8, x // 8)`，单位是 latent（÷8），顺序是 `(h, w, y, x)`。
- 百分比：`"area": ("percentage", height, width, y, x)`，值是 0~1 的比例。

- `"mask": mask_tensor`，`"set_area_to_bounds": bool`，`"mask_strength": float`。

## 4. `PK_DynamicPrompt` —— 内联通配符展开

### 4.1 原理

支持 `{red|blue|green}` 这种内联随机通配符。用正则把每段 `{a|b|c}` 替换成随机选中的一项，再交给 CLIP 编码。比单纯用前端动态提示更可控（你可以加加权、去重、计数等逻辑）。

### 4.2 完整代码

```python
import re
import random
from comfy_api.latest import io


def _expand(text: str, rng: random.Random) -> str:
    """把 {a|b|c} 随机展开成其中一项。可嵌套、可多次。"""
    changed = True
    while changed:
        changed = False
        def repl(m):
            nonlocal changed
            changed = True
            return rng.choice(m.group(1).split("|"))
        text, n = re.subn(r"\{([^{}]*)\}", repl, text)
        if n == 0:
            break
    return text


class PK_DynamicPrompt(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="PK_DynamicPrompt",
            display_name="PK Dynamic Prompt",
            category="PK/conditioning",
            description="Expand {a|b|c} wildcards then CLIP-encode.",
            inputs=[
                io.CLIP.Input("clip"),
                io.String.Input("text", multiline=True, default="a {cat|dog|fox} in {spring|winter}"),
                io.Int.Input("seed", default=0, min=0, max=0xffffffffffffffff,
                             control_after_generate=True),
            ],
            outputs=[io.Conditioning.Output()],
        )

    @classmethod
    def execute(cls, clip, text: str, seed: int) -> io.NodeOutput:
        rng = random.Random(seed)
        expanded = _expand(text, rng)
        tokens = clip.tokenize(expanded)
        cond = clip.encode_from_tokens_scheduled(tokens)
        return io.NodeOutput(cond)
```

### 4.3 要点

- `multiline=True` 让文本框变大；`control_after_generate=True` 让每次生成后 `seed` 自动换值，得到不同随机结果。
- `_expand` 用 `while` 循环支持嵌套通配符（如 `{{a|b}|c}`）。
- 如果你还想支持 `__wildcard.txt__` 外部文件式通配符，用 `folder_paths.get_full_path("wildcards", name)` 读文件再随机选行，思路同 `CUSTOM_DEV_TUTORIAL.md` 第 7 章。
- 输入 `clip` 的写法：`io.CLIP.Input("clip")`（上面的 `hasattr` 守卫只是为了兼容不同 io 版本，正常直接用 `io.CLIP.Input`）。

## 5. `PK_PromptSchedule` —— 分时段提示词

### 5.1 原理

多行输入，每行 `提示词 :: 占比`。把占比累加成时间区间，分别编码后，用 `conditioning_set_values` 给每条打上 `start_percent`/`end_percent`，最后拼成一个 CONDITIONING 列表。采样器在对应进度段只激活对应条件。

### 5.2 完整代码

```python
import node_helpers
from comfy_api.latest import io


class PK_PromptSchedule(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="PK_PromptSchedule",
            display_name="PK Prompt Schedule",
            category="PK/conditioning",
            description="Schedule multiple prompts across the denoising timeline.",
            inputs=[
                io.CLIP.Input("clip"),
                io.String.Input("text",
                                multiline=True,
                                default="a sunny meadow :: 0.5\na stormy sea :: 0.5"),
            ],
            outputs=[io.Conditioning.Output()],
        )

    @classmethod
    def execute(cls, clip, text: str) -> io.NodeOutput:
        lines = [ln.strip() for ln in text.strip().split("\n") if ln.strip()]
        segments = []
        for ln in lines:
            if "::" in ln:
                prompt, frac = ln.rsplit("::", 1)
                segments.append((prompt.strip(), float(frac.strip())))
            else:
                segments.append((ln, 1.0 / len(lines)))   # 没写占比就平分

        total = sum(f for _, f in segments) or 1.0
        out = []
        cursor = 0.0
        for prompt, frac in segments:
            start = cursor
            end = cursor + frac / total
            cursor = end
            tokens = clip.tokenize(prompt)
            cond = clip.encode_from_tokens_scheduled(tokens)   # 单条 CONDITIONING
            # 给这条打上时间区间
            cond = node_helpers.conditioning_set_values(
                cond, {"start_percent": start, "end_percent": end})
            out.extend(cond)
        return io.NodeOutput(out)
```

### 5.3 要点

- 多条 conditioning 用 `out.extend(cond)` 拼成**一个列表**——这正是"分时段"的实现方式：采样器逐条检查 `start_percent/end_percent`，只在该段激活。
- 占比用 `rsplit("::", 1)`，避免提示词里出现 `:` 被误拆。
- 若想"同一条条件在不同时间段出现且互不覆盖"，用 `node_helpers.conditioning_set_values_with_timestep_range`，它会自动保留区间外原始条件。

## 6. `PK_RegionPrompt` —— 分区提示词

### 6.1 原理

给一条已编码的 conditioning 打上 `area` 标记，告诉采样器"这段条件只在 latent 的某个矩形区域生效"。这就是 `ConditioningSetArea` 的全部逻辑。

### 6.2 完整代码（百分比坐标版）

```python
import node_helpers
from comfy_api.latest import io


class PK_RegionPrompt(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="PK_RegionPrompt",
            display_name="PK Region Prompt",
            category="PK/conditioning",
            description="Assign a fractional region to a conditioning (area prompt).",
            inputs=[
                io.Conditioning.Input("conditioning"),
                io.Float.Input("x", default=0.0, min=0.0, max=1.0, step=0.01),
                io.Float.Input("y", default=0.0, min=0.0, max=1.0, step=0.01),
                io.Float.Input("width", default=0.5, min=0.0, max=1.0, step=0.01),
                io.Float.Input("height", default=0.5, min=0.0, max=1.0, step=0.01),
                io.Float.Input("strength", default=1.0, min=0.0, max=10.0, step=0.01),
            ],
            outputs=[io.Conditioning.Output()],
        )

    @classmethod
    def execute(cls, conditioning, x, y, width, height, strength) -> io.NodeOutput:
        area = ("percentage", height, width, y, x)   # 顺序: (h, w, y, x)
        c = node_helpers.conditioning_set_values(
            conditioning,
            {"area": area, "strength": strength, "set_area_to_bounds": False},
        )
        return io.NodeOutput(c)
```

### 6.3 要点

- `area` 元组顺序是 **`(height, width, y, x)`**，单位对百分比模式是 0~1 比例（绝对像素模式则是 `height//8, width//8, y//8, x//8`，即 latent 坐标）。
- 区域提示词常和 `ConditioningCombine`（即 `PK_ConditioningMerge`）配合：一条做全局、一条做区域，拼起来。
- 要基于蒙版而不是矩形，把 `"area"` 换成 `"mask": mask_tensor`（来自 LoadImage 输出的 MASK），见 `ConditioningSetMask` 的键。

## 7. `PK_ConditioningMerge` —— 合并

就是列表相加，但封装成节点更直观：

```python
class PK_ConditioningMerge(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="PK_ConditioningMerge",
            display_name="PK Conditioning Merge",
            category="PK/conditioning",
            inputs=[
                io.Conditioning.Input("conditioning_a"),
                io.Conditioning.Input("conditioning_b"),
            ],
            outputs=[io.Conditioning.Output()],
        )

    @classmethod
    def execute(cls, conditioning_a, conditioning_b) -> io.NodeOutput:
        return io.NodeOutput(conditioning_a + conditioning_b)
```

> 顺序有讲究：通常把"全局/主体"放前面，"区域/风格"放后面；若两条都带 `area` 且重叠，后者的 `strength` 在重叠区占优。

## 9. 排错清单

| 现象 | 原因 | 解决 |
|---|---|---|
| 报错 `cond[0]` / `pooled_output` 相关 | 把 cond 当成单个张量返回 | 必须返回**列表** `[[tensor, dict], ...]`，直接用 `encode_from_tokens_scheduled` 的返回值 |
| 分时段不生效 | 没给每条打 `start_percent`/`end_percent` | 用 `conditioning_set_values` 设置区间 |
| 区域提示词整图都变 | `area` 坐标写反/单位错 | 百分比模式顺序是 `(h, w, y, x)`，值 0~1 |
| 通配符没展开 | 没用 `control_after_generate` 换 seed | 加 `control_after_generate=True` 或手动换 seed |
| 合并后只有一条生效 | 用 `append` 而非 `+` 拼列表 | 用 `list_a + list_b`（`extend` 也行） |
| CLIP 编码慢/卡 | 每次 execute 都重新 tokenize 大词表 | 属正常，必要时缓存 token 结果 |

## 10. 进阶：手动构造一条 conditioning

极少数场景需要完全手搓（例如从外部张量直接注入）。模板如下，**不推荐日常使用**，仅作理解：

```python
cond_tensor = ...   # [B, seq_len, dim]，来自某次 clip.encode
pooled = ...        # [B, pooled_dim]
manual_cond = [[cond_tensor, {"pooled_output": pooled, "start_percent": 0.0, "end_percent": 1.0}]]
```

绝大多数情况请走 `clip.encode_from_tokens_scheduled` + `conditioning_set_values`，避免破坏内部键（如 `model_conds`、`cross_attn` 缓存）导致采样异常。
