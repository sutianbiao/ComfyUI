## 第 0 章 阅读方式

本文分三档深度，你可以按需跳读：

| 深度 | 章节 | 适合场景 |
|---|---|---|
| **用** | 3.x / 4.x 每个节点的「做什么 · 参数表 · 什么时候用」 | 搭工作流时查参数含义 |
| **懂** | 每个节点的「代码详解」 | 知道它到底改了什么张量 / 什么对象 |
| **写** | 第 2 章 + 第 6 章 | 自己写节点 |

几个贯穿全文的约定：

- `LATENT` 在 Python 里就是 `dict`，关键是 `{"samples": Tensor[B, C, H, W]}`，还可能有 `noise_mask`、`batch_index`、`downscale_ratio_spacial` 等附加键。
- `IMAGE` 是 `Tensor[B, H, W, C]`，值域 `[0, 1]`，**通道在最后**。
- `MASK` 是 `Tensor[B, H, W]` 或 `[H, W]`，`1.0` 表示"要处理的地方"。
- `CONDITIONING` 是 `list[ [Tensor, dict] ]`，第二项是**携带区域/掩码/时间步/ControlNet 等元信息的字典**。几乎所有"条件类节点"本质上都在改这个字典。
- `MODEL` 是 `ModelPatcher`。绝大多数"模型补丁类节点"都在 `model.clone()` 之后往克隆体上挂 patch，**不改原对象**。

## 第 1 章 节点系统总览

### 1.1 三套内置节点库

ComfyUI 的节点不是在一个文件里，而是三层，加载顺序与职责都不同：

| 库 | 位置 | 数量 | 加载时机 | 职责 |
|---|---|---|---|---|
| **核心内置** | `nodes.py` | 65 | 模块导入即注册（写死在文件末尾的 `NODE_CLASS_MAPPINGS`） | 最基础、最稳定、兼容基线。任何 ComfyUI 安装都有 |
| **扩展内置** | `comfy_extras/` | 594（140 个文件） | `init_builtin_extra_nodes()` 逐个 `load_custom_node()` | 官方维护的进阶能力：自定义采样、模型合并、3D、音频、视频… |
| **合作方 API** | `comfy_api_nodes/` | 292（41 个文件） | `init_builtin_api_nodes()` | 云端付费模型（Runway、Kling、OpenAI 等），`--offline` 可禁用 |

加载入口在 `nodes.py:2409` `init_builtin_extra_nodes()`——注意它**不是自动扫描目录**，而是一份硬编码的文件清单（142 个文件名，见 `nodes.py:2420-2563`）。这意味着：

> 往 `comfy_extras/` 里丢一个新 `.py` 文件不会自动生效，必须把文件名加进这份清单。

`comfy_api_nodes/` 则是 `glob` 扫描（`nodes.py:2575`）：

```python
api_nodes_files = sorted(glob.glob(os.path.join(api_nodes_dir, "nodes_*.py")))
```

三者的加载最终都走同一个函数 `load_custom_node()`（`nodes.py:2255`），只是 `module_parent` 不同（`"custom_nodes"` / `"comfy_extras"` / `"comfy_api_nodes"`）。这个函数同时负责 V1（`NODE_CLASS_MAPPINGS`）和 V3（`comfy_entrypoint`）两种注册方式：

```python
# nodes.py:2304  V1：模块级字典
if hasattr(module, "NODE_CLASS_MAPPINGS"):
    for name, node_cls in module.NODE_CLASS_MAPPINGS.items():
        if name not in ignore:
            NODE_CLASS_MAPPINGS[name] = node_cls
            node_cls.RELATIVE_PYTHON_MODULE = "{}.{}".format(module_parent, get_module_name(module_path))
    ...
# nodes.py:2316  V3：异步入口点
elif hasattr(module, "comfy_entrypoint"):
    extension = await entrypoint()
    await extension.on_load()
    for node_cls in await extension.get_node_list():
        schema = node_cls.GET_SCHEMA()
        NODE_CLASS_MAPPINGS[schema.node_id] = node_cls
```

关键点：`ignore` 参数是 `base_node_names = set(NODE_CLASS_MAPPINGS.keys())`，即 **核心 65 个节点先占位，后来的同名节点会被静默忽略**——这是防止自定义节点覆盖核心节点的第一道防线。

### 1.2 节点从定义到执行的完整生命周期

```
① 定义        nodes.py / comfy_extras/*.py 中的 class
                ↓  NODE_CLASS_MAPPINGS 或 comfy_entrypoint
② 注册        nodes.py:2077  NODE_CLASS_MAPPINGS（全局字典）
                ↓  server.py /object_info
③ 暴露给前端  GET /object_info  → 前端渲染节点菜单与插槽
                ↓  用户连线、点 Queue
④ 入队        POST /prompt → DynamicPrompt → PromptQueue
                ↓
⑤ 拓扑排序    comfy_execution/graph.py  ExecutionList
                ↓
⑥ 逐节点执行  execution.py:execute()
   ├─ get_input_data()          execution.py:164   解析输入（连线 / widget / hidden）
   ├─ 缓存查询 IsChangedCache    execution.py:84    IS_CHANGED 或 fingerprint_inputs
   ├─ _async_map_node_over_list() execution.py:236  按 batch 展开调用
   │    ├─ V3: class_clone = type_obj.PREPARE_CLASS_CLONE(v3_data); f = make_locked_method_func(...)
   │    └─ V1: f = getattr(obj, FUNCTION)
   ├─ f(**inputs)               ← 真正跑到你的节点代码
   └─ get_output_data()         execution.py:352   收集 ui / expand / 结果
                ↓
⑦ 结果        写入 outputs → history → WebSocket 推给前端
```

理解 ⑥ 的三个细节，很多"为什么我的节点没执行 / 执行了 N 次"的问题就通了：

1. **列表展开**：`_async_map_node_over_list()` 会取所有输入里**最长的那个列表长度** `max_len_input`，然后循环调用你的函数 N 次（`execution.py:283`）。这就是"上游输出 5 张图，下游节点自动跑 5 次"的实现。除非节点声明 `INPUT_IS_LIST = True`，那它会一次性拿到整个 list。
2. **V3 用的是类克隆**：`PREPARE_CLASS_CLONE(v3_data)`（`execution.py:269`）。所以 V3 节点的 `execute` 全是 `@classmethod`，**不要在里面存实例状态**（`self.xxx` 会串味）。需要跨节点状态请用 V1 实例节点。
3. **缓存键**：`IS_CHANGED` 的返回值参与缓存判断（`execution.py:84-95`）。像 `LoadImage` 返回文件 sha256，所以改了图片会重新执行，不改就直接复用。

### 1.3 V1 与 V3 两套节点范式

本仓库同时存在两套写法，且**同一份 `NODE_CLASS_MAPPINGS` 里混装**。判断标准：看 `execution.py:264` 的 `isinstance(obj, _ComfyNodeInternal)`。

| 维度 | V1（传统） | V3（`comfy_api.latest.io`） |
|---|---|---|
| 基类 | 通常无，或 `ComfyNodeABC` | `io.ComfyNode` / `IO.ComfyNode` |
| 接口声明 | 类属性 `INPUT_TYPES` / `RETURN_TYPES` / `FUNCTION` / `CATEGORY` | `@classmethod define_schema()` 返回 `io.Schema(...)` |
| 执行方法 | `FUNCTION` 字符串指向的方法，**实例方法** `def f(self, ...)` | `execute()`，**类方法** `@classmethod def execute(cls, ...)` |
| 返回值 | `tuple`，如 `return (images,)` | `io.NodeOutput(...)` |
| UI 输出 | `return {"ui": {...}, "result": (...)}` | `io.NodeOutput(value, ui=UI.PreviewImage(...))` |
| 注册 | 模块级 `NODE_CLASS_MAPPINGS` 字典 | 模块级 `async def comfy_entrypoint() -> MyExtension`，Extension 的 `get_node_list()` |
| 输入定义 | `("INT", {"default": 20, "min": 1})` 元组 | `io.Int.Input("steps", default=20, min=1)` |
| 数量占比（comfy_extras） | 73 | **521** |

> **结论**：新代码一律写 V3。V1 只在 `nodes.py` 核心节点和少数老扩展（`nodes_model_merging.py`、`nodes_model_advanced.py`、`nodes_hooks.py`…）里保留，因为改了会破坏工作流兼容性。

`comfy_extras` 里绝大多数文件同时 import 了 `IO` 和 `io` 两个名字（`from comfy_api.latest import ComfyExtension, IO, UI` 或 `io`），它们是同一个对象的不同别名，写法风格差异而已。

### 2.1 V1 节点的全部字段

定义位置：`comfy/comfy_types/node_typing.py:214` 的 `ComfyNodeABC`。

```python
class CLIPTextEncode(ComfyNodeABC):          # nodes.py:58
    @classmethod
    def INPUT_TYPES(s) -> InputTypeDict:
        return {
            "required": {
                "text": (IO.STRING, {"multiline": True, "dynamicPrompts": True, "tooltip": "..."}),
                "clip": (IO.CLIP, {"tooltip": "..."})
            }
        }
    RETURN_TYPES = (IO.CONDITIONING,)
    OUTPUT_TOOLTIPS = ("A conditioning containing the embedded text ...",)
    FUNCTION = "encode"                       # ← 真正被调用的方法名
    CATEGORY = "model/conditioning"           # ← 前端"添加节点"菜单路径，用 / 分层
    DESCRIPTION = "Encodes a text prompt ..." # ← 悬停提示
    SEARCH_ALIASES = ["text", "prompt", ...]  # ← 搜索别名

    def encode(self, clip, text):             # ← 参数名必须与 INPUT_TYPES 的 key 一致
```

### 2.4 隐藏输入 Hidden

Hidden 输入不出现在 UI 上，由执行引擎注入。V1 写法（`nodes.py:1686`）：

```python
"hidden": {"prompt": "PROMPT", "extra_pnginfo": "EXTRA_PNGINFO"}
```

V3 写法（`comfy_extras/nodes_mask.py:426`）：

```python
hidden=[IO.Hidden.prompt, IO.Hidden.extra_pnginfo]
```

| 名字 | 注入内容 | 典型用途 |
|---|---|---|
| `PROMPT` | 完整 workflow dict | 写进 PNG 元数据（SaveImage / SaveLatent） |
| `EXTRA_PNGINFO` | 额外元数据 dict | 同上 |
| `UNIQUE_ID` / `unique_id` | 节点在图中的 id | 前端通信、日志定位 |
| `DYNPROMPT` | `DynamicPrompt` 对象 | 节点展开（node expansion） |

### 2.5 执行控制：OUTPUT_NODE / IS_CHANGED / VALIDATE_INPUTS / 懒求值 / 列表

**OUTPUT_NODE = True**（`nodes.py:1695`）

**IS_CHANGED**（`nodes.py:1808`）

```python
@classmethod
def IS_CHANGED(s, image):
    image_path = folder_paths.get_annotated_filepath(image)
    m = hashlib.sha256()
    with open(image_path, 'rb') as f:
        m.update(f.read())
    return m.digest().hex()
```

返回任意可比较值；变了就重跑，没变就走缓存。`LoadImage`、`LoadLatent` 用它做文件内容指纹。V3 对应 `fingerprint_inputs()`。

**VALIDATE_INPUTS**（`nodes.py:1816`）

```python
@classmethod

        return "Invalid image file: {}".format(image)   # 返回字符串 = 报错
```

返回**字符串即视为错误**。这是前端传来的文件名不可信、必须在服务端复核的典型场景（`DEVELOPMENT_GUIDE.md` 22.1 也强调过）。

#### 3.1.1 CheckpointLoaderSimple —— 一切工作流的起点

**做什么**：加载一个完整 checkpoint 文件，自动推断模型结构，拆出扩散模型 / 文本编码器 / VAE 三件套。

**参数**

| 输入 | 类型 | 说明 |
|---|---|---|
| `ckpt_name` | COMBO | `models/checkpoints/` 下的文件名，由 `folder_paths.get_filename_list("checkpoints")` 动态列出 |

**输出**：`MODEL`（扩散模型）、`CLIP`（文本编码器）、`VAE`

**代码详解**（`nodes.py:621-642`）

```python
class CheckpointLoaderSimple:
    @classmethod
    def INPUT_TYPES(s):
        return {"required": {
            "ckpt_name": (folder_paths.get_filename_list("checkpoints"),
                          {"tooltip": "The name of the checkpoint (model) to load."}),
        }}
    RETURN_TYPES = ("MODEL", "CLIP", "VAE")
    FUNCTION = "load_checkpoint"
    CATEGORY = "model/loaders"

    def load_checkpoint(self, ckpt_name):
        ckpt_path = folder_paths.get_full_path_or_raise("checkpoints", ckpt_name)
        out = comfy.sd.load_checkpoint_guess_config(
            ckpt_path, output_vae=True, output_clip=True,
            embedding_directory=folder_paths.get_folder_paths("embeddings"))
        return out[:3]
```

四个细节：

1. **`folder_paths.get_filename_list("checkpoints")` 在 `INPUT_TYPES()` 里被调用**，而 `INPUT_TYPES` 是每次 `/object_info` 请求都会执行的类方法——所以你往 `models/checkpoints/` 丢新模型后刷新前端就能看到，无需重启。
2. **`get_full_path_or_raise` 而不是 `get_full_path`**：路径不存在直接抛异常，而不是返回 `None` 让后面炸得莫名其妙。
3. **`load_checkpoint_guess_config`** 是"自动推断"的关键。它内部走 `comfy/model_detection.py` 从 state_dict 的 key 形状反推模型族（SD15 / SDXL / SD3 / Flux / Wan…）。对比 `CheckpointLoader`（旧版）需要你手工指定 `config_name`。
4. **`return out[:3]` 是刻意的截断**：`load_checkpoint_guess_config` 在有 CLIP Vision 时会返回 4 项，这里只取前 3 项。想拿 CLIP_VISION 请用 `unCLIPCheckpointLoader`。

**什么时候用**：99% 的文生图工作流。当你需要**分开**指定 unet / clip / vae（比如 SDXL 换 fp16 VAE、Flux 单独加载 t5）时改用 `UNETLoader` + `DualCLIPLoader` + `VAELoader`。

#### 3.1.2 VAELoader —— 一个藏了很多细节的节点

**做什么**：加载 VAE，或者选择内置的 TAESD 轻量预览 VAE，或者 `pixel_space`（不使用 VAE，像素空间模型专用）。

**代码详解**（`nodes.py:776-873`）

```python
class VAELoader:
    video_taes = ["taehv", "lighttaew2_2", "lighttaew2_1", "lighttaehy1_5", "taeltx_2", "taeh3"]
    image_taes = ["taesd", "taesdxl", "taesd3", "taef1", "taef2", "taeqi2_1"]

    @staticmethod
    def vae_list(s):
        vaes = folder_paths.get_filename_list("vae")
        approx_vaes = folder_paths.get_filename_list("vae_approx")
        have_img_encoder, have_img_decoder = set(), set()
        for v in approx_vaes:
            parts = v.rsplit("_", 1)
            if len(parts) != 2 or parts[0] not in s.image_taes:
                for tae in s.video_taes:
                    if v.startswith(tae):
                        vaes.append(v)
                        break
                continue
            if parts[1].startswith("encoder."):
                have_img_encoder.add(parts[0])
            elif parts[1].startswith("decoder."):
                have_img_decoder.add(parts[0])
        vaes += [k for k in have_img_decoder if k in have_img_encoder]
        vaes.append("pixel_space")
        return vaes
```

这段代码在解决一个真实问题：**TAESD 的 encoder 和 decoder 是两个独立文件**（`taesd_encoder.pth` / `taesd_decoder.pth`），只有两个都存在时这个选项才可用。所以它先扫 `models/vae_approx/`，收集"有 encoder 的前缀集合"和"有 decoder 的前缀集合"，取交集（`nodes.py:797`），再加进去。视频类 TAE 是单文件，直接按前缀匹配加进去。

`load_taesd()`（`nodes.py:801-833`）负责把两个文件拼成一个 state_dict，并补上 `vae_scale` / `vae_shift` 两个常数：

```python
if name == "taesd":
    sd["vae_scale"] = torch.tensor(0.18215)
    sd["vae_shift"] = torch.tensor(0.0)
elif name == "taesdxl":
    sd["vae_scale"] = torch.tensor(0.13025)
...
elif name == "taeqi2_1":
    latent_format = comfy.latent_formats.QwenImage21()
    sd["vae_scale"] = 1.0 / latent_format.latents_std[0]
    sd["vae_shift"] = latent_format.latents_mean[0]
```

**为什么要 hardcode 这些数**：TAESD 权重文件里不带缩放系数，而不同模型族的潜空间归一化系数不同。SD1.5 的 `0.18215` 就是经典 VAE scaling factor；`taeqi2_1` 则反过来从 `latent_formats` 里查，避免再 hardcode 一次。

最后一段（`nodes.py:864-872`）：

```python
vae = comfy.sd.VAE(sd=sd, metadata=metadata)
vae.throw_exception_if_invalid()
if vae_path is not None:
    vae.patcher.cached_patcher_init = (comfy.sd.load_vae_patcher, (vae_path, metadata, None))
return (vae,)
```

`cached_patcher_init` 是为了多 GPU 深拷贝——只有能通过**单个文件**重建的 VAE（即真实 VAE 和视频 TAE）才设置；`pixel_space` 和图片 TAESD（由两个文件拼成）不行，所以 `vae_path is None` 时跳过。

**`pixel_space` 是什么**：给 Z-Image 这类**直接在像素空间做扩散**的模型用，sd 里只有一个哨兵张量 `{"pixel_space_vae": tensor(1.0)}`。

#### 3.1.3 LoraLoader —— 带缓存的 LoRA 叠加

**做什么**：把 LoRA 权重同时叠加到扩散模型和 CLIP 上。

**参数**

| 输入 | 默认 | 说明 |
|---|---|---|
| `model` | — | 扩散模型 |
| `clip` | — | 文本编码器 |
| `lora_name` | — | `models/loras/` 下的文件 |
| `strength_model` | 1.0 | 范围 `-100 ~ 100`，**可为负**（反向前推） |
| `strength_clip` | 1.0 | 同上 |

**代码详解**（`nodes.py:714-759`）

```python
class LoraLoader:
    def __init__(self):
        self.loaded_lora = None          # ← 实例级缓存！

    def load_lora(self, model, clip, lora_name, strength_model, strength_clip):
        if strength_model == 0 and strength_clip == 0:
            return (model, clip)          # ① 强度都 0，直接短路

        lora_path = folder_paths.get_full_path_or_raise("loras", lora_name)
        lora = None
        lora_metadata = None
        if self.loaded_lora is not None:
            if self.loaded_lora[0] == lora_path:
                lora = self.loaded_lora[1]                     # ② 命中缓存
                lora_metadata = self.loaded_lora[2] if len(self.loaded_lora) > 2 else None
            else:
                self.loaded_lora = None

        if lora is None:
            lora, lora_metadata = comfy.utils.load_torch_file(lora_path, safe_load=True, return_metadata=True)
            self.loaded_lora = (lora_path, lora, lora_metadata)

        model_lora, clip_lora = comfy.sd.load_lora_for_models(
            model, clip, lora, strength_model, strength_clip, lora_metadata=lora_metadata)
        return (model_lora, clip_lora)
```

三点值得学：

1. **实例级缓存**（`self.loaded_lora`）：只缓存**最近一个** LoRA 文件。为什么有效？因为常见用法是同一个节点连续跑多张图，或者调强度反复试。改了 `lora_name` 就失效。这是 V1 实例节点相比 V3 类节点的一个真实优势——V3 的 `execute` 是 `@classmethod`，没有这种 per-node 实例状态。
2. **`safe_load=True`**：用 safetensors 安全加载，避免 pickle 反序列化风险。
3. **`return_metadata=True` + 传给 `load_lora_for_models`**：LoRA 文件头部可能带元数据（如某些格式的 rank/alpha 约定），用来正确计算权重。

**`LoraLoaderModelOnly`**（`nodes.py:761-774`）用继承复用：

```python
class LoraLoaderModelOnly(LoraLoader):
    RETURN_TYPES = ("MODEL",)
    FUNCTION = "load_lora_model_only"

    def load_lora_model_only(self, model, lora_name, strength_model):
        return (self.load_lora(model, None, lora_name, strength_model, 0)[0],)
```

传 `clip=None`、`strength_clip=0`，取返回值第 0 项。这是 ComfyUI 里很典型的"继承 + 收窄接口"套路。

**串联**：多个 LoraLoader 首尾相接即可叠加（每个都对上游 MODEL 做 `clone()` + patch）。

### 3.2 文本编码与条件族（19 个）

这族节点绝大多数在做同一件事：**修改 CONDITIONING 的第二项字典**。

先记住 CONDITIONING 的结构：

```python
[
  [ Tensor[1, token_len, hidden_dim],   # 编码后的文本向量
    { "pooled_output": Tensor[...],     # 池化向量（SDXL 等需要）
      "area": (h, w, y, x),             # 生效区域（潜空间尺度）
      "strength": 1.0,                  # 条件强度
      "mask": Tensor,                   # 区域掩码
      "start_percent": 0.0, "end_percent": 1.0,   # 生效时间步区间
      "control": ControlBase,           # 挂 ControlNet
      ... } ],
  ...
]
```

工具函数 `node_helpers.conditioning_set_values()`（`node_helpers.py:9`）就是"深拷贝第二项字典并写入新键"：

```python
def conditioning_set_values(conditioning, values={}, append=False):
    c = []
    for t in conditioning:
        n = [t[0], t[1].copy()]     # ← 只 copy 字典，张量本体共享（省显存）
        for k in values:
            val = values[k]
            if append:              # append=True 时把新值追加到已有列表后
                old_val = n[1].get(k, None)
                if old_val is not None:
                    val = old_val + val
            n[1][k] = val
        c.append(n)
    return c
```

> **为什么必须 `.copy()`**：CONDITIONING 常同时被正负两条分支、多个区域条件共享。不 copy 就会互相污染。

#### 3.2.1 CLIPTextEncode —— 最基础的文本编码

`nodes.py:58-79`，全仓库唯一一个继承 `ComfyNodeABC` 的核心节点（V1 但带类型标注）：

```python
class CLIPTextEncode(ComfyNodeABC):
    @classmethod
    def INPUT_TYPES(s) -> InputTypeDict:
        return {"required": {
            "text": (IO.STRING, {"multiline": True, "dynamicPrompts": True, ...}),
            "clip": (IO.CLIP, {"tooltip": "..."})
        }}
    RETURN_TYPES = (IO.CONDITIONING,)
    FUNCTION = "encode"
    CATEGORY = "model/conditioning"

    def encode(self, clip, text):
        if clip is None:
            raise RuntimeError("ERROR: clip input is invalid: None\n\n"
                               "If the clip is from a checkpoint loader node your checkpoint "
                               "does not contain a valid clip or text encoder model.")
        tokens = clip.tokenize(text)
        return (clip.encode_from_tokens_scheduled(tokens), )
```

三个知识点：

1. **`encode_from_tokens_scheduled`** 而不是 `encode_from_tokens`。`scheduled` 版本返回的是**带时间表的** conditioning，支持提示词里的时间步调度语法。这是新版的标准做法。
2. **`clip is None` 的显式报错**（`nodes.py:76`）。什么时候会 None？用 `UNETLoader` 单独加载扩散模型却没接 CLIP，或者 checkpoint 里根本不含文本编码器（某些纯 unet 文件）。这个错误信息直接告诉用户原因——写节点时值得模仿。
3. **`dynamicPrompts: True`**：开启前端对 `{a|b|c}` 随机选择和 `(word:1.2)` 权重语法的解析。任何接受提示词的节点都该开。

**提示词语法**（`USAGE.md` 9.3）：
- `(good code:1.2)` 加权，默认 1.1；字面括号用 `\(`
- `{day|night}` 每次入队随机选一个；字面大括号用 `\{`
- 支持 `// 注释` 与 `/* 注释 */`
- `embedding:文件名.pt` 引用 `models/embeddings/` 下的 Textual Inversion

#### 3.2.2 ConditioningCombine / Concat / Average / Multiply —— 四种"合并"

这四个名字很像，含义完全不同：

| 节点 | 行号 | 语义 | 结果长度 |
|---|---|---|---|
| `ConditioningCombine` | 82 | **串联**：两条条件依次都生效 | 相加（`len(a) + len(b)`） |
| `ConditioningConcat` | 136 | **拼接 token**：把 b 的 token 接到 a 的 token 后面 | 不变（`len(a)`） |
| `ConditioningAverage` | 96 | **插值**：按权重混合两个条件的向量 | 不变（`len(a)`） |
| `ConditioningMultiply` | 164 | **缩放**：整体乘一个系数 | 不变 |

**Combine**（`nodes.py:93`）简单到只有一行，但这是"多个提示词分别生效"的实现基础：

```python
def combine(self, conditioning_1, conditioning_2):
    return (conditioning_1 + conditioning_2, )
```

列表相加 → 采样时 `calc_cond_batch` 会**累加**所有条目的贡献。

**Concat**（`nodes.py:148-162`）是 token 维度的拼接：

```python
cond_from = conditioning_from[0][0]        # 取来源的第 0 条
for i in range(len(conditioning_to)):
    t1 = conditioning_to[i][0]
    tw = torch.cat((t1, cond_from), 1)     # dim=1 即 token 维
    n = [tw, conditioning_to[i][1].copy()]
    out.append(n)
```

注意 `if len(conditioning_from) > 1` 会打 warning：**只用第一条**，多余的静默忽略。这类 warning 在 Concat 和 Average 里都有，是 ComfyUI 一贯的"不崩、但告诉你"风格。

**Average**（`nodes.py:109-134`）最复杂，因为要处理 token 长度不等和 pooled_output：

```python
t0 = cond_from[:,:t1.shape[1]]              # ① 截断到目标长度
if t0.shape[1] < t1.shape[1]:               # ② 不够就补零
    t0 = torch.cat([t0] + [torch.zeros((1, (t1.shape[1] - t0.shape[1]), t1.shape[2]))], dim=1)

tw = torch.mul(t1, conditioning_to_strength) + torch.mul(t0, (1.0 - conditioning_to_strength))
t_to = conditioning_to[i][1].copy()
if pooled_output_from is not None and pooled_output_to is not None:
    t_to["pooled_output"] = torch.mul(pooled_output_to, s) + torch.mul(pooled_output_from, (1.0 - s))
elif pooled_output_from is not None:
    t_to["pooled_output"] = pooled_output_from
```

`conditioning_to_strength=1.0` → 完全是 `to`；`0.0` → 完全是 `from`。**这是做风格融合 / 提示词插值的主力节点**。

**Multiply**（`nodes.py:176-185`）走的是另一条路——用 `conditioning_set_values` 并同时缩放 pooled_output：

```python
def multiply(self, conditioning, multiplier):
    c = []
    for t in conditioning:
        values = {}
        pooled_output = t[1].get("pooled_output", None)
        if pooled_output is not None:
            values["pooled_output"] = pooled_output * multiplier
        scaled = node_helpers.conditioning_set_values([[t[0] * multiplier, t[1]]], values)[0]
        c.append(scaled)
    return (c,)
```

#### 3.2.3 Conditioning 区域控制四件套

这一组实现"提示词只在画面某个区域/某个掩码/某个时间步生效"。

**ConditioningSetArea**（`nodes.py:187-208`）—— 矩形区域：

```python
def append(self, conditioning, width, height, x, y, strength):
    c = node_helpers.conditioning_set_values(conditioning, {
        "area": (height // 8, width // 8, y // 8, x // 8),   # ← 像素→潜空间，除以 8
        "strength": strength,
        "set_area_to_bounds": False})
    return (c, )
```

**`// 8` 是关键**：`area` 用的是潜空间尺度（VAE 下采样 8 倍）。前端填的是像素，节点负责换算。

**ConditioningSetAreaPercentage**（`nodes.py:210-229`）—— 用比例代替像素：

```python
"area": ("percentage", height, width, y, x),
```

第一个元素是哨兵字符串 `"percentage"`，下游（samplers 的 mask 计算）见到它就知道要按相对比例解释。这是 ComfyUI 里常见的"元组首元素做 tag"的技巧。

**ConditioningSetAreaStrength**（`nodes.py:231-244`）—— 只改强度，不管区域。

**ConditioningSetMask**（`nodes.py:247-272`）—— 用任意形状掩码：

```python
def append(self, conditioning, mask, set_cond_area, strength):
    set_area_to_bounds = False
    if set_cond_area != "default":
        set_area_to_bounds = True
    if len(mask.shape) < 3:
        mask = mask.unsqueeze(0)                    # [H,W] → [1,H,W]

    c = node_helpers.conditioning_set_values(conditioning, {
        "mask": mask,
        "set_area_to_bounds": set_area_to_bounds,
        "mask_strength": strength})
    return (c, )
```

`set_cond_area = "mask bounds"` 时开 `set_area_to_bounds`，意思是"只在掩码的外接矩形内计算，矩形外直接跳过"——**省算力的关键开关**，对大图 + 小掩码的场景提速明显。

**ConditioningSetTimestepRange**（`nodes.py:305-319`）—— 时间步区间：

```python
c = node_helpers.conditioning_set_values(conditioning, {"start_percent": start, "end_percent": end})
```

`start_percent=0, end_percent=0.5` 表示"只在前半程生效"。这是做**分步提示词**（先出构图、后出细节）的基础。

**ConditioningZeroOut**（`nodes.py:274-303`）—— 把条件清零，等价于"无条件"：

```python
def zero_out(self, conditioning):
    c = []
    for t in conditioning:
        d = t[1].copy()
        pooled_output = d.get("pooled_output", None)
        if pooled_output is not None:
            d["pooled_output"] = torch.zeros_like(pooled_output)
        conditioning_lyrics = d.get("conditioning_lyrics", None)
        if conditioning_lyrics is not None:
            d["conditioning_lyrics"] = torch.zeros_like(conditioning_lyrics)
        conditioning_scale = d.get("conditioning_scale", None)
        ...
        n = [torch.zeros_like(t[0]), d]
        c.append(n)
    return (c, )
```

注意它把**已知的所有"额外条件张量"都清零了**（`pooled_output`、`conditioning_lyrics`、`conditioning_scale`、`direct_context`）。为什么？因为音频/视频模型会在 cond dict 里塞额外张量，只清 `t[0]` 会留下残留引导。

#### 3.2.4 ControlNet 应用：ControlNetApply vs ControlNetApplyAdvanced

这是理解"新版 vs 旧版"差异的好例子。

**ControlNetApply**（`nodes.py:910`，`DEPRECATED = True`）：

```python
def apply_controlnet(self, conditioning, control_net, image, strength):
    if strength == 0:
        return (conditioning, )
    c = []
    control_hint = image.movedim(-1, 1)          # [B,H,W,C] → [B,C,H,W]
    for t in conditioning:
        n = [t[0], t[1].copy()]
        c_net = control_net.copy().set_cond_hint(control_hint, strength)
        if 'control' in t[1]:
            c_net.set_previous_controlnet(t[1]['control'])
        n[1]['control'] = c_net
        n[1]['control_apply_to_uncond'] = True   # ← 负面条件也应用
        c.append(n)
    return (c, )
```

**ControlNetApplyAdvanced**（`nodes.py:941`）的三个改进：

```python
def apply_controlnet(self, positive, negative, control_net, image, strength,
                     start_percent, end_percent, vae=None, extra_concat=[]):
    if strength == 0:
        return (positive, negative)

    control_hint = image.movedim(-1, 1)
    cnets = {}                                   # ① 复用缓存

    out = []
    for conditioning in [positive, negative]:
        c = []
        for t in conditioning:
            d = t[1].copy()
            prev_cnet = d.get('control', None)
            if prev_cnet in cnets:
                c_net = cnets[prev_cnet]
            else:
                c_net = control_net.copy().set_cond_hint(
                    control_hint, strength, (start_percent, end_percent),
                    vae=vae, extra_concat=extra_concat)   # ② 时间区间 + vae + 额外 concat
                c_net.set_previous_controlnet(prev_cnet)
                cnets[prev_cnet] = c_net

            d['control'] = c_net
            d['control_apply_to_uncond'] = False  # ③ 负面不应用
            n = [t[0], d]
            c.append(n)
        out.append(c)
    return (out[0], out[1])
```

| 差异 | 旧版 | Advanced |
|---|---|---|
| 输入 | 单条 conditioning | positive / negative 分开 |
| `control_apply_to_uncond` | `True`（负面也应用） | `False`（**不应用**） |
| 时间区间 | 无 | `start_percent` / `end_percent` |
| VAE 参数 | 无 | 有（某些 ControlNet 需要在潜空间预处理 hint） |
| 对象复用 | 每条都 `copy()` | 用 `cnets` 字典按 `prev_cnet` 复用 |

**`control_apply_to_uncond=False` 是质量关键点**：CFG 的负面分支不应被 ControlNet 的结构约束污染，否则构图会被"反提示词"拉偏。这就是为什么 Advanced 版成为默认。

**`set_previous_controlnet` 实现多 ControlNet 串联**：每个新 ControlNet 挂到前一个的 `previous_controlnet` 上，形成链表，采样时依次执行。

#### 3.2.5 StyleModelApply —— Redux 风格迁移

`nodes.py:1126-1187`，用在 StyleModelLoader + CLIPVisionEncode 之后。它把参考图的 CLIP Vision 特征**当作额外 token 拼到文本 token 后面**：

```python
cond = style_model.get_cond(clip_vision_output).flatten(start_dim=0, end_dim=1).unsqueeze(dim=0)
if strength_type == "multiply":
    cond *= strength

n = cond.shape[1]
for t in conditioning:
    (txt, keys) = t
    keys = keys.copy()
    if "attention_mask" in keys or (strength_type == "attn_bias" and strength != 1.0):
        attn_bias = torch.log(torch.Tensor([strength if strength_type == "attn_bias" else 1.0]))
        ...
        # 把 attention_mask 扩大 n 行 n 列，为新 token 腾位置
        new_mask = torch.zeros((txt.shape[0], n_txt + n + n_ref, n_txt + n + n_ref), dtype=torch.float16)
        new_mask[:, :n_txt, :n_txt]            = mask[:, :n_txt, :n_txt]
        new_mask[:, :n_txt, n_txt+n:]          = mask[:, :n_txt, n_txt:]
        new_mask[:, n_txt+n:, :n_txt]          = mask[:, n_txt:, :n_txt]
        new_mask[:, n_txt+n:, n_txt+n:]        = mask[:, n_txt:, n_txt+n:]
        new_mask[:, :n_txt, n_txt:n_txt+n]     = attn_bias
        new_mask[:, n_txt+n:, n_txt:n_txt+n]   = attn_bias
        keys["attention_mask"] = new_mask.to(txt.device)
    c_out.append([torch.cat((txt, cond), dim=1), keys])
```

最精妙的是 `attn_bias = torch.log(...)` 那行（`nodes.py:1156`）：attention mask 在这里被当成**加性偏置**（因为 attention 里 `logits + mask`），所以想让新 token 的注意力乘以 `strength`，就得填 `log(strength)`。代码注释也解释了为什么用 `torch.log` 而不是 `math.log`——后者遇到 0 会抛异常，前者返回 `-inf` 正是我们想要的（完全屏蔽）。

`strength_type` 两种模式：
- `multiply`：直接缩放风格 token 的数值
- `attn_bias`：通过 attention bias 控制风格 token 被关注的程度

### 3.3 采样器族（2 个 + 1 个公共函数）

#### 3.3.1 common_ksampler —— 真正的采样入口

`nodes.py:1581-1604`。**`KSampler` 和 `KSamplerAdvanced` 都只是它的包装**，理解它就理解了两个节点：

```python
def common_ksampler(model, seed, steps, cfg, sampler_name, scheduler, positive, negative,
                    latent, denoise=1.0, disable_noise=False,
                    start_step=None, last_step=None, force_full_denoise=False):
    latent_image = latent["samples"]
    # ① 修正通道数（不同模型 latent 通道数不同，如 SD=4 / SD3=16 / Flux=16）
    latent_image = comfy.sample.fix_empty_latent_channels(
        model, latent_image,
        latent.get("downscale_ratio_spacial", None),
        latent.get("downscale_ratio_temporal", None))

    # ② 生成噪声
    if disable_noise:
        noise = comfy.sample.prepare_empty_noise(latent_image)
    else:
        batch_inds = latent["batch_index"] if "batch_index" in latent else None
        noise = comfy.sample.prepare_noise(latent_image, seed, batch_inds)

    # ③ 噪声掩码（inpainting）
    noise_mask = None
    if "noise_mask" in latent:
        noise_mask = latent["noise_mask"]

    # ④ 预览回调 + 进度条
    callback = latent_preview.prepare_callback(model, steps)
    disable_pbar = not comfy.utils.PROGRESS_BAR_ENABLED

    # ⑤ 核心采样
    samples = comfy.sample.sample(model, noise, steps, cfg, sampler_name, scheduler,
                                  positive, negative, latent_image,
                                  denoise=denoise, disable_noise=disable_noise,
                                  start_step=start_step, last_step=last_step,
                                  force_full_denoise=force_full_denoise,
                                  noise_mask=noise_mask, callback=callback,
                                  disable_pbar=disable_pbar, seed=seed)

    # ⑥ 组装输出：清掉 downscale 标记，写入 samples
    out = latent.copy()
    out.pop("downscale_ratio_spacial", None)
    out.pop("downscale_ratio_temporal", None)
    out["samples"] = samples
    return (out, )
```

六个步骤对应六个可调点，也解释了为什么扩展节点要拆成 NOISE / SAMPLER / SIGMAS / GUIDER 四个独立对象（`nodes_custom_sampler.py`，见 4.2）——就是把 ②③④⑤ 拆出来单独可控。

`batch_inds`（`nodes.py:1588`）是一个容易忽略的细节：它让 batch 中每一张图拿到**不同的噪声**，而不是全部相同。来源见 `LatentFromBatch` / `RepeatLatentBatch` 写入的 `batch_index`。

`out.pop("downscale_ratio_spacial")` 是必须的：这个标记只对"空 latent"有意义（告诉采样器真实像素尺寸），采样完就该清掉，否则下游再采样时会误用。

```python
        latent = latent.unbind()[0]
    images = vae.decode(latent)
    if len(images.shape) == 5:                     # ② 视频 VAE 返回 [B,T,H,W,C]
        images = images.reshape(-1, images.shape[-3], images.shape[-2], images.shape[-1])
    return (images, )
```

- `is_nested`：变长 batch（不同尺寸 latent 打包在一起）时用，取第一项。
- `len(shape) == 5`：视频 VAE 的结果把时间维合并进 batch 维。

对应的 encode（`nodes.py:395`）就一行：`t = vae.encode(pixels); return ({"samples":t}, )`。

#### 3.4.3 VAEDecodeTiled / VAEEncodeTiled —— 大图显存救星

`nodes.py:348-383`。分块解码，避免一次性把整张大图塞进显存。

```python
def decode(self, vae, samples, tile_size, overlap=64, temporal_size=64, temporal_overlap=8):
    if tile_size < overlap * 4:                 # ① 参数自洽修正
        overlap = tile_size // 4
    if temporal_size < temporal_overlap * 2:
        temporal_overlap = temporal_overlap // 2

    temporal_compression = vae.temporal_compression_decode()
    if temporal_compression is not None:        # ② 视频 VAE：时间维也要压缩换算
        temporal_size = max(2, temporal_size // temporal_compression)
        temporal_overlap = max(1, min(temporal_size // 2, temporal_overlap // temporal_compression))
    else:
        temporal_size = None                    # 图片 VAE：不传时间参数
        temporal_overlap = None

    latent = samples["samples"]
    if latent.is_nested:
        latent = latent.unbind()[0]

    compression = vae.spacial_compression_decode()
    images = vae.decode_tiled(latent,
                              tile_x=tile_size // compression,     # ③ 像素尺度 → latent 尺度
                              tile_y=tile_size // compression,
                              overlap=overlap // compression,
                              tile_t=temporal_size,
                              overlap_t=temporal_overlap)
    ...
```

三个设计点：

1. **参数自洽修正**：用户可能填出 `tile_size=64, overlap=64` 这种无意义组合，节点直接修正而不是报错。
2. **`compression` 换算**：`tile_size` 是**像素**单位，而 `decode_tiled` 要的是 **latent** 单位，所以要除 `compression`（通常 8）。这是新手最容易弄错的地方。
3. **视频/图片自适应**：`temporal_compression_decode()` 返回 `None` 说明是图片 VAE，就把时间参数置 `None`。

**参数含义**

| 参数 | 默认 | 说明 |
|---|---|---|
| `tile_size` | 512 | 每块的像素边长。越小越省显存但越慢（且可能有接缝） |
| `overlap` | 64 | 块之间重叠的像素数。**防接缝的关键**，建议 ≥ 32 |
| `temporal_size` / `temporal_overlap` | 64 / 8 | 仅视频 VAE 有效，每次解码多少帧 |

> 注意 `VAEEncodeTiled`（`nodes.py:413`）的 `tile_size` **没有**除 compression——因为 `encode_tiled` 接收的就是像素尺度。两个节点接口不对称，用的时候别搞混。

#### 3.4.4 VAEEncodeForInpaint —— 掩码编码的细节

`nodes.py:417-455`。功能：把图像编码成 latent，同时产出"腐蚀后的掩码"作为 `noise_mask`。

```python
def encode(self, vae, pixels, mask, grow_mask_by=6):
    downscale_ratio = vae.spacial_compression_encode()
    x = (pixels.shape[1] // downscale_ratio) * downscale_ratio     # ① 对齐到 8 的倍数
    y = (pixels.shape[2] // downscale_ratio) * downscale_ratio
    mask = torch.nn.functional.interpolate(
        mask.reshape((-1, 1, mask.shape[-2], mask.shape[-1])),
        size=(pixels.shape[1], pixels.shape[2]), mode="bilinear")

    pixels = pixels.clone()
    if pixels.shape[1] != x or pixels.shape[2] != y:
        x_offset = (pixels.shape[1] % downscale_ratio) // 2        # ② 居中裁剪
        y_offset = (pixels.shape[2] % downscale_ratio) // 2
        pixels = pixels[:, x_offset:x + x_offset, y_offset:y + y_offset, :]
        mask    = mask[:, :, x_offset:x + x_offset, y_offset:y + y_offset]

    # ③ 掩码膨胀（grow），让潜空间里过渡更自然
    if grow_mask_by == 0:
        mask_erosion = mask
    else:
        kernel_tensor = torch.ones((1, 1, grow_mask_by, grow_mask_by))
        padding = math.ceil((grow_mask_by - 1) / 2)
        mask_erosion = torch.clamp(
            torch.nn.functional.conv2d(mask.round(), kernel_tensor, padding=padding), 0, 1)

    # ④ 掩码区外填充 0.5（灰色）
    m = (1.0 - mask.round()).squeeze(1)
    for i in range(3):
        pixels[:, :, :, i] -= 0.5
        pixels[:, :, :, i] *= m
        pixels[:, :, :, i] += 0.5
    t = vae.encode(pixels)

    return ({"samples": t, "noise_mask": (mask_erosion[:, :, :x, :y].round())}, )
```

四个技巧：

1. **尺寸对齐**：VAE 要求边长是 `compression`（8）的倍数，不是就裁。`//2` 的 offset 保证**居中裁剪**而不是从左上角裁。
2. **`grow_mask_by=6`**：用一个 6×6 全 1 卷积核做灰度膨胀，把掩码向外扩几个像素。注释写得很清楚——"keep things seamless in latent space"。因为潜空间一个像素 = 原图 8 像素，掩码边界在潜空间里很粗糙，不扩边会有明显接缝。
3. **外部填 0.5**：`pixels -= 0.5; pixels *= m; pixels += 0.5` 三步把掩码外区域变成中灰 0.5。为什么不是 0？因为 VAE 的潜空间分布大致以 0 为中心，纯黑/纯白都是分布外的极端值，中灰最接近"无信息"。
4. **返回 `noise_mask`**：下游 `SetLatentNoiseMask` 或直接进 KSampler 时，噪声只加在掩码区内。

#### 3.4.5 InpaintModelConditioning —— inpainting 专用装配

`nodes.py:458-507`。给**原生支持 inpainting 的模型**（如 SD1.5-inpaint，有 9 通道输入）用。

```python
def encode(self, positive, negative, pixels, vae, mask, noise_mask=True):
    # ① 对齐 + 居中裁剪
    x = (pixels.shape[1] // 8) * 8
    y = (pixels.shape[2] // 8) * 8
    mask = torch.nn.functional.interpolate(mask.reshape((-1, 1, mask.shape[-2], mask.shape[-2])),
                                           size=(pixels.shape[1], pixels.shape[2]), mode="bilinear")
    orig_pixels = pixels
    pixels = orig_pixels.clone()
    if pixels.shape[1] != x or pixels.shape[2] != y:
        x_offset = (pixels.shape[1] % 8) // 2
        y_offset = (pixels.shape[2] % 8) // 2
        pixels = pixels[:, x_offset:x + x_offset, y_offset:y + y_offset, :]
        mask    = mask[:, :, x_offset:x + x_offset, y_offset:y + y_offset]

    # ② 掩码外填灰
    m = (1.0 - mask.round()).squeeze(1)
    for i in range(3):
        pixels[:, :, :, i] -= 0.5
        pixels[:, :, :, i] *= m
        pixels[:, :, :, i] += 0.5

    concat_latent = vae.encode(pixels)      # ③ 被遮的图 → 作为额外输入通道
    orig_latent   = vae.encode(orig_pixels) # ④ 原图 → 作为待去噪的 latent

    out_latent = {}
    out_latent["samples"] = orig_latent
    if noise_mask:
        out_latent["noise_mask"] = mask

    out = []
    for conditioning in [positive, negative]:
        c = node_helpers.conditioning_set_values(conditioning, {
            "concat_latent_image": concat_latent,   # ← 采样时拼到输入通道上
            "concat_mask": mask})
        out.append(c)
    return (out[0], out[1], out_latent)
```

**核心机制**：`concat_latent_image` 会被采样器拼到模型输入的通道维上——SD1.5 正常是 4 通道，拼上 4 通道的 masked latent + 1 通道 mask = 9 通道，这正是 inpainting 模型训练时的输入格式。

`noise_mask` 参数的 tooltip 很诚实（`nodes.py:466`）：

> "Add a noise mask to the latent so sampling will only happen within the mask. Might improve results or completely break things depending on the model."

——对某些模型关掉反而更好。

输出三元组 `(positive, negative, latent)`，直接接 KSampler。

```python
def upscale(self, samples, upscale_method, width, height, crop):
    if width == 0 and height == 0:
        s = samples                       # 都为 0 → 原样返回
    else:
        s = samples.copy()
        if width == 0:                    # 只填一个 → 按宽高比推算另一个
            height = max(64, height)
            width = max(64, round(samples["samples"].shape[-1] * height / samples["samples"].shape[-2]))
        elif height == 0:
            width = max(64, width)
            height = max(64, round(samples["samples"].shape[-2] * width / samples["samples"].shape[-1]))
        else:
            width = max(64, width)
            height = max(64, height)

    return (s,)
```

**LatentComposite**（`nodes.py:1445-1487`）—— 把 source 贴到 destination 的 `(x, y)`：

```python
def composite(self, samples_to, samples_from, x, y, composite_method="normal", feather=0):
    x = x // 8; y = y // 8; feather = feather // 8       # 像素 → latent
    samples_out = samples_to.copy()
    s = samples_to["samples"].clone()                     # ← 必须 clone，否则改到上游
    samples_to = samples_to["samples"]
    samples_from = samples_from["samples"]
    if feather == 0:
        s[:, :, y:y+samples_from.shape[2], x:x+samples_from.shape[3]] = \
            samples_from[:, :, :samples_to.shape[2] - y, :samples_to.shape[3] - x]
    else:
        # 羽化：构造渐变 mask，边缘 ((1/feather) * (t+1)) 线性过渡
        samples_from = samples_from[:, :, :samples_to.shape[2] - y, :samples_to.shape[3] - x]
        mask = torch.ones_like(samples_from)
        for t in range(feather):
            if y != 0:
                mask[:, :, t:1+t, :] *= ((1.0/feather) * (t + 1))
            if y + samples_from.shape[2] < samples_to.shape[2]:
                mask[:, :, mask.shape[2]-1-t: mask.shape[2]-t, :] *= ((1.0/feather) * (t + 1))
            ...  # x 方向同理
        rev_mask = torch.ones_like(mask) - mask
        s[...] = samples_from[...] * mask + s[...] * rev_mask
    samples_out["samples"] = s
    return (samples_out,)
```

注意 `samples_to["samples"].clone()`：因为下面要做**原地赋值** `s[...] = ...`，不 clone 会直接改掉上游节点的输出（而上游输出可能被缓存并被其他地方引用）。这是写 latent 类节点最容易踩的坑。

**LatentCrop**（`nodes.py:1548`）里有一段保护：

```python

    x = samples.shape[3] - 8
if y > (samples.shape[2] - 8):
    y = samples.shape[2] - 8
```
保证裁出来至少有 1 个 latent 像素（8 个源像素），否则会得到空张量导致后面全崩。

#### 3.4.7 Latent 批次操作

**LatentFromBatch**（`nodes.py:1278-1312`）—— 从 batch 中取切片：

```python
def frombatch(self, samples, batch_index, length):
    s = samples.copy()
    s_in = samples["samples"]
    if batch_index < 0:
        batch_index += s_in.shape[0]                              # 支持负索引
    batch_index = max(0, min(s_in.shape[0] - 1, batch_index))      # 夹紧
    length = min(s_in.shape[0] - batch_index, length)
    s["samples"] = s_in[batch_index:batch_index + length].clone()
    if "noise_mask" in samples:
        masks = samples["noise_mask"]
        if masks.shape[0] == 1:
            s["noise_mask"] = masks.clone()                        # 单掩码共享给所有
        else:
            if masks.shape[0] < s_in.shape[0]:
                masks = masks.repeat(math.ceil(s_in.shape[0] / masks.shape[0]), 1, 1, 1)[:s_in.shape[0]]
            s["noise_mask"] = masks[batch_index:batch_index + length].clone()
    if "batch_index" not in s:
        s["batch_index"] = [x for x in range(batch_index, batch_index+length)]
    else:
        s["batch_index"] = samples["batch_index"][batch_index:batch_index + length]
    return (s,)
```

三个细节：负索引、夹紧防越界、`noise_mask` 单独处理（它可能只有 1 张却要服务整个 batch）。`batch_index` 键会一路传到采样器，决定噪声分配。

**RepeatLatentBatch**（`nodes.py:1327`）也有 `batch_index` 逻辑：

```python
if "batch_index" in s:
    offset = max(s["batch_index"]) - min(s["batch_index"]) + 1
    s["batch_index"] = s["batch_index"] + [x + (i * offset) for i in range(1, amount) for x in s["batch_index"]]
```

重复 N 次时给每份分配**不同的** index（偏移 `offset`），这样每张图噪声不同。如果不做这个，重复 4 次会得到 4 张一模一样的图。

#### 3.5.1 LoadImage —— 图像输入的全套处理

`nodes.py:1747-1821`。这是图像输入节点的完整范式，值得逐段读：

```python
@classmethod
def INPUT_TYPES(s):
    input_dir = folder_paths.get_input_directory()
    files = [f for f in os.listdir(input_dir) if os.path.isfile(os.path.join(input_dir, f))]
    files = folder_paths.filter_files_content_types(files, ["image"])    # ① 只留图片
    return {"required": {"image": (sorted(files), {"image_upload": True})}}

CATEGORY = "image"
ESSENTIALS_CATEGORY = "Basics"
RETURN_TYPES = ("IMAGE", "MASK")
FUNCTION = "load_image"

def load_image(self, image):
    image_path = folder_paths.get_annotated_filepath(image)

    dtype = comfy.model_management.intermediate_dtype()
    device = comfy.model_management.intermediate_device()

    # ② 优先走 pyav/视频管道（支持动图、webp、视频）
    components = InputImpl.VideoFromFile(image_path).get_components()
    if components.images.shape[0] > 0:
        return (components.images.to(device=device, dtype=dtype),
                (1.0 - components.alpha[..., -1]).to(device=device, dtype=dtype)
                if components.alpha is not None
                else torch.zeros((components.images.shape[0], 64, 64), dtype=dtype, device=device))

    # ③ 回退：PIL 处理（动画 webp 等 pyav 不支持的）
    img = node_helpers.pillow(Image.open, image_path)
    output_images, output_masks = [], []
    w, h = None, None
    for i in ImageSequence.Iterator(img):
        i = node_helpers.pillow(ImageOps.exif_transpose, i)   # ④ 处理 EXIF 方向
        image = i.convert("RGB")
        if len(output_images) == 0:
            w, h = image.size
        if image.size[0] != w or image.size[1] != h:           # ⑤ 尺寸不一致的帧跳过
            continue
        image = np.array(image).astype(np.float32) / 255.0
        image = torch.from_numpy(image)[None,]
        if 'A' in i.getbands():                                # ⑥ alpha → mask
            mask = np.array(i.getchannel('A')).astype(np.float32) / 255.0
            mask = 1. - torch.from_numpy(mask)
        else:
            mask = torch.zeros((64, 64), dtype=torch.float32, device="cpu")
        output_images.append(image.to(dtype=dtype))
        output_masks.append(mask.unsqueeze(0).to(dtype=dtype))

    output_image = torch.cat(output_images, dim=0)
    output_mask = torch.cat(output_masks, dim=0)
    return (output_image.to(device=device, dtype=dtype), output_mask.to(device=device, dtype=dtype))
```

六个要点：

1. `filter_files_content_types(files, ["image"])` 按扩展名过滤，避免把 `.latent`、`.txt` 也列出来。
2. **双通道解码**：先试 `InputImpl.VideoFromFile`（基于 pyav，能处理动图/视频/大部分格式），失败或返回空再回退 PIL。注释明确写了"animated webp which pyav does not support loading"。
3. **`node_helpers.pillow()`**（`node_helpers.py:55`）是一个容错包装：遇到 `OSError / UnidentifiedImageError / ValueError` 时临时打开 `ImageFile.LOAD_TRUNCATED_IMAGES = True` 重试，处理**截断的图片文件**。写完还要在 `finally` 里还原全局状态。
4. **EXIF 方向**：手机拍的照片靠 EXIF 标记旋转方向，`ImageOps.exif_transpose` 把它应用上。不处理的话竖拍照片会横着进来。
5. **尺寸不一致的帧跳过**：动图可能各帧尺寸不同，ComfyUI 的 IMAGE 要求 `[B,H,W,C]` 同尺寸，所以直接 `continue` 过滤掉。
6. **alpha → mask 且取反**：`(1.0 - alpha)`。因为 ComfyUI 的 mask 约定是 **1.0 = 要处理的区域**，而 alpha 是 **1.0 = 不透明**。没有 alpha 时给一个 64×64 的零掩码占位（而不是空张量，避免下游 shape 出错）。

`IS_CHANGED` 用文件 sha256，`VALIDATE_INPUTS` 检查路径存在——和 `LoadLatent` 一致。

```python
if feathering > 0 and feathering * 2 < d2 and feathering * 2 < d3:
    for i in range(d2):
        for j in range(d3):
            dt = i if top != 0 else d2                     # 只在真的扩了的边算羽化
            db = d2 - i if bottom != 0 else d2
            dl = j if left != 0 else d3
            dr = d3 - j if right != 0 else d3
            d = min(dt, db, dl, dr)                        # 到最近边（被扩的边）的距离

                continue
            v = (feathering - d) / feathering
            t[i, j] = v * v                                # 平方 → 更柔和的渐变
mask[top:top + d2, left:left + d3] = t
return (new_image, mask.unsqueeze(0))
```

**LatentInterpolate 的球面插值**（`nodes_latent.py:114-134`）—— 这是最值得学的一个：

```python
m1 = torch.linalg.vector_norm(s1, dim=(1))       # 每个样本的方向模长
m2 = torch.linalg.vector_norm(s2, dim=(1))

s1 = torch.nan_to_num(s1 / m1)                    # 归一化到单位方向
s2 = torch.nan_to_num(s2 / m2)

t = (s1 * ratio + s2 * (1.0 - ratio))             # 在单位球面上插值
mt = torch.linalg.vector_norm(t, dim=(1))
st = torch.nan_to_num(t / mt)                     # 再归一化回球面

samples_out["samples"] = st * (m1 * ratio + m2 * (1.0 - ratio))   # 模长单独线性插值
```

**为什么要这么绕**：潜空间里"直接线性插值两个 latent"会让中间结果的范数偏小（两个向量夹角越大越明显），表现为中间帧变暗/变糊。这里做的是 **slerp（球面线性插值）**：方向走球面弧线、模长走直线。做 latent 渐变动画时用它比 `LatentBlend` 好得多。

`torch.nan_to_num` 是防除零（全零 latent 的模长为 0）。

**LatentApplyOperation / LatentOperation\*** —— 一个很有意思的"高阶函数"设计：

```python
# 产生一个 operation（闭包）
class LatentOperationSharpen(io.ComfyNode):
    def execute(cls, sharpen_radius, sigma, alpha) -> io.NodeOutput:
        def sharpen(latent, **kwargs):
            luminance = (torch.linalg.vector_norm(latent, dim=(1)) + 1e-6)[:,None]
            normalized_latent = latent / luminance
            channels = latent.shape[1]
            kernel_size = sharpen_radius * 2 + 1
            kernel = comfy_extras.nodes_post_processing.gaussian_kernel(kernel_size, sigma, device=luminance.device)
            center = kernel_size // 2
            kernel *= alpha * -10
            kernel[center, center] = kernel[center, center] - kernel.sum() + 1.0   # ← 构造 unsharp mask
            padded_image = torch.nn.functional.pad(normalized_latent, (r,r,r,r), 'reflect')
            sharpened = torch.nn.functional.conv2d(padded_image, kernel.repeat(channels,1,1).unsqueeze(1),
                                                   padding=kernel_size//2, groups=channels)[:,:,r:-r, r:-r]
            return luminance * sharpened
        return io.NodeOutput(sharpen)      # ← 返回一个函数！
```

`LATENT_OPERATION` 类型的节点**返回一个可调用对象**，再由 `LatentApplyOperation` 施加到 latent 上。好处：operation 可以被复用、串联、也可以在 CFG 阶段施加（`LatentApplyOperationCFG`）：

```python
class LatentApplyOperationCFG(io.ComfyNode):
    def execute(cls, model, operation) -> io.NodeOutput:
        m = model.clone()
        def pre_cfg_function(args):
            conds_out = args["conds_out"]
            if len(conds_out) == 2:
                # 只对"正 - 负"的差值部分施加操作，再补回负向
                conds_out[0] = operation(latent=(conds_out[0] - conds_out[1])) + conds_out[1]
            else:
                conds_out[0] = operation(latent=conds_out[0])
            return conds_out
        m.set_model_sampler_pre_cfg_function(pre_cfg_function)
        return io.NodeOutput(m)
```

**"只锐化 CFG 差值部分"** 是锐化的正确做法——直接锐化完整预测会把负向提示词的噪声也放大。

#### 4.2.1 SIGMAS：噪声时间表

`SIGMAS` 是一个 1D 递减张量，长度 `steps + 1`（多一个终点 0）。

**BasicScheduler**（`nodes_custom_sampler.py:17-42`）：

```python
def execute(cls, model, scheduler, steps, denoise) -> io.NodeOutput:
    total_steps = steps
    if denoise < 1.0:
        if denoise <= 0.0:
            return io.NodeOutput(torch.FloatTensor([]))     # denoise=0 → 空时间表
        total_steps = int(steps/denoise)

    sigmas = comfy.samplers.calculate_sigmas(
        model.get_model_object("model_sampling"), scheduler, total_steps).cpu()
    sigmas = sigmas[-(steps + 1):]                          # ← 取尾部 steps+1 个
    return io.NodeOutput(sigmas)
```

**`denoise < 1` 的实现方式很巧妙**：先按 `steps/denoise` 生成一条**更长**的完整时间表，再截取尾部 `steps+1` 个。这样得到的是"从中间某个 sigma 开始下降到 0"的一段——正是图生图需要的。

注意它要 `model` 输入：因为 sigma 的取值范围（sigma_max / sigma_min）由模型的 `model_sampling` 对象决定，不同模型族（SD vs Flow vs Cosmos）完全不同。

**不依赖 model 的调度器**：`KarrasScheduler` / `ExponentialScheduler` / `PolyexponentialScheduler` / `LaplaceScheduler` / `VPScheduler` 直接调 k-diffusion 的函数，手工给 `sigma_max` / `sigma_min` / `rho`。适合你想脱离模型默认范围自定义时。

| `SplitSigmasDenoise` | 按 denoise 比例切分 |
| `FlipSigmas` | 反转（做反向采样 / 反向编辑） |
| `SetFirstSigma` | 改起始 sigma（控制初始噪声强度） |

#### 4.2.2 SAMPLER：采样算法

最简单的 `KSamplerSelect`（`nodes_custom_sampler.py:379-394`）：

带参数的采样器则构造"已绑定参数的采样器"：

```python
class SamplerDPMPP_2M_SDE(io.ComfyNode):
    def execute(cls, solver_type, eta, s_noise, noise_device) -> io.NodeOutput:
        if noise_device == 'cpu':
            sampler_name = "dpmpp_2m_sde"
        else:
            sampler_name = "dpmpp_2m_sde_gpu"
        sampler = comfy.samplers.ksampler(sampler_name, {"eta": eta, "s_noise": s_noise, "solver_type": solver_type})
        return io.NodeOutput(sampler)
```

```python
def predict_noise(self, x, timestep, model_options={}, seed=None):
    negative_cond = self.conds.get("negative", None)
    middle_cond   = self.conds.get("middle", None)
    positive_cond = self.conds.get("positive", None)

    if self.nested:
        out = calc_cond_batch(self.inner_model, [negative_cond, middle_cond, positive_cond], x, timestep, model_options)
        pred_text = cfg_function(self.inner_model, out[2], out[1], self.cfg1, x, timestep, ..., cond=positive_cond, uncond=middle_cond)
        return out[0] + self.cfg2 * (pred_text - out[0])
    else:
        if model_options.get("disable_cfg1_optimization", False) == False:
            if math.isclose(self.cfg2, 1.0):
                negative_cond = None                      # ← cfg=1 时跳过该分支！
                if math.isclose(self.cfg1, 1.0):
                    middle_cond = None
        out = calc_cond_batch(self.inner_model, [negative_cond, middle_cond, positive_cond], x, timestep, model_options)
        return cfg_function(self.inner_model, out[1], out[0], self.cfg2, ...) + (out[2] - out[1]) * self.cfg1
```

**`math.isclose(cfg, 1.0)` 时把分支置 None 是重要的性能优化**：CFG=1 意味着该项贡献为 0，干脆不算，省掉一次完整的前向传播。

### 4.3 掩码（nodes_mask.py）

14 个节点。文件开头有一个通用的 `composite()` 函数（`nodes_mask.py:12-47`），被 `LatentCompositeMasked` 和 `ImageCompositeMasked` 共用，差别只在 `multiplier` 参数（latent 用 8、image 用 1）和通道维度顺序：

```python
def composite(destination, source, x, y, mask=None, multiplier=8, resize_source=False):
    source = source.to(destination.device)
    if resize_source:
        source = torch.nn.functional.interpolate(source, size=(destination.shape[-2], destination.shape[-1]), mode="bilinear")
    source = comfy.utils.repeat_to_batch_size(source, destination.shape[0])

    x = max(-source.shape[-1] * multiplier, min(x, destination.shape[-1] * multiplier))
    y = max(-source.shape[-2] * multiplier, min(y, destination.shape[-2] * multiplier))
    left, top = (x // multiplier, y // multiplier)
    ...
    # 只处理与 destination 重叠的部分（防越界写入）
    visible_width, visible_height = (destination.shape[-1] - left + min(0, x),
                                     destination.shape[-2] - top  + min(0, y))
    mask = mask[:, :, :visible_height, :visible_width]
    ...
    destination[..., top:bottom, left:right] = source_portion + destination_portion
    return destination
```

`ImageCompositeMasked` 侧的适配（`nodes_mask.py:99-104`）：

**GrowMask**（`nodes_mask.py:367-384`）用 scipy 的灰度形态学：

```python
c = 0 if tapered_corners else 1
kernel = np.array([[c, 1, c],
                   [1, 1, 1],
                   [c, 1, c]])
for m in mask:
    output = m.numpy()
    for _ in range(abs(expand)):
        if expand < 0:
            output = scipy.ndimage.grey_erosion(output, footprint=kernel)    # 收缩
        else:
            output = scipy.ndimage.grey_dilation(output, footprint=kernel)   # 膨胀
```

`tapered_corners=True` 时核的四角是 0 → 膨胀出来是**圆角**；`False` 时是方形。`expand` 可为负（腐蚀）。逐帧循环（`for m in mask`）所以支持 batch。

**为什么用灰度形态学而不是二值**：掩码边缘可能是 0~1 的软过渡，灰度膨胀能保留软边，二值操作会让边缘变硬。

```python
    def calculate_denoised(self, sigma, model_output, model_input):
        timestep = self.timestep(sigma).view(sigma.shape[:1] + (1,) * (model_output.ndim - 1))
        sigma = sigma.view(sigma.shape[:1] + (1,) * (model_output.ndim - 1))
        x0 = model_input - model_output * sigma

        sigma_data = 0.5
        scaled_timestep = timestep * 10.0          # timestep_scaling

        c_skip = sigma_data**2 / (scaled_timestep**2 + sigma_data**2)
```

#### 4.4.2 RescaleCFG —— 一个教科书级的 CFG 补丁

`nodes_model_advanced.py:276-330`。它同时处理了 **v-prediction（eps 系）** 和 **flow matching（CONST 系）** 两种模型：

```python
def patch(self, model, multiplier):
    model_sampling = model.get_model_object("model_sampling")
    is_flow = isinstance(model_sampling, comfy.model_sampling.CONST)   # ← 分支判定

    def rescale_cfg(args):
        x_orig = args["input"]
        cond_scale = args["cond_scale"]

        if is_flow:
            # Flow-matching：cond_denoised/uncond_denoised 是 x_0 估计，
            # 不能走下面的 eps↔v 转换，直接在 x_0 空间 rescale
            x_0_cond   = args["cond_denoised"]
            x_0_uncond = args["uncond_denoised"]
            x_0_cfg = x_0_uncond + cond_scale * (x_0_cond - x_0_uncond)
            dims = tuple(range(1, x_0_cond.ndim))
            ro_pos = x_0_cond.std(dim=dims, keepdim=True)
            ro_cfg = x_0_cfg.std(dim=dims, keepdim=True).clamp(min=1e-8)
            x_0_rescaled = x_0_cfg * (ro_pos / ro_cfg)
            x_0_final = multiplier * x_0_rescaled + (1.0 - multiplier) * x_0_cfg
            return x_orig - x_0_final

        # ---- 以下是 eps / v-prediction 分支 ----
        cond   = args["cond"]
        uncond = args["uncond"]
        sigma  = args["sigma"]
        sigma = sigma.view(sigma.shape[:1] + (1,) * (cond.ndim - 1))

        # rescale cfg 必须在 v-pred 空间做
        x = x_orig / (sigma * sigma + 1.0)
        cond   = ((x - (x_orig - cond))   * (sigma ** 2 + 1.0) ** 0.5) / (sigma)
        uncond = ((x - (x_orig - uncond)) * (sigma ** 2 + 1.0) ** 0.5) / (sigma)

        x_cfg = uncond + cond_scale * (cond - uncond)          # 标准 CFG
        ro_pos = torch.std(cond,   dim=(1,2,3), keepdim=True)  # 正向标准差
        ro_cfg = torch.std(x_cfg,  dim=(1,2,3), keepdim=True)  # CFG 后标准差

        x_rescaled = x_cfg * (ro_pos / ro_cfg)                 # 把 std 拉回正向水平
        x_final = multiplier * x_rescaled + (1.0 - multiplier) * x_cfg

        return x_orig - (x - x_final * sigma / (sigma * sigma + 1.0) ** 0.5)

    m = model.clone()
    m.set_model_sampler_cfg_function(rescale_cfg)
    return (m, )
```

**解决什么问题**：CFG 会放大输出的标准差，cfg 越大图越"过曝/过饱和"。RescaleCFG 把 CFG 结果的标准差重新拉回正向分支的水平，`multiplier` 控制拉回多少（1.0 完全拉回，0.0 不处理）。

**`dims = tuple(range(1, x_0_cond.ndim))`** 而不是硬编码 `(1,2,3)`：因为视频 latent 是 5 维的。这种写法同时兼容图像和视频。

#### 4.4.3 CFG 家族（nodes_cfg.py）

`CFGZeroStar`（`nodes_cfg.py:24-49`）实现 CFG-Zero* 论文的方法：

```python
def optimized_scale(positive, negative):
    positive_flat = positive.reshape(positive.shape[0], -1)
    negative_flat = negative.reshape(negative.shape[0], -1)
    dot_product  = torch.sum(positive_flat * negative_flat, dim=1, keepdim=True)
    squared_norm = torch.sum(negative_flat ** 2, dim=1, keepdim=True) + 1e-8
    # st_star = v_cond^T * v_uncond / ||v_uncond||^2
    st_star = dot_product / squared_norm
    return st_star.reshape([positive.shape[0]] + [1] * (positive.ndim - 1))

def cfg_zero_star(args):
    guidance_scale = args['cond_scale']
    x = args['input']
    cond_p   = args['cond_denoised']
    uncond_p = args['uncond_denoised']
    out      = args["denoised"]
    alpha = optimized_scale(x - cond_p, x - uncond_p)     # 最优投影系数
    return out + uncond_p * (alpha - 1.0) + guidance_scale * uncond_p * (1.0 - alpha)
```

核心思想：**在高噪声阶段（st_star 接近 1）自动抑制 CFG**，因为早期 CFG 只会把图推向崩坏。

`CFGNorm`（`nodes_cfg.py:51-109`）有两种模式，通过 `pre_cfg` 开关切换：
- `pre_cfg=False`（默认）：`post_cfg_function`，在 x0 空间把模长**衰减**到不超过正向（`clamp(max=1.0)`，只减不增）
- `pre_cfg=True`：`cfg_function`，在噪声空间缩放（`cond_norm / comb_norm`，**可放大**，匹配 Lens 等模型）

`args` 字典的可用键（由 `comfy/samplers.py` 传入）：

| 键 | 含义 |
|---|---|
| `input` | 当前带噪 latent `x` |
| `cond` / `uncond` | 原始模型输出（噪声预测空间） |
| `cond_denoised` / `uncond_denoised` | 各自的去噪结果（x0 空间） |
| `denoised` | CFG 合成后的结果 |
| `cond_scale` | 当前 cfg 值 |
| `sigma` | 当前 sigma |

**HyperTile 的实现**（`nodes_hypertile.py:44-86`）展示了"attn1 patch 对"的用法：

```python
def hypertile_in(q, k, v, extra_options):
    nonlocal temp
    model_chans = q.shape[-2]
    orig_shape = extra_options['original_shape']
    apply_to = []
    for i in range(max_depth + 1):
        apply_to.append((orig_shape[-2] / (2 ** i)) * (orig_shape[-1] / (2 ** i)))

    if model_chans in apply_to:
        shape = extra_options["original_shape"]
        aspect_ratio = shape[-1] / shape[-2]
        hw = q.size(1)
        h, w = round(math.sqrt(hw * aspect_ratio)), round(math.sqrt(hw / aspect_ratio))
        factor = (2 ** apply_to.index(model_chans)) if scale_depth else 1
        nh = random_divisor(h, latent_tile_size * factor, swap_size)
        nw = random_divisor(w, latent_tile_size * factor, swap_size)
        if nh * nw > 1:
            q = rearrange(q, "b (nh h nw w) c -> (b nh nw) (h w) c", h=h//nh, w=w//nw, nh=nh, nw=nw)
            temp = (nh, nw, h, w)
        return q, k, v
    return q, k, v

def hypertile_out(out, extra_options):
    nonlocal temp
    if temp is not None:
        nh, nw, h, w = temp
        temp = None
        out = rearrange(out, "(b nh nw) hw c -> b nh nw hw c", nh=nh, nw=nw)
        out = rearrange(out, "b nh nw (h w) c -> b (nh h nw w) c", h=h//nh, w=w//nw)
    return out

m = model.clone()
m.set_model_attn1_patch(hypertile_in)
m.set_model_attn1_output_patch(hypertile_out)
```

**`in` patch 把 q 重排成"分块 batch"，`out` patch 再拼回去**。用 `nonlocal temp` 在两个回调间传递形状信息——因为这两个 hook 是成对的。这是理解 `set_model_attn1_patch` / `set_model_attn1_output_patch` 成对使用的最佳例子。

### 4.8 模型放大（nodes_upscale_model.py）

`ImageUpscaleWithModel`（`nodes_upscale_model.py:53-111`）有两个值得学的工程细节。

**① 显存估算**（`nodes_upscale_model.py:79`）：


`384.0` 是作者注释里承认的"经验估计值"（`TODO: make it more accurate`）。**估算而非精确计算**，然后交给 `load_models_gpu` 决定要不要卸载别的模型。

**② OOM 自动降 tile**（`nodes_upscale_model.py:90-101`）：

```python
oom = True
while oom:
    try:
        steps = in_img.shape[0] * comfy.utils.get_tiled_scale_steps(...)
        pbar = comfy.utils.ProgressBar(steps)
        s = comfy.utils.tiled_scale(in_img, lambda a: upscale_model(a.float()),
                                    tile_x=tile, tile_y=tile, overlap=overlap,
                                    upscale_amount=upscale_model.scale, pbar=pbar, output_device=output_device)
        oom = False
    except Exception as e:
        model_management.raise_non_oom(e)     # ← 非 OOM 异常直接抛出，不重试
        tile //= 2                            # ← OOM：tile 减半重试
        if tile < 128:
            raise e
```

**`raise_non_oom(e)` 是关键**：只有真的是显存不足才降 tile 重试，其它异常（模型格式错、维度不匹配）立刻抛出，避免死循环或掩盖真实错误。这是写健壮 GPU 代码的标准模式。

`UpscaleModelLoader` 用 spandrel 自动识别架构：

```python
out = ModelLoader().load_from_state_dict(sd).eval()
if not isinstance(out, ImageModelDescriptor):
    raise Exception("Upscale model must be a single-image model.")
out.patcher = comfy.model_patcher.CoreModelPatcher(out.model, ...)
```

还会尝试注册 `spandrel_extra_arches`（非商用放大模型架构，`nodes_upscale_model.py:13-19`），失败就静默跳过（`except: pass`）。

```
EmptyLatentImage ─► KSampler(steps=20, denoise=1.0)
   ─► LatentUpscaleBy(scale_by=1.5, method="bicubic")
   ─► KSampler(steps=15, denoise=0.55)     ← 二次采样，低 denoise 保结构
   ─► VAEDecode ─► SaveImage
```

或走像素空间（质量更好、更慢）：

```
KSampler ─► VAEDecode ─► UpscaleModelLoader + ImageUpscaleWithModel
   ─► VAEEncode ─► KSampler(denoise=0.4~0.5) ─► VAEDecode ─► SaveImage
```

### 5.4 LoRA 叠加

```
CheckpointLoaderSimple ─► LoraLoader(lora_A, 0.8/0.8) ─► LoraLoader(lora_B, 0.6/0.6) ─► KSampler
                                    ↑ clip 也一起串
```

### 5.5 ControlNet

```
ControlNetLoader ─► ControlNetApplyAdvanced(positive, negative, image=预处理器输出)
                        ├─ positive ─► KSampler.positive
                        └─ negative ─► KSampler.negative
```

预处理器：`Canny`（`nodes_canny.py`）、`Depth`（`nodes_moge.py` / `nodes_depth_anything_3.py`）、`Pose`（`nodes_sdpose.py` / `nodes_mediapipe.py`）等。

### 5.6 区域提示词

```
CLIPTextEncode("a cat")  ─► ConditioningSetArea(x=0,   y=0, width=512, height=1024) ─┐
CLIPTextEncode("a dog")  ─► ConditioningSetArea(x=512, y=0, width=512, height=1024) ─┤
                                                                                     ├─► ConditioningCombine ─► KSampler.positive
（负向单独一条）                                                                     ┘
```

### 5.7 自定义采样（SamplerCustomAdvanced）

```
CheckpointLoaderSimple.model ─┬─► BasicScheduler(steps=20) ─► SIGMAS
                              ├─► CFGGuider(positive, negative, cfg=8) ─► GUIDER
RandomNoise(seed=42) ─────────► NOISE
KSamplerSelect("euler_ancestral") ─► SAMPLER
EmptyLatentImage ─► LATENT
        ↓
SamplerCustomAdvanced ─► VAEDecode ─► SaveImage
```

**想加"前 50% 步 cfg=3、后 50% cfg=8"**：`SplitSigmas` 切成两段，各配一个 `CFGGuider`，跑两个 `SamplerCustomAdvanced` 串联。

### 5.8 inpainting

```
LoadImage ─┬─► VAEEncodeForInpaint(mask) ─► KSampler.latent_image
           └─► InpaintModelConditioning(positive, negative, vae, pixels, mask)
                     ├─ positive ─► KSampler.positive
                     ├─ negative ─► KSampler.negative
                     └─ latent   ─► KSampler.latent_image
```

用**普通模型**（非 inpainting 模型）时用 `VAEEncodeForInpaint` + `SetLatentNoiseMask`；用 **inpainting 专用模型**时用 `InpaintModelConditioning`。

```python
from typing_extensions import override
from comfy_api.latest import ComfyExtension, io

class MyNode(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="MyNode",                      # 加前缀避免与内置冲突
            display_name="My Node",
            category="MyCategory/Sub",
            description="一句话说明这个节点做什么。",
            search_aliases=["别名1", "alias2"],
            inputs=[
                io.Image.Input("image"),
                io.Float.Input("strength", default=1.0, min=0.0, max=10.0, step=0.01),
                io.Mask.Input("mask", optional=True),
            ],
            outputs=[io.Image.Output()],
        )

    @classmethod
    def execute(cls, image, strength, mask=None) -> io.NodeOutput:
        out = image.clone()                        # 不要原地改输入！
        if mask is not None:
            m = mask.reshape((-1, 1, mask.shape[-2], mask.shape[-1]))
            m = torch.nn.functional.interpolate(m, size=(out.shape[1], out.shape[2]), mode="bilinear")
            out = out * (1 - m) + out * strength * m
        else:
            out = out * strength
        return io.NodeOutput(out)

class MyExtension(ComfyExtension):
    @override
    async def get_node_list(self) -> list[type[io.ComfyNode]]:
        return [MyNode]

async def comfy_entrypoint() -> MyExtension:
    return MyExtension()
```

### 6.4 本项目代码规范（来自 AGENTS.md，写节点时务必遵守）

1. **改动最小化** —— 只碰必要的代码路径，别顺手重构。
2. **不加新依赖** —— 除非绝对必要。
3. **删掉死代码** —— 不留兼容分支、debug print、未使用的选项。
4. **不要 `torch.no_grad()` / `torch.inference_mode()`** —— ComfyUI 全程视为推理，加了反而有害。
5. **不要给模型类加 freeze/unfreeze**。
6. **不要直接 patch 模型** —— 走 `ModelPatcher` 的 clone + patch 接口。
7. **模型类节点必须 `model.clone()`**，不要改传入对象。
8. **不要原地修改输入的张量** —— 先 `.clone()`。
9. **核心 ComfyUI 不做任何联网请求** —— 不加遥测、更新检查、远程配置。
10. **前端传来的文件名要二次校验**（`VALIDATE_INPUTS` + `folder_paths.exists_annotated_filepath`）。
11. **Combo 值涉及文件系统访问时必须再验证一次**。
12. **不要输出不属于本节点的值**（不加 pass-through 输出）。
13. **张量形状约定**：`IMAGE` 是 `[B,H,W,C]`，`common_upscale` 要 `[B,C,H,W]`，用 `movedim(-1,1)` / `movedim(1,-1)` 转换。
14. **尺寸参数**：界面上是像素，Latent 侧要 `// 8`（或用 `vae.spacial_compression_decode()`）。
15. **设备与精度**：用 `comfy.model_management.intermediate_device()` / `intermediate_dtype()`，不写死 `.cuda()`。
16. **import 放模块顶层**，不要函数内 import（除非解决循环依赖）。
17. **不加无谓的 try/except**。

## 第 7 章 排错清单与最佳实践

### 7.1 常见问题

| 现象 | 原因 / 排查 |
|---|---|
| 节点没出现在搜索里 | ① 文件名没加进 `nodes.py:2420` 的清单（仅 comfy_extras）② `comfy_entrypoint()` 没写或没返回 Extension ③ 节点 ID 与核心 65 个重名（被 `ignore` 静默丢弃） |
| 报错 "clip input is invalid: None" | 用了纯 unet checkpoint 或没接 CLIP。换 `UNETLoader` + 单独 CLIP |
| 生成图全黑 | `--fp16-vae`；试 `--fp32-vae` 或 `--force-upcast-attention` |
| 显存不足 | `--reserve-vram` / `--cache-none` / `--novram` / `--cpu-vae`；VAE 用 Tiled 版；模型用 fp8 |
| 改了图但没重新执行 | `IS_CHANGED` 没变（文件类节点用 sha256） |
| 下游节点被跑了 N 次 | 上游输出是 batch（B>1），引擎按最大长度展开 |
| 改 latent 把上游也改了 | 原地赋值前没 `.clone()` |
| 大图 VAE 崩 | 用 `VAEDecodeTiled`，注意 `tile_size` 单位是像素、内部会 `// compression` |
| 换模型后 `EmptyLatentImage` 通道不对 | 正常，`common_ksampler` 里的 `fix_empty_latent_channels` 会修正 |
| 同名节点被忽略 | 核心节点先注册，后加载的同名节点进 `ignore` |

### 7.2 参数速查

| 场景 | 建议 |
|---|---|
| 文生图步数 | SD1.5/SDXL 20-30；Flux 20-30；Turbo/LCM 4-8 |
| CFG | SD1.5 7-8；SDXL 5-7；Flux 1.0-3.5（用 `FluxGuidance`） |
| 采样器 | 通用 `euler` + `normal`；要细节 `dpmpp_2m` + `karras` |
| 图生图 denoise | 0.5-0.75（想保结构取低值） |
| Tiled VAE | `tile_size` 512-1024，`overlap` ≥ 64 |
| 放大 | 潜空间 `LatentUpscaleBy` 快；像素空间 `ImageUpscaleWithModel` 质量好 |

### 7.3 调试技巧

1. `PreviewAny`（`nodes_preview_any.py`）预览任意类型的值。
2. `MaskPreview` / `PreviewImage` 中途插桩。
3. `LoraLoaderBypass`（`nodes_lora_debug.py`）快速 A/B 对比 LoRA 效果。
4. `GET /object_info/<node_id>` 看节点真实 schema。
5. 启动日志里的 "Import times for custom nodes" 能看出哪个节点导入慢 / 失败。

### B.3 张量形状与换算速查

| 操作 | 公式 |
|---|---|
| 像素 → latent | `// 8`（或 `// vae.spacial_compression_decode()`） |
| IMAGE 内部布局 | `[B, H, W, C]`，值域 `[0, 1]` |
| 调 `common_upscale` 前 | `image.movedim(-1, 1)` → `[B, C, H, W]` |
| 调 `common_upscale` 后 | `.movedim(1, -1)` → 转回 `[B, H, W, C]` |
| MASK 统一 3 维 | `mask.reshape((-1, mask.shape[-2], mask.shape[-1]))` |
| MASK→4 维（插值时） | `mask.reshape((-1, 1, H, W))` |
| MASK 语义 | `1.0` = 要处理的区域；alpha 是 `1.0` = 不透明，所以 `mask = 1 - alpha` |
| SIGMAS 长度 | `steps + 1` |
