## 0. 你将做出什么

一个 `ComfyUI-SamplerLab` 自定义节点包，包含 5 个可运行的节点：

| 节点 ID | 类型角色 | 干什么 |
|---|---|---|
| `PK_BlueNoise` | **Noise** | 生成带高频偏置的噪声（蓝噪声近似），替代默认随机噪声 |
| `PK_CustomSigmas` | **Sigmas** | 用任意 scheduler 算 sigma 表，并做 gamma 重排改变步长分布 |
| `PK_ScheduledCFG` | **Guider** | CFG 随去噪进度从 `cfg_min` 线性过渡到 `cfg_max` |
| `PK_EulerSampler` | **Sampler** | 用 `k_diffusion.sample_euler` 包一个自定义采样器 |
| `PK_SamplerCustom` | 组装节点 | 把上述组件串起来，等价于自带 `SamplerCustom` |

学完你会彻底理解：**一次去噪 = Noise + Sigmas + Guider(CFG) + Sampler(迭代更新)** 四件套，以及它们如何在 `comfy.sample.sample_custom` 里被组装。

## 1. 采样管线里这几个组件各自扮演什么角色

ComfyUI 的采样不是一个黑盒，而是四个可独立替换的对象。看 `comfy/samplers.py` 的 `CFGGuider.outer_sample` → `inner_sample`，以及 `comfy/sample.py:86` 的 `sample_custom`：

```
KSampler 节点 (如 PK_SamplerCustom)
   │
   ├─ Noise.generate_noise(latent)        → 初始噪声张量 [B,4,H,W]
   ├─ Sigmas (一个 1D 张量, 长度 steps+1)  → 每步的噪声水平 sigma
   ├─ Guider (CFGGuider 子类)             → 把 positive/negative 合成一步的去噪预测
   └─ Sampler.sample(...)                 → 按 sigmas 一步步更新 latent
```

对应到代码（`comfy/sample.py:86`）：

```python
def sample_custom(model, noise, cfg, sampler, sigmas, positive, negative, latent_image,
                  noise_mask=None, callback=None, disable_pbar=False, seed=None):
    samples = comfy.samplers.sample(model, noise, positive, negative, cfg,
                                    model.load_device, sampler, sigmas, ...)  # 内部用 Guider 包装
```

**四个组件的职责边界**（务必分清，后面写节点才不会乱）：

| 组件 | 输入 | 输出 | 你通常要实现的接口 |
|---|---|---|---|
| **Noise** | `latent` 字典 | 噪声张量 `[B,C,H,W]` | `generate_noise(self, input_latent) -> Tensor` |
| **Sigmas** | —— | `Tensor[steps+1]`（含首尾） | 直接返回张量即可，**不是一个类** |
| **Guider** | 模型 + 正/负条件 | 一步去噪预测 | 继承 `comfy.samplers.CFGGuider`，重写 `predict_noise` |
| **Sampler** | 模型包装、`sigmas`、`noise` | 去噪后的 latent | 继承 `comfy.samplers.Sampler`，重写 `sample` |

> ⚠️ **Sigmas 不是类，只是个张量。** 节点 `RETURN_TYPES` 里它叫 `SIGMAS`，值就是一个 `torch.Tensor`。很多初学者误以为要实现某个接口，其实返回一个 1D 张量就行。

```python
# comfy/samplers.py:592 —— 标准 CFG 合成（Guider 内部用它）

                                 model_options={}, seed=None) -> torch.Tensor

# comfy/k_diffusion/sampling.py:190 —— 现成的采样函数，可直接复用
comfy.k_diffusion.sampling.sample_euler(model, x, sigmas, extra_args=None,
                                         callback=None, disable=None, ...) -> torch.Tensor
```

**`model_wrap` / `inner_model` 是什么？** `Guider` 把 `model_patcher` 包成一个可调用对象，传入 Sampler 时叫 `model_wrap`。你几乎永远不需要手动构造它——`sample_custom` 会替你做。`model_wrap(x, sigma, model_options=...)` 就等价于"在 sigma 处对 x 做一次模型预测"。

**`model_sampling` 是什么？** `model.get_model_object("model_sampling")` 返回负责 sigma 与噪声缩放的模块；`calculate_sigmas` 需要它。

## 4. `PK_BlueNoise` —— 自定义噪声（Noise 组件）

### 4.1 原理

默认噪声是纯高斯白噪声（`comfy.sample.prepare_noise`）。蓝噪声在低频能量低、高频能量高，视觉上更"颗粒均匀"。这里用一个朴素近似：**白噪声减去它的模糊版本 = 高通（偏蓝），再加回一点**。这足以演示 `Noise` 接口，也确实改变了噪声频谱。

### 4.2 完整代码

```python
import math
import torch
import comfy.sample
import comfy.utils
from comfy_api.latest import io


class _BlueNoise:
    """噪声生成器对象，必须实现 generate_noise(input_latent) -> Tensor。"""
    def __init__(self, seed: int, blue_strength: float = 0.3):
        self.seed = seed
        self.blue_strength = blue_strength

    def generate_noise(self, input_latent: dict) -> torch.Tensor:
        latent = input_latent["samples"]                       # [B, C, H, W]
        batch_inds = input_latent.get("batch_index", None)
        # 先拿一份标准随机噪声（prepare_noise 会按 seed 确定性生成）
        noise = comfy.sample.prepare_noise(latent, self.seed, batch_inds)

        # 仅在空间尺寸足够时做高通近似
        if noise.shape[-1] > 3 and noise.shape[-2] > 3:
            blurred = torch.nn.functional.avg_pool2d(noise, 3, stride=1, padding=1)
            high_pass = noise - blurred                          # 偏蓝分量
            noise = noise + self.blue_strength * high_pass

        # 保持数值范围大致在白噪声量级（经验缩放，非必须）
        noise = noise / (1.0 + self.blue_strength * 0.5)
        return noise


class PK_BlueNoise(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="PK_BlueNoise",
            display_name="PK Blue Noise",
            category="PK/sampling/noise",
            description="Generate blue-ish noise by high-pass filtering white noise.",
            inputs=[
                io.Int.Input("noise_seed", default=0, min=0, max=0xffffffffffffffff,
                             control_after_generate=True),
                io.Float.Input("blue_strength", default=0.3, min=0.0, max=1.0, step=0.05,
                               round=0.01, advanced=True),
            ],
            outputs=[io.Noise.Output()],
        )

    @classmethod
    def execute(cls, noise_seed: int, blue_strength: float) -> io.NodeOutput:
        return io.NodeOutput(_BlueNoise(noise_seed, blue_strength))
```

### 4.3 要点

- **Noise 节点返回的是一个对象**（含 `generate_noise`），不是张量。该对象会在 `sample_custom` 里、拿到真实 `latent` 尺寸后才被调用。这就是为什么接口拿的是 `input_latent` 而不是 `shape`——尺寸要等运行时才知道。
- `control_after_generate=True` 让前端在每次生成后自动给 `noise_seed` 换一个新随机值。
- 不要在这里 `torch.randn` 后就完事——必须和 `prepare_noise` 一样尊重 `batch_index` 的批内偏移，否则多图批次的噪声会错乱。

## 5. `PK_CustomSigmas` —— 自定义 sigma 调度（Sigmas 组件）

### 5.1 原理

`SIGMAS` 是一个 1D 张量，长度 = `steps + 1`，从 `sigma_max` 递减到 `0`。`calculate_sigmas(model_sampling, scheduler, steps)` 已经帮你算好某个 scheduler 的表。我们要做的是**在保留首尾端点（sigma_max 和 0）的前提下，重排中间步长**，用公式 `sigmas = sigma_max * (norm ** gamma)`，其中 `norm = sigmas/sigma_max`，`gamma` 控制疏密。

### 5.2 完整代码

```python
import comfy.samplers
from comfy_api.latest import io


class PK_CustomSigmas(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="PK_CustomSigmas",
            display_name="PK Custom Sigmas",
            category="PK/sampling/sigmas",
            description="Build a sigma schedule and re-space it with a gamma curve.",
            inputs=[
                io.Model.Input("model"),
                io.Int.Input("steps", default=20, min=1, max=10000,
                             control_after_generate=False),
                io.Combo.Input("scheduler", options=comfy.samplers.SCHEDULER_NAMES, default="karras"),
                io.Float.Input("gamma", default=1.0, min=0.1, max=5.0, step=0.05,
                               round=0.01, tooltip=">1: 步长前密后疏；<1: 前疏后密"),
            ],
            outputs=[io.Sigmas.Output()],
        )

    @classmethod
    def execute(cls, model, steps: int, scheduler: str, gamma: float) -> io.NodeOutput:
        model_sampling = model.get_model_object("model_sampling")
        sigmas = comfy.samplers.calculate_sigmas(model_sampling, scheduler, steps).cpu()

        if gamma != 1.0:
            sigma_max = float(sigmas[0])
            norm = sigmas / sigma_max                       # 末尾为 0，首为 1
            # 两端点保持：norm[0]=1 -> sigma_max；norm[-1]=0 -> 0
            sigmas = sigma_max * (norm ** gamma)

        return io.NodeOutput(sigmas)
```

### 5.3 要点

- `model` 输入是**必须的**——`calculate_sigmas` 要用 `model_sampling` 把"步数"翻译成真正的 sigma 值（不同模型 sigma 范围不同）。
- 返回的 `sigmas` 张量**必须包含末位 0**：最后一个 sigma=0 代表"完全去噪"。你若自己构造，别忘了 `sigmas[-1] = 0`。
- `SCHEDULER_NAMES` 是直接从 `comfy.samplers` 拿的字符串列表，做下拉项最稳，不会因版本增减而写错。

## 6. `PK_ScheduledCFG` —— 自定义 CFG（Guider 组件）

### 6.1 原理

`CFGGuider.predict_noise(x, timestep, ...)` 负责"给定当前 latent `x` 和时间步 `timestep`，算出一步去噪预测"。标准实现是固定 `cfg` 做 `cond`/`uncond` 插值。我们重写它，让 `cfg` 随去噪进度线性变化：开始用低 CFG（保多样性），结束用高 CFG（保贴合）。

### 6.2 完整代码

```python
import comfy.samplers
from comfy_api.latest import io


class PK_ScheduledCFGGuider(comfy.samplers.CFGGuider):
    """CFG 随去噪进度从 cfg_min 线性升到 cfg_max。"""
    def __init__(self, model, cfg_min: float, cfg_max: float):
        super().__init__(model)
        self.cfg_min = cfg_min
        self.cfg_max = cfg_max

    def predict_noise(self, x, timestep, model_options={}, seed=None):
        # timestep 在 [0, ~1000] 区间；归一化到 [0,1] 作为进度
        t = float(timestep) / 1000.0
        cfg = self.cfg_min + (self.cfg_max - self.cfg_min) * t
        # 直接调用标准 CFG 合成函数，用动态 cfg
        return comfy.samplers.sampling_function(
            self.inner_model, x, timestep,
            self.conds["negative"], self.conds["positive"],
            cfg, model_options=model_options, seed=seed,
        )


class PK_ScheduledCFG(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="PK_ScheduledCFG",
            display_name="PK Scheduled CFG",
            category="PK/sampling/guiders",
            description="CFG that ramps from cfg_min to cfg_max over denoising.",
            inputs=[
                io.Model.Input("model"),
                io.Conditioning.Input("positive"),
                io.Conditioning.Input("negative"),
                io.Float.Input("cfg_min", default=1.0, min=0.0, max=100.0, step=0.1, round=0.01),
                io.Float.Input("cfg_max", default=8.0, min=0.0, max=100.0, step=0.1, round=0.01),
            ],
            outputs=[io.Guider.Output()],
        )

    @classmethod
    def execute(cls, model, positive, negative, cfg_min, cfg_max) -> io.NodeOutput:
        guider = PK_ScheduledCFGGuider(model, cfg_min, cfg_max)
        guider.set_conds(positive, negative)
        return io.NodeOutput(guider)
```

### 6.3 要点

- `set_conds(positive, negative)` 必须在返回前调用，否则 `self.conds` 为空，`predict_noise` 里 `self.conds["negative"]` 会 KeyError。
- `self.inner_model` 是 Guider 内部的模型包装；传给 `sampling_function` 的就是它。
- 如果你只想**固定**某个 CFG 但换种合成方式（如 rescale CFG），同样重写 `predict_noise`，区别在于 `cfg` 怎么算。注意 rescale 需要分别拿到 cond 与 uncond 预测——`sampling_function` 内部已做，要改得更细就得自己 `calc_cond_batch` 拿两份预测再做 `cfg_function`（见 `comfy/samplers.py:592`、`comfy/samplers.py:208`）。

## 7. `PK_EulerSampler` —— 自定义采样器（Sampler 组件）

### 7.1 原理

`Sampler.sample(self, model_wrap, sigmas, extra_args, callback, noise, latent_image, denoise_mask, disable_pbar)` 是一步迭代的总入口。最省事的做法是**直接复用 `comfy.k_diffusion.sampling` 里现成的采样函数**，它们签名正好匹配。下面用 `sample_euler` 包一个常驻采样器对象。

### 7.2 完整代码

```python
import comfy.k_diffusion.sampling as k_diffusion_sampling
import comfy.samplers
from comfy_api.latest import io


class PK_EulerSampler(comfy.samplers.Sampler):
    def sample(self, model_wrap, sigmas, extra_args, callback,
               noise, latent_image=None, denoise_mask=None, disable_pbar=False):
        # model_wrap(x, sigma, model_options=...) 即一次模型预测
        return k_diffusion_sampling.sample_euler(
            model_wrap, noise, sigmas,
            extra_args=extra_args, callback=callback, disable=disable_pbar,
        )


class PK_SamplerEulerNode(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="PK_EulerSampler",
            display_name="PK Euler Sampler",
            category="PK/sampling/samplers",
            description="A custom Sampler wrapping k_diffusion sample_euler.",
            inputs=[],
            outputs=[io.Sampler.Output()],
        )

    @classmethod
    def execute(cls) -> io.NodeOutput:
        return io.NodeOutput(PK_EulerSampler())
```

### 7.3 要点

- 复用现成采样函数是最安全的做法。如果你要写**全新**的迭代逻辑，照着 `comfy/k_diffusion/sampling.py:190` 的 `sample_euler` 改即可：核心就是循环 `for i in range(len(sigmas)-1)`，每步调用 `model_wrap(x, sigmas[i], ...)` 拿到 `denoised`，再用对应公式更新 `x`。
- `extra_args` 里带 `denoise_mask`、`model_options` 等，原样透传给 `model_wrap`。
- 返回的是**采样器对象**，节点 `OUTPUT` 类型是 `io.Sampler`。

## 8. `PK_SamplerCustom` —— 把四件套组装起来

这个节点等价于自带 `SamplerCustom`（`comfy_extras/nodes_custom_sampler.py`），这里完整复刻，方便你理解"四件套如何被串起来"。

```python
import comfy.sample
import comfy.utils
import latent_preview
from comfy_api.latest import io


class PK_SamplerCustom(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="PK_SamplerCustom",
            display_name="PK Sampler (Custom)",
            category="PK/sampling",
            description="Assemble Noise + Sigmas + Guider + Sampler.",
            inputs=[
                io.Model.Input("model"),
                io.Boolean.Input("add_noise", default=True, advanced=True),
                io.Int.Input("noise_seed", default=0, min=0, max=0xffffffffffffffff,
                             control_after_generate=True),
                io.Conditioning.Input("positive"),
                io.Conditioning.Input("negative"),
                io.Noise.Input("noise"),
                io.Sigmas.Input("sigmas"),
                io.Guider.Input("guider"),
                io.Latent.Input("latent_image"),
            ],
            outputs=[
                io.Latent.Output(display_name="output"),
                io.Latent.Output(display_name="denoised_output"),
            ],
        )

    @classmethod
    def execute(cls, model, add_noise, noise_seed, positive, negative,
                noise, sigmas, guider, latent_image) -> io.NodeOutput:
        latent = latent_image.copy()
        latent_image = latent["samples"]
        latent_image = comfy.sample.fix_empty_latent_channels(model, latent_image,
                                                              latent.get("downscale_ratio_spacial", None),
                                                              latent.get("downscale_ratio_temporal", None))
        latent["samples"] = latent_image

        # 1) 噪声：调用 Noise 对象
        if not add_noise:
            gen = _EmptyNoise()
        else:
            gen = noise
        noise_tensor = gen.generate_noise(latent)

        noise_mask = latent.get("noise_mask", None)

        # 2) 进度预览回调
        x0_output = {}
        callback = latent_preview.prepare_callback(model, sigmas.shape[-1] - 1, x0_output)
        disable_pbar = not comfy.utils.PROGRESS_BAR_ENABLED

        # 3) 真正采样：Guider 内部会包装 model，Sampler 负责迭代
        samples = comfy.sample.sample_custom(
            model, noise_tensor, 1.0, guider, sigmas, positive, negative,
            latent_image, noise_mask=noise_mask, callback=callback,
            disable_pbar=disable_pbar, seed=noise_seed,
        )

        out = latent.copy()
        out.pop("downscale_ratio_spacial", None)
        out.pop("downscale_ratio_temporal", None)
        out["samples"] = samples

        if "x0" in x0_output:
            x0 = x0_output["x0"]
            x0_out = model.model.process_latent_out(x0.cpu())
            out_denoised = latent.copy()
            out_denoised["samples"] = x0_out
        else:
            out_denoised = out
        return io.NodeOutput(out, out_denoised)


class _EmptyNoise:
    def generate_noise(self, input_latent):
        return comfy.sample.prepare_empty_noise(input_latent["samples"])
```

> 注意 `cfg` 参数这里传 `1.0`：因为我们把 CFG 逻辑放进 `guider` 了（`sample_custom` 的 `cfg` 只是给 Guider 用的默认值，真正起作用的是 `PK_ScheduledCFG` 里动态算的 `cfg`）。如果你用自带 `CFGGuider`，则要把 `cfg` 从节点参数传进来。

## 10. 排错清单

| 现象 | 原因 | 解决 |
|---|---|---|
| 节点不出现在 UI | `node_id` 与内置重名被忽略 / 放在了 `comfy_extras/` | 加 `PK_` 前缀；放 `custom_nodes/` |
| `KeyError: 'negative'` in Guider | 忘了调 `set_conds` | 返回前 `guider.set_conds(positive, negative)` |
| 全程没去噪（输出=输入） | sigmas 末尾不是 0 | 保证 `sigmas[-1] == 0` |
| CFG 没生效 | 把 `cfg` 写死在节点却没传给 Guider | 在 Guider 内部算 `cfg`，`sample_custom` 的 cfg 仅作默认 |
| 噪声每步都变 | 在 `generate_noise` 外 `torch.randn` | 只在 `generate_noise` 内按 seed 生成 |
| 自定义 Sampler 不收敛 | 直接调 `model_wrap` 但没传 `extra_args` | 把 `extra_args` 透传给采样函数 |
| `model.get_model_object` 报错 | 在 Sigmas 节点没接 `model` | Sigmas 节点务必接 `io.Model.Input` |
