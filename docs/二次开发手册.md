## 1. 项目概述

ComfyUI 是一个基于节点的生成式 AI 推理引擎，用户通过节点图组合各种 AI 模型和操作，实现图像、视频、音频、3D 等内容的生成。它完全开源，支持本地运行，是当前最强大的开源扩散模型推理引擎。

**核心特性：**
- 可视化节点图界面，无需编写代码即可构建复杂工作流
- 高效本地执行：异步队列、部分图重执行、智能 VRAM/RAM 管理、模型卸载、量化模型支持
- 广泛的原生模型支持：SD1.5、SDXL、SD3.5、Flux.1/2、Wan 2.1/2.2、HunyuanVideo 等数十种模型族
- 完整的 REST + WebSocket Server API，可编程化调用
- 自定义节点扩展系统，支持 Python 后端和 JavaScript 前端扩展
- 跨平台支持：NVIDIA、AMD、Intel、Apple Silicon、Ascend NPU、Cambricon MLU

## 3. 环境搭建

### 3.1 系统要求

- Python 3.13（推荐）或 3.12（兼容性更好）
- PyTorch 2.7+（推荐最新版本，NVIDIA 20 系及以上需 cu130+）
- 支持的 GPU：NVIDIA、AMD (ROCm)、Intel Arc、Apple Silicon (MPS)、Ascend NPU、Cambricon MLU

### 3.2 安装步骤

```bash
# 1. 克隆仓库
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI

# 2. 安装 PyTorch（NVIDIA 为例）
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130

# 3. 安装依赖
pip install -r requirements.txt

# 4. 启动
python main.py
```

| `text_encoders` | 文本编码器（也搜索 `clip/`） | 同上 |
| `diffusion_models` | 扩散模型（也搜索 `unet/`） | 同上 |

```yaml
# extra_model_paths.yaml

```

## 5. 核心概念

### 5.1 工作流 (Workflow)

工作流是一个有向无环图 (DAG)，由节点和连接组成。每个节点有输入、输出和参数。前端将整个工作流（包含所有参数值）序列化为 JSON 提交到 `/prompt` 端点。

### 5.2 节点 (Node)

节点是工作流的基本单元，每个节点是一个 Python 类，定义了：
- 输入（`INPUT_TYPES` 或 `define_schema`）
- 输出（`RETURN_TYPES` 或 `outputs`）
- 执行函数（`FUNCTION` 或 `execute`）
- 分类（`CATEGORY` 或 `category`）

### 5.3 数据类型 (Datatype)

数据类型用于在节点之间传递数据。常用类型包括：

| 类型 | Python 类型 | 张量形状 | 说明 |
|---|---|---|---|
| `IMAGE` | `torch.Tensor` | `[B,H,W,C]` | 图片批量，C=3 为 RGB |
| `LATENT` | `dict` | `samples: [B,C,H,W]` | 潜空间表示，H/W 为图像 1/8 |
| `MASK` | `torch.Tensor` | `[H,W]` 或 `[B,C,H,W]` | 掩码 |
| `AUDIO` | `dict` | `waveform: [B,C,T]` | 音频，含 `sample_rate` |
| `INT` | `int` | — | 整数 |
| `FLOAT` | `float` | — | 浮点数 |
| `STRING` | `str` | — | 字符串 |
| `BOOLEAN` | `bool` | — | 布尔值 |
| `MODEL` | `ModelPatcher` | — | 扩散模型 |
| `CLIP` | `CLIP` | — | 文本编码器 |
| `VAE` | `VAE` | — | VAE 模型 |
| `CONDITIONING` | `list` | — | 条件对象 |
| `COMBO` | `str` (from `list[str]`) | — | 下拉菜单选择 |

### 5.4 Prompt（API 格式）

前端提交的工作流 JSON 采用 API 格式：

```json
{
  "3": {
    "class_type": "KSampler",
    "inputs": {
      "cfg": 8,
      "denoise": 1,
      "latent_image": ["5", 0],
      "model": ["4", 0],
      "negative": ["7", 0],
      "positive": ["6", 0],
      "sampler_name": "euler",
      "scheduler": "normal",
      "seed": 8566257,
      "steps": 20
    }
  },
  "4": {
    "class_type": "CheckpointLoaderSimple",
    "inputs": { "ckpt_name": "model.safetensors" }
  }
}
```

- 顶层 key 是节点 ID（字符串数字）
- `["5", 0]` 表示连接到节点 5 的第 0 个输出
- 常量值直接写值

```

        │           └── operations = comfy.ops.pick_operations()  ← 选择算子策略
```

## 9. 执行引擎

### 9.1 执行流程

```
用户提交 Prompt (POST /prompt)
        │
        ▼
PromptServer /prompt handler
  ├── 验证图结构
  ├── 调用 on_prompt handlers
  └── 入队 PromptQueue
        │
        ▼
prompt_worker() (main.py 中的消费者循环)
        │
        ▼
PromptExecutor.execute(prompt)
  ├── 构建 ExecutionList (comfy_execution/graph.py 拓扑排序)
  ├── 检查缓存 (caching.py)，只执行变化部分
  └── 遍历节点：获取输入数据 → 调用节点函数 → 存储输出
        │
        ▼
返回结果 → 存入 history → WebSocket 通知前端
```

### 9.2 缓存策略

| 策略 | CLI 参数 | 行为 |
|---|---|---|
| RAMPressureCache（默认） | `--cache-ram` | 基于系统 RAM 压力自动驱逐 |
| LRU | `--cache-lru N` | 最多缓存 N 个节点结果 |
| HierarchicalCache | `--cache-classic` | 旧式激进缓存 |
| NullCache | `--cache-none` | 不缓存，每次全量执行 |

### 9.3 执行引擎模块

| 文件 | 关键类 | 职责 |
|---|---|---|
| `execution.py` | `PromptExecutor`, `PromptQueue` | 节点图执行主循环、缓存管理 |
| `comfy_execution/graph.py` | `DynamicPrompt`, `ExecutionList`, `TopologicalSort` | 图构建与拓扑排序 |
| `comfy_execution/caching.py` | `RAMPressureCache`, `LRUCache`, `HierarchicalCache`, `NullCache` | 多策略缓存 |
| `comfy_execution/jobs.py` | `JobStatus` | 任务状态规范化 |
| `comfy_execution/validation.py` | — | 图验证（循环检测等） |

### 11.1 节点基本结构

```python
import torch

        return {
            "required": {
                "image_in": ("IMAGE", {}),
```

### 11.6 完整 V1 示例

```python
import torch

class ImageSelector:
    CATEGORY = "example"

    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "images": ("IMAGE",),
                "mode": (["brightest", "reddest", "greenest", "bluest"],),
            }
        }

    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "choose_image"

    def choose_image(self, images, mode):
        batch_size = images.shape[0]
        brightness = list(torch.mean(image.flatten()).item() for image in images)
        if mode == "brightest":
            scores = brightness
        else:
            channel = 0 if mode == "reddest" else (1 if mode == "greenest" else 2)
            absolute = list(torch.mean(image[:, :, channel].flatten()).item() for image in images)
            scores = list(absolute[i] / (brightness[i] + 1e-8) for i in range(batch_size))
        best = scores.index(max(scores))
        result = images[best].unsqueeze(0)
        return (result,)
```

## 12. 自定义节点开发 — V3 现代模式

V3 是新的节点 Schema，提供更组织化的定义方式和更多高级功能。未来的节点功能扩展将只添加到 V3。

### 12.1 V1 与 V3 架构对比

| 特性 | V1 | V3 |
|---|---|---|
| 输入/输出定义 | 字典 | 对象 (`io.Image.Input()` 等) |
| 执行方法名 | 自定义 (`FUNCTION`) | 固定 `execute` |
| 执行方法类型 | 实例方法 | 类方法 |
| 节点注册 | `NODE_CLASS_MAPPINGS` 字典 | `ComfyExtension` + `comfy_entrypoint` |
| 节点状态 | `__init__` 可设置状态 | 无状态（全部类方法） |
| 动态输入 | 不支持 | `Autogrow`, `DynamicCombo` |
| 类型匹配 | 不支持 | `MatchType` |
| 进度报告 | `PROGRESS_BAR_HOOK` | `ComfyAPI().execution.set_progress()` |

### 12.2 V3 基本结构

```python
from comfy_api.latest import ComfyExtension, io, ui

    @classmethod
    def define_schema(cls) -> io.Schema:
        return io.Schema(
            node_id="MyNode",
            display_name="My Node",
            category="my_category",
            description="Node description",

                io.Image.Input("image"),
                io.Int.Input("int_field", default=0, min=0, max=4096, step=64,
                             display_mode=io.NumberDisplay.number),
                io.Float.Input("float_field", default=1.0, min=0.0, max=10.0, step=0.01,
                              display_mode=io.NumberDisplay.number, lazy=True),

                io.Boolean.Input("enabled", default=True),
                io.Combo.Input("mode", options=["option1", "option2"]),
            ],
            outputs=[
                io.Image.Output(),
            ],
        )

    @classmethod
    def execute(cls, image, int_field, float_field, string_field, enabled, mode) -> io.NodeOutput:
        result = 1.0 - image
        return io.NodeOutput(result, ui=ui.PreviewImage(result, cls=cls))
```

## 14. 进阶特性

### 14.1 懒求值 (Lazy Evaluation)

懒求值允许节点在运行时决定是否需要某个输入，避免不必要的计算。

**V1 用法：**

```python
class LazyMixImages:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image1": ("IMAGE", {"lazy": True}),
                "image2": ("IMAGE", {"lazy": True}),
                "mask": ("MASK",),
            },
        }

    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "mix"

    def check_lazy_status(self, mask, image1, image2):
        mask_min = mask.min()
        mask_max = mask.max()
        needed = []
        if image1 is None and (mask_min != 1.0 or mask_max != 1.0):
            needed.append("image1")
        if image2 is None and (mask_min != 0.0 or mask_max != 1.0):
            needed.append("image2")
        return needed

    def mix(self, mask, image1, image2):
        # mask 全 1.0 时只需 image2，全 0.0 时只需 image1
        result = image1 * (1. - mask) + image2 * mask
        return (result,)
```

**V3 用法：** 在 `define_schema` 中设置 `lazy=True`，`check_lazy_status` 改为 `@classmethod`。

### 14.2 ExecutionBlocker（执行阻断）

用于阻断下游节点执行：

```python
from comfy_execution.graph import ExecutionBlocker

def silent_passthrough(self, passthrough, blocked):
    if blocked:
        return (ExecutionBlocker(None),)  # 静默阻断
    else:
        return (passthrough,)

def load_checkpoint(self, ckpt_name):
    model, clip, vae = load_checkpoint(ckpt_name)
    if vae is None:
        vae = ExecutionBlocker(f"No VAE in {ckpt_name}")  # 带错误消息
    return (model, clip, vae)
```

```python
class MyNode:
    INPUT_IS_LIST = True   # 输入以列表形式接收（每个输入可能是多值）
```

### 16.2 方法 2：WebSocket + History（推荐）

```python
import websocket
import uuid
import json
import urllib.request
import urllib.parse

SERVER_ADDRESS = "127.0.0.1:8188"
client_id = str(uuid.uuid4())

def queue_prompt(prompt, prompt_id):
    p = {"prompt": prompt, "client_id": client_id, "prompt_id": prompt_id}
    data = json.dumps(p).encode("utf-8")
    req = urllib.request.Request(f"http://{SERVER_ADDRESS}/prompt", data=data)
    urllib.request.urlopen(req)

def get_image(filename, subfolder, folder_type):
    params = urllib.parse.urlencode({"filename": filename, "subfolder": subfolder, "type": folder_type})
    with urllib.request.urlopen(f"http://{SERVER_ADDRESS}/view?{params}") as r:
        return r.read()

def get_history(prompt_id):
    with urllib.request.urlopen(f"http://{SERVER_ADDRESS}/history/{prompt_id}") as r:
        return json.loads(r.read())

def get_images(ws, prompt):
    prompt_id = str(uuid.uuid4())
    queue_prompt(prompt, prompt_id)
    while True:
        out = ws.recv()
        if isinstance(out, str):
            message = json.loads(out)
            if message["type"] == "executing":
                data = message["data"]
                if data["node"] is None and data["prompt_id"] == prompt_id:
                    break
    history = get_history(prompt_id)[prompt_id]
    output_images = {}
    for node_id in history["outputs"]:
        node_output = history["outputs"][node_id]
        if "images" in node_output:
            images_output = []
            for image in node_output["images"]:
                image_data = get_image(image["filename"], image["subfolder"], image["type"])
                images_output.append(image_data)
            output_images[node_id] = images_output
    return output_images

# 使用
ws = websocket.WebSocket()
ws.connect(f"ws://{SERVER_ADDRESS}/ws?clientId={client_id}")
images = get_images(ws, prompt)
ws.close()
```

## 22. 开发最佳实践

### 22.1 节点设计原则

1. **保持节点单一职责**：一个节点做一件事，复杂逻辑用多个节点组合
2. **向后兼容**：新增输入用 sensible 默认值，不改变输出类型
3. **可选输入标记为 optional**：有有效路径不使用它时
4. **使用 Combo 而非 STRING 做枚举选择**：Combo 提供更好的 UI 体验和验证
5. **Combo 值在文件系统访问时需要再次验证**：不信任前端传来的值

### 22.2 张量处理

```python
# IMAGE 张量形状: [B, H, W, C]，值域 [0.0, 1.0]
# 单张图片: B=1
# 返回单张图片: images[idx].unsqueeze(0)

# MASK 张量形状: [H, W] 或 [B, C, H, W]
# 转换: image[:, :, :, 0] 获取第一个通道

# LATENT 是 dict: {"samples": tensor[B, C, H, W], ...}
```

### 22.3 节点不应做的事

- **不要在节点代码中直接 patch 模型**：通过 ModelPatcher 类
- **不要添加网络请求**：核心 ComfyUI 不应有出站网络请求
- **不要在模型类中添加 freeze/unfreeze**：ComfyUI 模型始终视为冻结
- **不要添加 `torch.no_grad()` / `torch.inference_mode()`**
- **不要输出节点不拥有的值**：不要添加 pass-through 输出

### 22.4 性能优化

- 对可能不需要的输入使用 **lazy evaluation**
- 使用 `IS_CHANGED` / `fingerprint_inputs` 避免不必要的重新执行
- 避免在节点中创建全局缓存（应作用域到单次执行）
- 使用现有 ComfyUI 优化算子（`comfy.ops`, `comfy.quant_ops`）而非自己实现

### 22.5 错误处理

```python
# 返回有意义的错误而非静默失败
def execute(self, image, mode):
    if image.shape[0] == 0:
        raise ValueError("Input image batch is empty")
    # ...
```
