# 第 0 章 读前须知

## 0.1 你需要什么

| 项 | 要求 |
|---|---|
| Python | ≥ 3.9（本仓库 `pyproject.toml` 要求） |
| ComfyUI | 本仓库当前版本（V3 API 已稳定可用） |
| 依赖 | `torch`、`numpy`、`Pillow`（ComfyUI 自带） |
| 编辑器 | 任意。建议给 `custom_nodes/` 目录单独开一个 VS Code 窗口 |
| 调试方式 | 直接重启 ComfyUI 看控制台日志（**没有热重载**，改 Python 必须重启） |

## 0.2 三个必须分清的目录

```
ComfyUI/
├── nodes.py            # 65 个核心节点（Checkpoint/KSampler/VAE...）
├── comfy_extras/       # 594 个内置扩展节点 —— 由 nodes.py 里的【硬编码清单】加载
├── comfy_api_nodes/    # 292 个云端 API 节点 —— glob 自动扫描
├── comfy/              # 底层引擎（samplers/model_base/model_management...）
├── comfy_api/latest/   # ★ V3 节点 API（io / ui / ComfyExtension）
└── custom_nodes/       # ★★ 你写的东西放这里 —— 自动扫描
```

**关键结论：你的代码放 `custom_nodes/`，不要动 `comfy_extras/`。**
原因见 2.3——往 `comfy_extras/` 丢新文件**不会自动生效**。

## 0.3 术语表

| 术语 | 含义 |
|---|---|
| **节点 ID / `node_id` / `class_type`** | 同一个东西。API JSON 里的 key，全局唯一 |
| **V1 节点** | 老范式：类属性 `INPUT_TYPES` / `RETURN_TYPES` / `FUNCTION` + `NODE_CLASS_MAPPINGS` |
| **V3 节点** | 新范式：`io.ComfyNode` + `define_schema()` + `execute()` + `comfy_entrypoint()` |
| **Extension（扩展）** | 一个 Python 包，含 1~N 个节点，入口是 `comfy_entrypoint()` |
| **Widget** | 节点上的输入控件（滑块、文本框、下拉） |
| **Socket** | 节点上可连线的输入输出端点 |
| **Link** | 连线。API JSON 里写作 `[源节点ID, 输出槽下标]` |
| **输出节点** | `OUTPUT_NODE=True` / `is_output_node=True`。没连到输出节点的分支**不会被执行** |
| **Latent** | 潜空间张量 `[B, 4, H/8, W/8]` |
| **IMAGE** | 图像张量 `[B, H, W, C]`，值域 `[0, 1]`（**通道在最后**） |
| **MASK** | 掩码 `[B, H, W]`，`1.0` = 需要处理 |

# 第 1 章 二次开发的五种形态与选型

| 形态 | 适用场景 | 优点 | 缺点 |
|---|---|---|---|
| **① 纯工作流编排**（不写代码） | 用现成节点拼流程 | 零风险、可视化 | 逻辑复杂后连线爆炸 |
| **② 自定义节点包**（`custom_nodes/`）★本教程 | 需要新算子/接外部系统/封装固定流程 | 独立仓库、可分发、可复用 | 需维护代码 |
| **③ 改 `comfy_extras/`** | 你要给 ComfyUI 主干贡献内置节点 | 随官方发布 | 必须改 `nodes.py` 的清单，且受 AGENTS.md 严格约束 |
| **④ API 节点**（`comfy_api_nodes/`） | 调用云端推理服务 | 官方已跑通鉴权/计费 | 需要联网与鉴权 |
| **⑤ 前端扩展** | 只想改 UI（新控件、右键菜单、面板） | 不改后端 | 依赖前端版本 |

**选型速判：**

```
只是换参数跑图？            → ①
需要一个新的图像/张量运算？  → ② ★
需要接你公司的内部服务？      → ②
需要调用第三方云 API？        → ④
只想加个按钮/面板？           → ⑤（通常也配 ② 一起）
要给官方提 PR？               → ③（先读第 18 章）
```

# 第 2 章 节点加载机制源码拆解

> 这一章解决 90% 的"我的节点怎么没出现在菜单里"。

## 2.1 启动顺序

`main.py` → `nodes.init_extra_nodes()`（`nodes.py:2592`）：

```python
async def init_extra_nodes(init_custom_nodes=True, init_api_nodes=True):
    await init_public_apis()                    # 注册 comfy_api 版本
    import_failed = await init_builtin_extra_nodes()   # ① 内置 comfy_extras
    if init_api_nodes:
        import_failed_api = await init_builtin_api_nodes()  # ② comfy_api_nodes
    if init_custom_nodes:
        await init_external_custom_nodes()      # ③ 你的 custom_nodes
```

**顺序很重要**：内置 → API → 外部。你的节点最后加载。

## 2.2 `custom_nodes/` 是怎么被扫到的

`nodes.py:2354` `init_external_custom_nodes()`：

```python
node_paths = folder_paths.get_folder_paths("custom_nodes")
for custom_node_path in node_paths:
    possible_modules = os.listdir(os.path.realpath(custom_node_path))
    for possible_module in possible_modules:
        module_path = os.path.join(custom_node_path, possible_module)
        # ① 不是 .py 的文件直接跳过
        if os.path.isfile(module_path) and os.path.splitext(module_path)[1] != ".py":
            continue
        # ② .disabled 后缀跳过（临时禁用节点用这个）
        if module_path.endswith(".disabled"):
            continue
        # ③ 白名单/黑名单策略
        if args.disable_all_custom_nodes and possible_module not in args.whitelist_custom_nodes:
            continue
        # ④ 安全治理拦截
        refusal = governance.pack_refusal(module_path)
        if refusal is not None:
            logging.warning(refusal); continue
        # ⑤ 真正加载
        await load_custom_node(module_path, base_node_names, module_parent="custom_nodes")
```

要点：
- **目录** → 加载该目录下的 `__init__.py`
- **`.py` 文件** → 直接加载
- 想临时禁用：把目录改名加 `.disabled` 后缀
- `custom_nodes` 路径可通过 `extra_model_paths.yaml` 扩展多份

## 2.3 ⚠️ 往 `comfy_extras/` 丢文件不会生效

`nodes.py:2409` `init_builtin_extra_nodes()` 里是一张**硬编码的 140 项文件名清单**（`nodes_latent.py` … `nodes_marigold.py`）。
不在清单里的文件永远不会被导入。

而 API 节点是 glob（`nodes.py:2573`）：

```python
api_nodes_files = sorted(glob.glob(os.path.join(api_nodes_dir, "nodes_*.py")))
```

所以：**改内置节点 = 加文件 + 在清单里加一行**。这也是第 18 章规范存在的理由。

## 2.4 你的模块必须提供什么

`nodes.py:2255` `load_custom_node()` 的判定顺序：

```python
# ① V1：有 NODE_CLASS_MAPPINGS
if hasattr(module, "NODE_CLASS_MAPPINGS") and getattr(module, "NODE_CLASS_MAPPINGS") is not None:
    for name, node_cls in module.NODE_CLASS_MAPPINGS.items():
        if name not in ignore:              #  ← 注意 ignore
            NODE_CLASS_MAPPINGS[name] = node_cls
    ...
    return True
# ② V3：有 comfy_entrypoint
elif hasattr(module, "comfy_entrypoint"):
    entrypoint = getattr(module, "comfy_entrypoint")
    extension = await entrypoint() if iscoroutine else entrypoint()
    await extension.on_load()
    for node_cls in await extension.get_node_list():
        schema = node_cls.GET_SCHEMA()
        if schema.node_id not in ignore:
            NODE_CLASS_MAPPINGS[schema.node_id] = node_cls
    return True
# ③ 都没有 → 警告并跳过
else:
    logging.warning(f"Skip {module_path} module for custom nodes due to the lack of "
                    f"NODE_CLASS_MAPPINGS or comfy_entrypoint (need one).")
    return False
```

### 三个致命细节

1. **`ignore` = 内置已有节点名集合**（`nodes.py:2367` `base_node_names = set(NODE_CLASS_MAPPINGS.keys())`）。
   如果你把 `node_id` 起成 `KSampler`，它会被**静默忽略**——不报错，就是不生效。
   → **自定义节点必须加前缀**，如 `PK_`、`MyCompany_`。这是 `io.Schema.node_id` 文档注释明确要求的。

2. **V1 优先于 V3**。同一模块里两个都存在，只有 V1 生效，V3 分支根本不会走到。

3. **导入失败 = 静默跳过 + 打印 traceback**。启动日志里搜 `IMPORT FAILED` 或 `Cannot import`。

## 2.5 前端目录怎么注册

两种方式（`nodes.py:2280-2302`）：

# 第 3 章 V3 / V1 双范式对照

## 3.1 直观对比

同一个"图像乘以系数"节点：

**V1（老）**

```python
class ImageMultiply:
    @classmethod
    def INPUT_TYPES(s):
        return {"required": {
            "image": ("IMAGE",),
            "factor": ("FLOAT", {"default": 1.0, "min": 0.0, "max": 10.0, "step": 0.01}),
        }}
    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "multiply"
    CATEGORY = "posterkit"

    def multiply(self, image, factor):
        return (image * factor,)

NODE_CLASS_MAPPINGS = {"ImageMultiply": ImageMultiply}
NODE_DISPLAY_NAME_MAPPINGS = {"ImageMultiply": "Image Multiply"}
```

**V3（新）**

```python
from comfy_api.latest import ComfyExtension, io

class ImageMultiply(io.ComfyNode):
    @classmethod
    def define_schema(cls) -> io.Schema:
        return io.Schema(
            node_id="PK_ImageMultiply",
            display_name="Image Multiply",
            category="posterkit",
            inputs=[
                io.Image.Input("image"),
                io.Float.Input("factor", default=1.0, min=0.0, max=10.0, step=0.01),
            ],
            outputs=[io.Image.Output()],
        )

    @classmethod
    def execute(cls, image, factor) -> io.NodeOutput:
        return io.NodeOutput(image * factor)
```

## 3.2 字段映射表

| V1 | V3 | 说明 |
|---|---|---|
| `NODE_CLASS_MAPPINGS` 的 key | `Schema.node_id` | 全局唯一 ID |
| `NODE_DISPLAY_NAME_MAPPINGS` | `Schema.display_name` | |
| `CATEGORY` | `Schema.category` | 默认 `"sd"` |
| `INPUT_TYPES()` | `Schema.inputs=[io.X.Input(...)]` | |
| `RETURN_TYPES` | `Schema.outputs=[io.X.Output()]` | |
| `RETURN_NAMES` | `io.X.Output(display_name=...)` | |
| `FUNCTION` | `execute()`（固定名） | |
| `OUTPUT_NODE=True` | `Schema.is_output_node=True` | |
| `INPUT_IS_LIST` | `Schema.is_input_list=True` | |
| `OUTPUT_IS_LIST` | `io.X.Output(is_output_list=True)` | |
| `IS_CHANGED()` | `fingerprint_inputs()` | |
| `VALIDATE_INPUTS()` | `validate_inputs()` | 返回 `True` 或错误字符串 |
| `DEPRECATED` / `EXPERIMENTAL` | `Schema.is_deprecated` / `is_experimental` | |
| `DESCRIPTION` | `Schema.description` | |
| `hidden` 输入 | `Schema.hidden=[io.Hidden.prompt]` | |

## 3.3 该用哪个？

| 场景 | 选择 |
|---|---|
| 新项目 | **V3**。类型安全、schema 可校验、支持 lazy/UI 回传 |
| 需要兼容 ComfyUI ≤ 旧版 | V1 |
| 节点要被官方收录进 `comfy_extras/` | V3（当前 521/594 是 V3） |
| 想同时支持 | 两个类都写，但**同一模块只能注册一种**（2.4 细节 2）→ 拆成两个子模块 |

**本教程以 V3 为主**，第 10 章给 V1 版与迁移表。

## 3.4 `io.Schema` 全部字段（逐字段注释）

源码 `comfy_api/latest/_io.py:1841`：

```python
io.Schema(

    display_name="Xxx",            # 菜单显示名
    category="posterkit",          # 菜单路径，用 / 分级
    inputs=[...],                  # 输入列表

    hidden=[],                     # [io.Hidden.prompt, io.Hidden.unique_id, ...]
    description="...",             # 悬停提示

    is_output_node=False,          # 输出节点 → 自动加 Hidden.prompt/extra_pnginfo
    is_deprecated=False,
    is_experimental=False,
    is_dev_only=False,             # dev 模式才显示
    is_api_node=False,             # 云端 API 节点 → 自动加鉴权 hidden
    price_badge=None,
    not_idempotent=False,          # True = 相同输入也重新执行（不复用缓存）
```

## 3.5 `io.ComfyNode` 可覆写的方法

源码 `_io.py:2462`：

```python
class ComfyNode(_ComfyNodeBaseInternal):
    @classmethod
    def define_schema(cls) -> Schema: ...          # 必填
    @classmethod
    def execute(cls, **kwargs) -> NodeOutput: ...  # 必填（可 async）
    @classmethod
    def validate_inputs(cls, **kwargs) -> bool | str: ...   # 可选，返回 str = 错误信息
    @classmethod
    def fingerprint_inputs(cls, **kwargs) -> Any: ...       # 可选，等价 IS_CHANGED
    @classmethod
    def check_lazy_status(cls, **kwargs) -> list[str]: ...  # 可选，lazy 输入用
```

`execute` 的返回值（`_io.py:2218` `EXECUTE_NORMALIZED`）支持四种：

```python
return io.NodeOutput(a, b)         # 推荐
return (a, b)                      # 元组会自动包装
return None                        # 无输出
return {"ui": {...}, "result": (a, b)}   # 等价 V1 的 dict 返回
```

```python
import torch
from comfy_api.latest import ComfyExtension, io


class PK_Canvas(io.ComfyNode):
    """生成一张纯色或渐变画布。"""

    @classmethod
    def define_schema(cls) -> io.Schema:
        return io.Schema(
            node_id="PK_Canvas",                    # ★ 全局唯一，带 PK_ 前缀
            display_name="Poster Canvas",
            category="posterkit/generate",
            description="Create a solid or gradient canvas as IMAGE tensor.",
            inputs=[
                io.Int.Input("width",  default=1024, min=64,  max=16384, step=8),
                io.Int.Input("height", default=1024, min=64,  max=16384, step=8),
                io.Int.Input("batch_size", default=1, min=1, max=64),
                io.Combo.Input("mode", options=["solid", "h_gradient", "v_gradient"], default="solid"),
                io.Color.Input("color", default="#FFFFFF"),          # 前端颜色选择器
            ],
            outputs=[io.Image.Output(display_name="IMAGE")],
        )

    @classmethod
    def execute(cls, width, height, batch_size, mode, color) -> io.NodeOutput:
        # "#RRGGBB" -> (r, g, b) in [0,1]
        hex_s = color.lstrip("#")
        rgb = torch.tensor([int(hex_s[i:i + 2], 16) / 255.0 for i in (0, 2, 4)])

        # IMAGE 约定：[B, H, W, C]，float32，值域 [0,1]，通道在最后
        canvas = rgb.reshape(1, 1, 1, 3).expand(batch_size, height, width, 3).contiguous()

        if mode == "h_gradient":
            ramp = torch.linspace(0, 1, width).reshape(1, 1, width, 1)
            canvas = canvas * ramp                      # 左黑右彩
        elif mode == "v_gradient":
            ramp = torch.linspace(0, 1, height).reshape(1, height, 1, 1)
            canvas = canvas * ramp

        return io.NodeOutput(canvas)


class PosterKitExtension(ComfyExtension):
    async def get_node_list(self) -> list[type[io.ComfyNode]]:
        return [PK_Canvas]
```

## 5.2 逐行讲解

| 行 | 为什么这么写 |
|---|---|
| `class PK_Canvas(io.ComfyNode)` | V3 节点必须继承 `io.ComfyNode`（`_io.py:2462`） |
| `define_schema()` | `@classmethod`，返回 `io.Schema`。**不能**是实例方法 |
| `node_id="PK_Canvas"` | 加前缀。重名会被静默忽略（见 2.4 细节 1） |
| `category="posterkit/generate"` | 菜单路径，用 `/` 分级 |
| `io.Int.Input(..., step=8)` | `step` 是滑块步长；`display_mode=io.NumberDisplay.number` 可改成数字输入框 |
| `io.Color.Input("color")` | 前端颜色选择器，返回 `"#RRGGBB"` 字符串 |
| `io.Image.Output()` | 输出类型。**输出不写 id** 时 `finalize()` 会自动补 `_0_IMAGE_` |
| `rgb.reshape(1,1,1,3).expand(...)` | `expand` 是零拷贝广播，后面必须 `.contiguous()` |
| `return io.NodeOutput(canvas)` | 单输出也要包 `NodeOutput`（也可以直接 `return (canvas,)`） |

# 第 6 章 图像节点实战：PK_ColorGrade

**目标**：掌握 ComfyUI 里图像处理的全部规矩——张量布局、批处理、设备/dtype、原地修改陷阱。

## 6.1 先写纯算法层 `pk_ops.py`

**为什么单独拆一层**：不含任何 ComfyUI import，可以直接用 pytest 跑，不启动 ComfyUI。

```python
"""PosterKit 纯算法层：不 import 任何 ComfyUI 模块。"""
from __future__ import annotations

from typing import Any

import torch


# ---------------------------------------------------------------- 张量工具

def as_4d(image: torch.Tensor) -> torch.Tensor:
    """[H,W,C] -> [1,H,W,C]；[B,H,W,C] 原样返回。"""
    if image.ndim == 3:
        return image.unsqueeze(0)
    return image


def match_device_dtype(image: torch.Tensor, ref: torch.Tensor) -> torch.Tensor:
    """把 image 对齐到 ref 的设备与 dtype。"""
    if image.device != ref.device or image.dtype != ref.dtype:
        return image.to(device=ref.device, dtype=ref.dtype)
    return image


# ---------------------------------------------------------------- 色彩空间

def rgb_to_hsv(rgb: torch.Tensor) -> torch.Tensor:
    """rgb: [..., 3] 值域 [0,1] -> hsv: [..., 3]，h/s/v 均在 [0,1]。"""
    maxc, _ = rgb.max(-1)
    minc, _ = rgb.min(-1)
    delta = (maxc - minc).clamp(min=1e-8)

    v = maxc
    s = torch.where(maxc <= 0, torch.zeros_like(delta), (maxc - minc) / maxc.clamp(min=1e-8))

    r, g, b = rgb.unbind(-1)
    rc = (maxc - r) / delta
    gc = (maxc - g) / delta
    bc = (maxc - b) / delta

    h = torch.zeros_like(maxc)
    h = torch.where((maxc == r), (bc - gc) % 6.0, h)
    h = torch.where((maxc == g), (rc - bc) + 2.0, h)
    h = torch.where((maxc == b), (gc - rc) + 4.0, h)
    return torch.stack([(h / 6.0) % 1.0, s, v], dim=-1)


def hsv_to_rgb(hsv: torch.Tensor) -> torch.Tensor:
    """hsv: [..., 3] -> rgb: [..., 3]。rgb_to_hsv 的逆变换。"""
    h, s, v = hsv.unbind(-1)
    h6 = (h % 1.0) * 6.0
    i = torch.floor(h6) % 6.0
    f = h6 - torch.floor(h6)

    p = v * (1.0 - s)
    q = v * (1.0 - s * f)
    t = v * (1.0 - s * (1.0 - f))

    r = torch.where(i == 0, v, torch.where(i == 1, q, torch.where(i == 2, p,
        torch.where(i == 3, p, torch.where(i == 4, t, v)))))
    g = torch.where(i == 0, t, torch.where(i == 1, v, torch.where(i == 2, v,
        torch.where(i == 3, q, torch.where(i == 4, p, p)))))
    b = torch.where(i == 0, p, torch.where(i == 1, p, torch.where(i == 2, t,
        torch.where(i == 3, v, torch.where(i == 4, v, q)))))
    return torch.stack([r, g, b], dim=-1)


def apply_grade(
    image: torch.Tensor,
    brightness: float = 0.0,
    contrast: float = 1.0,
    saturation: float = 1.0,
    hue_shift: float = 0.0,
    gamma: float = 1.0,
) -> torch.Tensor:
    """对 [B,H,W,3] 的 IMAGE 张量做调色。返回新张量，不修改入参。"""
    out = image.clamp(0.0, 1.0)

    # 只有需要动色相/饱和度时才进 HSV（HSV 往返有精度损失）
    if hue_shift != 0.0 or saturation != 1.0:
        hsv = rgb_to_hsv(out)
        h, s, v = hsv.unbind(-1)
        h = (h + hue_shift) % 1.0
        s = (s * saturation).clamp(0.0, 1.0)
        out = hsv_to_rgb(torch.stack([h, s, v], dim=-1))

    out = (out - 0.5) * contrast + 0.5 + brightness
    if gamma != 1.0:
        out = out.clamp(min=1e-6).pow(1.0 / gamma)
    return out.clamp(0.0, 1.0)
```

## 6.2 再写节点 `PK_ColorGrade`

追加到 `nodes.py`：

```python
from .pk_ops import apply_grade, as_4d
import comfy.model_management as mm


class PK_ColorGrade(io.ComfyNode):
    """按参数或预设对图像做调色。"""

    @classmethod
    def define_schema(cls) -> io.Schema:
        return io.Schema(
            node_id="PK_ColorGrade",
            display_name="Poster Color Grade",
            category="posterkit/adjust",
            description="Brightness / contrast / saturation / hue / gamma grading for IMAGE batches.",
            inputs=[
                io.Image.Input("image"),
                io.Float.Input("brightness", default=0.0,  min=-1.0, max=1.0, step=0.01, round=0.001),
                io.Float.Input("contrast",   default=1.0,  min=0.0,  max=4.0, step=0.01, round=0.001),
                io.Float.Input("saturation", default=1.0,  min=0.0,  max=4.0, step=0.01, round=0.001),
                io.Float.Input("hue_shift",  default=0.0,  min=-1.0, max=1.0, step=0.01, round=0.001),
                io.Float.Input("gamma",      default=1.0,  min=0.1,  max=4.0, step=0.01, round=0.001),
            ],
            outputs=[io.Image.Output()],
        )

    @classmethod
    def execute(cls, image, brightness, contrast, saturation, hue_shift, gamma) -> io.NodeOutput:
        # ① 统一成 4 维 [B,H,W,C]
        batch = as_4d(image)

        # ② 只取 RGB 三通道；如果上游给了 4 通道就裁掉 alpha
        rgb = batch[..., :3]

        # ③ 计算设备：ComfyUI 会按显存情况把张量放在 cpu / cuda
        device = mm.get_torch_device()
        rgb = rgb.to(device)
        # 计算统一用 float32（fp16 下 pow/clamp 容易溢出）
        work = rgb.float() if rgb.dtype != torch.float32 else rgb

        # ④ 批处理：整批一起算，不要 for 循环逐张
        graded = apply_grade(
            work,
            brightness=brightness,
            contrast=contrast,
            saturation=saturation,
            hue_shift=hue_shift,
            gamma=gamma,
        )

        # ⑤ 回到原 dtype/设备，避免把 fp16 图变成 fp32 撑爆显存
        out = graded.to(dtype=rgb.dtype, device=image.device)

        return io.NodeOutput(out)
```

## 6.3 图像节点的 8 条铁律

| # | 规则 | 违反后果 |
|---|---|---|
| 1 | `IMAGE` 是 `[B, H, W, C]`，**通道在最后** | 用 `torchvision`/`F.interpolate` 前必须 `movedim(-1, 1)`，算完 `movedim(1, -1)` 转回 |
| 2 | 值域一律 `[0, 1]` 的 float | 存盘/送 PIL 前 `* 255` 再 `clamp` |
| 3 | 一定要处理 `batch` 维 | 上游可能一次来 8 张，`for image in images` 是新手最常见的性能坑 |
| 4 | **不要原地修改入参张量** | 上游节点可能复用同一张量；要改就先 `.clone()` |
| 5 | 算完恢复到原 `dtype` / `device` | 把 fp16 升成 fp32 会让下游显存翻倍 |
| 6 | 用 `mm.get_torch_device()` 取设备 | 硬编码 `cuda` 会在纯 CPU 环境崩 |
| 7 | 除零保护用 `.clamp(min=1e-8)` | HSV 的 delta、gamma 的 pow 都会踩 |
| 8 | 大图插值用 `torch.nn.functional.interpolate` | 别先转 numpy 再 PIL，会掉设备 |

> 规则 4 的现场演示在第 8 章的水印节点（必须先 `.clone()`）。

```python
            float(data.get("contrast", 1.0)),
            float(data.get("saturation", 1.0)),
            float(data.get("hue_shift", 0.0)),
            float(data.get("gamma", 1.0)),
        )

    @classmethod
    def fingerprint_inputs(cls, preset) -> str:

        path = folder_paths.get_full_path(PRESET_FOLDER, preset)
```

1. **Combo 的 `options` 在 `define_schema()` 时求值**。

3. **不要在 `execute` 里做昂贵 IO**。

## 8.1 合成算法（放 `pk_ops.py`）

```python
import numpy as np
import torch
from PIL import Image


def load_rgba(path: str) -> torch.Tensor:
    """读一张带 alpha 的图片 -> [H, W, 4] float32，值域 [0,1]。"""
    with Image.open(path) as img:
        arr = np.asarray(img.convert("RGBA"), dtype=np.float32) / 255.0
    return torch.from_numpy(arr)


def resize_rgba(rgba: torch.Tensor, target_w: int) -> torch.Tensor:
    """按目标宽度等比缩放 RGBA 图。"""
    h, w = rgba.shape[0], rgba.shape[1]
    if w <= 0 or target_w <= 0:
        return rgba
    new_h = max(1, round(h * target_w / w))
    # [H,W,4] -> [1,4,H,W]（PyTorch 的通道在第 2 维）
    x = rgba.movedim(-1, 0).unsqueeze(0)
    x = torch.nn.functional.interpolate(x, size=(new_h, target_w), mode="bicubic", align_corners=False)
    # 转回 [H',W',4]
    return x.squeeze(0).movedim(0, -1).clamp(0.0, 1.0)


def paste_rgba(base: torch.Tensor, rgba: torch.Tensor, x: int, y: int, opacity: float = 1.0) -> torch.Tensor:
    """把 rgba 叠到 base 上。base: [B,H,W,3|4]，rgba: [h,w,4]。
    返回新张量（内部 clone），不修改 base。"""
    B, H, W = base.shape[0], base.shape[1], base.shape[2]
    oh, ow = rgba.shape[0], rgba.shape[1]

    x0, y0 = max(0, x), max(0, y)
    x1, y1 = min(W, x + ow), min(H, y + oh)
    if x1 <= x0 or y1 <= y0:                # 完全在画布外
        return base

    sx0, sy0 = x0 - x, y0 - y
    src = rgba[sy0:sy0 + (y1 - y0), sx0:sx0 + (x1 - x0)]    # [h',w',4]

    alpha = src[..., 3:4] * opacity                          # [h',w',1]
    rgb = src[..., :3]                                       # [h',w',3]

    # ★ 关键：先 clone 再写，绝不能原地改入参（上游可能复用同一张量）
    out = base.clone()
    dst = out[:, y0:y1, x0:x1, :3]
    out[:, y0:y1, x0:x1, :3] = dst * (1.0 - alpha) + rgb * alpha
    return out


def anchor_xy(position: str, W: int, H: int, ow: int, oh: int, margin: int) -> tuple[int, int]:
    """九宫格锚点 -> 左上角坐标。"""
    table = {
        "top_left":     (margin, margin),
        "top_center":   ((W - ow) // 2, margin),
        "top_right":    (W - ow - margin, margin),

    }
```

## 9.1 `PK_TileWatermark`：lazy 输入 + 进度条 + 异步

```python
from comfy_api.latest import ComfyAPI, ComfyExtension, io

api = ComfyAPI()          # 单例，模块级创建即可（参考 comfy_extras/nodes_replacements.py）


class PK_TileWatermark(io.ComfyNode):
    """把水印平铺满整张图（防盗图常用）。"""

    @classmethod
    def define_schema(cls) -> io.Schema:
        return io.Schema(
            node_id="PK_TileWatermark",
            display_name="Poster Tile Watermark",
            category="posterkit/watermark",
            description="Tile a watermark across the whole image.",
            inputs=[
                io.Image.Input("image"),
                io.Combo.Input("watermark", options=list_watermarks() or ["(none)"]),
                io.Float.Input("scale", default=0.12, min=0.01, max=1.0, step=0.01),
                io.Float.Input("opacity", default=0.25, min=0.0, max=1.0, step=0.01),
                io.Int.Input("margin", default=24, min=0, max=1024, step=1,
                             lazy=True,                    # ★ 惰性求值
                             tooltip="间距；只有 mode==grid 时才需要求值"),
                io.Combo.Input("mode", options=["grid", "diagonal"], default="diagonal"),
            ],
            outputs=[io.Image.Output()],
        )

    @classmethod
    def check_lazy_status(cls, image, watermark, scale, opacity, margin, mode):
        """返回"还需要哪些输入"的列表。执行引擎会反复调用直到返回空列表。
        未求值的输入在这里是 None。"""
        needed = []
        if watermark is None:
            needed.append("watermark")
        if scale is None:
            needed.append("scale")
        if opacity is None:
            needed.append("opacity")
        if mode is None:
            needed.append("mode")
        # 只有 grid 模式才真正需要 margin
        if mode == "grid" and margin is None:
            needed.append("margin")
        return needed

    @classmethod
    async def execute(cls, image, watermark, scale, opacity, margin, mode) -> io.NodeOutput:
        if not watermark or watermark == "(none)":
            return io.NodeOutput(as_4d(image))

        batch = as_4d(image)
        rgba = load_rgba(folder_paths.get_full_path_or_raise(WATERMARK_FOLDER, watermark))
        rgba = resize_rgba(rgba, max(1, round(batch.shape[2] * scale)))
        rgba = rgba.to(device=batch.device, dtype=batch.dtype)

        out = batch.clone()
        H, W = out.shape[1], out.shape[2]
        ow, oh = rgba.shape[1], rgba.shape[0]

        # 生成所有落点
        if mode == "grid":
            step_x, step_y = ow + margin, oh + margin
            xs = list(range(0, W, max(1, step_x)))
            ys = list(range(0, H, max(1, step_y)))
        else:  # diagonal
            step_x, step_y = ow + max(8, ow // 2), oh + max(8, oh // 2)
            xs = list(range(0, W, max(1, step_x)))
            ys = list(range(0, H, max(1, step_y)))

        total = len(xs) * len(ys)
        done = 0
        for yi, y in enumerate(ys):
            for x in xs:
                yy = y + (x // max(1, step_x)) * (step_y // 2) if mode == "diagonal" else y
                out = paste_rgba(out, rgba, x, yy, opacity)
                done += 1
            # 进度条：value / max_value；node_id 省略时取当前执行上下文
            await api.execution.set_progress(done, total)

        return io.NodeOutput(out)
```

### lazy 机制要点

- `lazy=True` 的输入在 `check_lazy_status` 返回它之前**不会被求值**（上游节点不会执行）
- 执行引擎反复调用 `check_lazy_status`，直到返回空列表（`_io.py:2180`）
- 未求值的入参在 `check_lazy_status` 里是 `None`；`is_input_list=True` 时是 `(None,)`
- **典型用法**：`mode` 决定要不要算某个分支的参数；或者某个输入是昂贵的文件 IO

### 进度条要点

- V3：`await api.execution.set_progress(value, max_value, node_id=None, preview_image=None, ignore_size_limit=False)`
  - `node_id` 省略时自动取执行上下文（`comfy_api/latest/__init__.py:41`）
- V1：`pbar = comfy.utils.ProgressBar(total); pbar.update(i)`

### 异步要点

- `execute` 可以是 `async def`（`execution.py:301` 检测 `iscoroutinefunction`）
- 异步适合：网络请求、文件 IO、`await` 其他协程
- **不要在 async execute 里做长时间同步阻塞**，会卡住事件循环

# 第 12 章 自定义 HTTP 路由

## 12.1 基本写法

`routes.py`：

```python
import json
import os

from aiohttp import web
from server import PromptServer

import folder_paths
from .pk_paths import PRESET_FOLDER, WATERMARK_FOLDER


@PromptServer.instance.routes.get("/pk/presets")
async def list_presets_route(request):
    """GET /api/pk/presets -> {"presets": [...]}"""
    return web.json_response({"presets": folder_paths.get_filename_list(PRESET_FOLDER)})


@PromptServer.instance.routes.get("/pk/presets/{name}")
async def get_preset_route(request):
    name = request.match_info["name"]
    path = folder_paths.get_full_path(PRESET_FOLDER, name)
    if path is None or not os.path.isfile(path):
        return web.json_response({"error": "not found"}, status=404)
    return web.json_response(json.load(open(path, "r", encoding="utf-8")))


@PromptServer.instance.routes.post("/pk/presets/reload")
async def reload_presets_route(request):
    """清空缓存 + 让 folder_paths 重新扫描（懒导入避免循环依赖）。"""
    from .nodes import _CACHE                      # 第 7 章里定义的解析缓存
    _CACHE.clear()
    folder_paths.filename_list_cache.pop(PRESET_FOLDER, None)
    return web.json_response({"ok": True, "presets": folder_paths.get_filename_list(PRESET_FOLDER)})
```

在 `__init__.py` 里导入以触发注册：

```python
from . import routes   # noqa: F401  —— 必须导入，路由才会注册
```

## 12.2 路由前缀

`server.py:1306` 会把所有注册到 `PromptServer.instance.routes` 的非静态路由**再复制一份加 `/api` 前缀**：

```python
api_routes.route(route.method, "/api" + route.path)(route.handler, **route.kwargs)
```

所以 `/pk/presets` 和 `/api/pk/presets` **都能访问**。
给前端 `RemoteOptions` 用时建议写 `/api/...`（前端 dev server 只转发 `/api`）。

## 12.3 安全红线

按本仓库 `AGENTS.md`，**核心 ComfyUI 不得新增任何对外网络请求**（遥测/埋点/更新检查/远程配置一律禁止）。
自定义节点里要联网属于用户自己的选择，但要：

- 不在导入时联网（会拖慢启动、无网环境直接崩）
- 明确放在 `execute` 里，失败要有清晰报错
- 不静默上传用户数据

# 第 13 章 组装完整工作流（API JSON）

## 13.1 两种 JSON 的区别

| 格式 | 来源 | 能否直接 POST /prompt |
|---|---|---|
| **UI 工作流** | 前端「Save」 | ❌ 含 `nodes`/`links`/`groups`/`pos`，需要转换 |
| **API 工作流** | 前端「Save (API Format)」 | ✅ 直接提交 |

**API 格式**：

```json
{
  "4": {
    "class_type": "EmptyLatentImage",
    "inputs": { "width": 1024, "height": 1536, "batch_size": 1 }
  },
  "5": {
    "class_type": "KSampler",
    "inputs": {
      "seed": 123456789,
      "steps": 28,
      "cfg": 6.5,
      "sampler_name": "dpmpp_2m",
      "scheduler": "karras",
      "denoise": 1.0,
      "latent_image": ["4", 0]
    }
  }
}
```

- 顶层 key 是**节点 ID**（字符串，图内唯一即可，不要求连续、不要求数字）
- `class_type` = 节点的 `node_id`
- `inputs` 的值可以是：**字面量**（widget 值）或 **`[源节点ID, 输出槽下标]`**（连线）
- 节点 ID 是字符串，只要图内唯一即可
- 没有 `links` 数组，连线直接内联

# 第 14 章 Python 客户端调用

## 14.1 完整脚本 `run_poster.py`

```python
#!/usr/bin/env python3
"""提交工作流到 ComfyUI 并取回图片。"""
import json
import sys
import time
import urllib.parse
import urllib.request
import uuid
import websocket   # pip install websocket-client

SERVER = "127.0.0.1:8188"


def http_json(method, path, payload=None):
    data = json.dumps(payload).encode() if payload is not None else None
    req = urllib.request.Request(
        f"http://{SERVER}{path}",
        data=data,
        method=method,
        headers={"Content-Type": "application/json"},
    )
    with urllib.request.urlopen(req) as r:
        return json.loads(r.read())


def queue_prompt(prompt_graph, client_id):
    p = {"prompt": prompt_graph, "client_id": client_id}
    return http_json("POST", "/prompt", p)


def wait_for_images(prompt_id, client_id, timeout=600):
    """连 WebSocket，等 executing 事件里 node 变 None = 本轮结束。"""
    ws = websocket.WebSocket()
    ws.connect(f"ws://{SERVER}/ws?clientId={client_id}")
    deadline = time.time() + timeout
    try:
        while time.time() < deadline:
            msg = json.loads(ws.recv())
            if msg.get("type") == "executing":
                data = msg["data"]
                if data.get("prompt_id") == prompt_id and data.get("node") is None:
                    break
            if msg.get("type") == "execution_error":
                raise RuntimeError(json.dumps(msg["data"], ensure_ascii=False))
    finally:
        ws.close()


def fetch_outputs(prompt_id, out_dir="."):
    """从 /history 拿文件名，再用 /view 下载。"""
    hist = http_json("GET", f"/history/{prompt_id}")
    entry = hist[prompt_id]
    saved = []
    for node_id, node_out in entry.get("outputs", {}).items():
        for img in node_out.get("images", []):
            params = urllib.parse.urlencode({
                "filename": img["filename"],
                "subfolder": img.get("subfolder", ""),
                "type": img.get("type", "output"),
            })
            url = f"http://{SERVER}/view?{params}"
            dest = f"{out_dir}/{prompt_id}_{node_id}_{img['filename']}"
            urllib.request.urlretrieve(url, dest)
            saved.append(dest)
    return saved


def main():
    graph = json.load(open(sys.argv[1], "r", encoding="utf-8"))

    # 每次跑换一个 seed（示例：把节点 5 的 seed 换掉）
    graph["5"]["inputs"]["seed"] = int(uuid.uuid4().int % (2 ** 32))

    client_id = str(uuid.uuid4())
    resp = queue_prompt(graph, client_id)
    if "error" in resp:
        print("提交失败:", json.dumps(resp, ensure_ascii=False, indent=2))
        sys.exit(1)

    prompt_id = resp["prompt_id"]
    print("queued:", prompt_id)
    wait_for_images(prompt_id, client_id)
    for p in fetch_outputs(prompt_id):
        print("saved:", p)


if __name__ == "__main__":
    main()
```

运行：

```bash
pip install websocket-client
python run_poster.py workflows/poster_api.json
```
