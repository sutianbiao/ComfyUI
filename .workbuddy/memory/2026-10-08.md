## 追加：《MiniMax H3 进阶实操手册》（多帧锚定 + Fun ControlNet）

用户要「多帧锚定 + Fun ControlNet 视频 inpainting 实操手册」→ `docs/MINIMAX_H3_ADVANCED_GUIDE.md`。

### 底层机制（读源码才确认）
- H3 把一切 pack 成一条序列：`[text | ref blocks | 关键帧 cond 行 | 目标音频 | 目标视频]`（`PackedLayout`，model.py:353）
- `seg_t` 里 `cond/ref_img` 跑 `max(t_v, VISUAL_COND_TIMESTEP=0.999)`、`cond_audio/ref_audio` 跑 `max(t_a, AUDIO_COND_TIMESTEP=1.0)` → **条件行永不去噪，每步重新注入**。锚定是"让模型每步看见这张图"，不是时序插值
- `img_update`/`audio_update` 布尔掩码区分"目标行 vs 条件行"

### 多帧锚定硬规则
- latent 必须同时满足 4 条件（nested / 2 张量 / 5 维 / 通道 24）
- 片段长度**向下**裁到 17k+5：<5 帧只取首帧；上限 362
- `frame_idx + guide_frames` 必须落在 `frame_count` 内；负数从结尾数
- **音轨锚点额外限制**：`max_rt = floor(audio_T - 5/3*idx)`，124 帧时 idx 最大约 123（画面可到最后一帧，音轨不行）
- 关键帧时间坐标 `cond_t = cursor + 5/3 * resolved_frame_index`；ref2va 下 cursor 已先累加所有 ref 的时间跨度
- 序列行数账本（1344×768,124 帧）：frame_rows=1008, latent_t=37, video=37296 行, audio_t=207, audio=414 行 → ~37.7k+文本
- **接 AddGuide 的图对文本编码器不可见**，要同时接 `ref_images` 才能用 `<Picture N>` 指代

### Fun ControlNet
- `control_in_dim=49` = 24(控制视频 latent) + 1(可见度) + 24(遮罩后的源 latent)，patchify 后 196
- `init_stream` 只在 `img_update` 行填控制；`step` 返回 after_proj 残差；`skip[audio_pos]=0`（音频不受控）
- adaLN 宽度不匹配直接抛 RuntimeError（curve basis vs full）→ **pruned 基座必须配 pruned 控制网**
- injection_layers：metadata `control_blocks_places` 优先，否则 `range(0,50,50//num_blocks)`（v1=5 块→0,10,20,30,40；v2=10 块→每 5 层）
- 控制视频长度不匹配：`_fit_frames` 用 `arange().clamp(max=N-1)` → 长的截前帧、短的定格末帧；bilinear+center crop
- **inpainting 有两条独立机制**：A=FunCN 的 mask+source_video（条件注入）；B=`SetLatentNoiseMask`（`scale_latent_inpaint` 按 0.999 注入噪声 pin 住保留行）。B 不需要控制网。官方模板走 A
- `inpaint_post_norm`（v2 ckpt metadata）→ 洞填 ImageNet 均值灰而非黑（VAE 把中灰归一化到 0）
- FunCN 支持 fl2va 和 ref2va 两种 transformer；Canny/Depth/HED/MLSD/Pose 一个 checkpoint 通吃

### 官方模板差异（易混）
- Multiframe / FunCN 模板用 `minimax_h3_video_vae_int8_convrot.safetensors`，I2V 蓝图用 `..._fp16.safetensors` → **别混**
- Turbo LoRA 分任务：`fl2v_turbo_8step`（I2V）vs `ref2v_turbo_4step_v0.1`（Multiframe/FunCN）
- FunCN 文件名 `minimax_h3_fun_controlnet_union_pruned_int8_convrot.safetensors` → `models/model_patches/`
- Pose 示例另需 `sdpose_wholebody_fp16.safetensors`(checkpoints) + `rt_detr_v4-x-hgnet_fp16.safetensors`(diffusion_models)
- 官方子页面 URL 规律：`minimax-h3-{native,multiframe,fun-controlnet,prompt-guide,fastvideo}`（我猜的 multiframe-reference / native-workflows 是 404）

## 追加：《MiniMax H3 节点完全参考手册》（六列参数表版）

### 结构（三层圈层划分，这是本手册的组织骨架）
- **A 层 H3 专属 6 个**：`EmptyMiniMaxH3LatentAV`、`MiniMaxH3ImageToVideo`、`MiniMaxH3AddGuide`、`MiniMaxH3ReferenceToVideo`、`MiniMaxH3SigmaShift`(显示名 ModelSamplingMiniMaxH3)、`MiniMaxH3FunControlNetApply`
- **B 层 为 H3 开专用分支的通用节点 3 个**：`LTXVConcatAVLatent`、`LTXVSeparateAVLatent`（描述里明写 "e.g. LTXV or MiniMax H3"）、`BlockSparseAttention`（`sink_conditioning` tooltip 只讲 H3）
- **C 层 配套通用 ~20 个**：加载/采样/解码/输出/遮罩

### 本次新确认的源码级细节（前面两份文档没记的）
- **`MiniMaxH3SigmaShift` 的 ID 与显示名不一致** —— ID 是 SigmaShift，界面显示 ModelSamplingMiniMaxH3，别名 `sigma shift`/`minimax shift`。API 用 ID，UI 搜显示名
- **首尾帧缩放策略不同**：`first_frame` 用 `crop="disabled"`（硬拉伸，几何锚点）；`last_frame` 用 `crop="center"`（保比例中心裁切，跟随者）。且只取 `[:1]`
- **AddGuide 帧数向下裁 vs Empty latent 向上吸附** —— 方向相反，100 帧片段实际钉 90 帧
- **Autogrow 的 API 键名规则**：`{input_id}.{prefix}{i}`，即 `ref_images.ref_image_1`、`ref_video_audios.ref_video_audio_1`。依据 `tests-unit/execution_test/dynamic_inputs_test.py:22`（`{"rows.item0": 0.5}` → execute 收到 `{"item0": 0.5}`）
- **`ref_image_size`**：`match` 按生成面积 `sqrt(W*H/(w*h))` 只缩不放；`max` 短边 2048（`REF_IMAGE_SHORT_EDGE`）。参考 token 贯穿每个采样步，所以 max 慢数倍
- **参考视频走 `adapt_canvas`**（768 短边 + 768*1344 面积上限 + 逐轴 32 取整），与 ref_image_size 无关，是另一套逻辑
- **Qwen 以 2 fps 看参考视频**（`range(0, N, FPS//2)` = 每 12 帧取 1，带 timestamps），但 DiT latent 用完整帧率
- **`ref_item` 顺序**：图 → (视频音轨标签, 视频) → 独立音频。编号是类型分组后的 1-based，不是连线顺序
- **`ref_video_audio_N` 必须和 `ref_video_N` 同号**（源码用 `name.rsplit("_",1)[-1]` 配对）
- **FunCN 早退条件**：`strength == 0 or (control_video is None and mask is None)` → 直接返回原 model
- **`BlockSparseAttention` 的 VSA 忽略 `extra_tokens`**；保护区间 = video 段之前全部内容按 BLOCK_SIZE=64 向上取整
- **`LTXVConcatAVLatent.fit_audio`**：音频短于画面时补零且**不加噪声遮罩**（尾部交给模型自由生成）
- `MAX_RESOLUTION = 16384`（nodes.py:56）
