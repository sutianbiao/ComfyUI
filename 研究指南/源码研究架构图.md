## 详细模块分析

### 1. 启动流程 (main.py)
```
main.py
├── 环境变量设置
├── 日志系统初始化
├── 路径配置 (apply_custom_paths)
├── 自定义节点预启动 (execute_prestartup_script)
├── 设备配置 (CUDA/GPU设置)
├── 核心模块导入
└── 服务启动 (start_comfyui)
```

### 2. Web服务器 (server.py)
```
PromptServer
├── 路由管理 (routes)
├── WebSocket处理
├── 文件上传下载
├── 用户管理 (UserManager)
├── 模型管理 (ModelFileManager)
└── 自定义节点管理 (CustomNodeManager)
```

### 3. 执行引擎 (execution.py)
```
PromptExecutor
├── 工作流执行
├── 缓存管理
├── 进度跟踪
├── 错误处理
└── 异步执行
```

### 4. 节点系统 (nodes.py)
```
节点管理
├── 内置节点注册
├── 自定义节点加载
├── 节点依赖解析
├── 节点执行调度
└── 节点信息管理
```

### 5. AI模型处理 (comfy/)
```
comfy/
├── model_management.py  # 模型管理
├── samplers.py         # 采样器
├── sd.py              # Stable Diffusion
├── lora.py            # LoRA处理
├── controlnet.py      # ControlNet
└── utils.py           # 工具函数
```

## 数据流向

```
用户请求 → Web服务器 → 执行引擎 → 节点系统 → AI模型 → 结果返回
    ↓           ↓          ↓         ↓        ↓
  HTTP/WS   PromptServer  PromptExecutor  Nodes  Comfy模块
```

## 关键接口

### 1. 节点接口
- `io.ComfyNode` - 节点基类
- `io.Schema` - 节点定义
- `io.NodeOutput` - 节点输出

### 2. API接口
- REST API - HTTP接口
- WebSocket - 实时通信
- 内部API - 系统内部接口

### 3. 模型接口
- `comfy.model_management` - 模型管理
- `comfy.samplers` - 采样器接口
- `comfy.utils` - 工具函数
