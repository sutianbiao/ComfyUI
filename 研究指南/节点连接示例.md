# ComfyUI 节点连接示例

## 🔗 MyBasicNode 连接指南

### 输出类型
- **类型**: `FLOAT` (浮点数)
- **名称**: `result`

### 可以连接的节点

#### 1. 内置节点连接
```
MyBasicNode (result: FLOAT) 
    ↓
┌─────────────────────────┐
│ 数学运算节点 (Math)      │ ← 接受 FLOAT 输入
│ - 加法 (Add)            │
│ - 减法 (Subtract)       │
│ - 乘法 (Multiply)       │
│ - 除法 (Divide)         │
└─────────────────────────┘
```

#### 2. 自定义节点连接
```
MyBasicNode (result: FLOAT)
    ↓
┌─────────────────────────┐
│ MathOperationNode       │ ← 接受 FLOAT 输入
│ - a: FLOAT              │
│ - b: FLOAT              │
│ - operation: STRING     │
└─────────────────────────┘
```

#### 3. 条件判断连接
```
MyBasicNode (result: FLOAT)
    ↓
┌─────────────────────────┐
│ ConditionalNode         │ ← 接受 FLOAT 输入
│ - condition: BOOLEAN    │
│ - true_value: FLOAT     │
│ - false_value: FLOAT    │
└─────────────────────────┘
```

#### 4. 链式连接
```
MyBasicNode (result: FLOAT)
    ↓
MyBasicNode (input_number: FLOAT)
    ↓
MathOperationNode (a: FLOAT)
```

## 🎯 实际使用示例

### 示例1: 简单数学运算
```
输入: 5.0
乘数: 2.0
结果: 10.0
    ↓
连接到: MathOperationNode (加法)
```

### 示例2: 条件判断
```
输入: 8.0
乘数: 1.5
结果: 12.0
    ↓
连接到: ConditionalNode
- 条件: result > 10
- 真值: 100.0
- 假值: 0.0
```

### 示例3: 链式计算
```
MyBasicNode1: 5.0 × 2.0 = 10.0
    ↓
MyBasicNode2: 10.0 × 3.0 = 30.0
    ↓
MathOperationNode: 30.0 + 5.0 = 35.0
```

## 🔧 在ComfyUI中的操作步骤

1. **拖拽节点**
   - 拖拽 `MyBasicNode` 到工作区
   - 拖拽目标节点到工作区

2. **连接节点**
   - 点击 `MyBasicNode` 的 `result` 输出点
   - 拖拽到目标节点的 `FLOAT` 输入点

3. **设置参数**
   - 设置 `input_number` 和 `multiplier`
   - 设置目标节点的参数

4. **执行工作流**
   - 点击 "Queue Prompt" 执行
   - 查看结果

## 💡 连接技巧

### 1. 类型匹配
- 确保输出类型与输入类型匹配
- `FLOAT` 可以连接到 `FLOAT` 输入
- 不能直接连接到 `IMAGE` 或 `STRING` 输入

### 2. 数据流方向
- 数据从输出点流向输入点
- 一个输出可以连接到多个输入
- 一个输入只能接受一个输出

### 3. 调试技巧
- 使用 `print()` 查看中间结果
- 检查节点参数设置
- 验证数据类型匹配

## 🎨 创意连接示例

### 数学计算链
```
输入数字 → MyBasicNode → MathOperationNode → ConditionalNode → 输出
   5.0   →    10.0    →       15.0        →      100.0     → 显示
```

### 条件处理链
```
MyBasicNode → ConditionalNode → MyBasicNode → 最终结果
   8.0     →      100.0      →    200.0    →   200.0
```

这样你就可以灵活地使用你的自定义节点了！🚀
