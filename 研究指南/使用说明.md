## 🚀 快速开始

### 1. 进入研究指南文件夹
```bash
cd 研究指南
```

### 2. 运行项目分析
```bash
# 生成完整的项目分析报告
python3 源码分析工具.py --output 项目分析报告.md

# 查看分析结果
cat 项目分析报告.md
```

### 3. 使用学习辅助工具
```bash
# 查看学习检查清单
python3 学习辅助工具.py --checklist

# 查找函数使用情况
python3 学习辅助工具.py --find-usage "PromptExecutor"

# 查找类继承层次
python3 学习辅助工具.py --find-class "ComfyNode"

# 跟踪执行流程
python3 学习辅助工具.py --trace-flow "start_comfyui"

# 生成学习笔记模板
python3 学习辅助工具.py --generate-notes "节点开发"
```

## 🛠️ 工具详细说明

### 源码分析工具 (源码分析工具.py)

**功能**: 分析ComfyUI项目的整体结构，生成详细的分析报告

**使用方法**:
```bash
# 基本用法
python3 源码分析工具.py

# 指定输出文件
python3 源码分析工具.py --output 我的分析报告.md

# 指定项目根目录（如果需要）
python3 源码分析工具.py --project-root ../../
```

**输出内容**:
- 项目概览统计
- 核心文件分析
- 关键模块分类
- 依赖关系分析
- API端点列表
- 学习路线图

### 学习辅助工具 (学习辅助工具.py)

**功能**: 提供各种学习辅助功能，帮助快速理解源码

**主要功能**:

1. **查找函数使用情况**
```bash
python3 学习辅助工具.py --find-usage "函数名"
```

2. **查找类继承层次**
```bash
python3 学习辅助工具.py --find-class "类名"
```

3. **跟踪执行流程**
```bash
python3 学习辅助工具.py --trace-flow "函数名"
```

4. **查找模块导入链**
```bash
python3 学习辅助工具.py --find-imports "模块名"
```

5. **生成学习笔记模板**
```bash
python3 学习辅助工具.py --generate-notes "主题"
```

6. **生成学习检查清单**
```bash
python3 学习辅助工具.py --checklist
```

## 🔧 常见问题

### Q: 工具提示找不到文件？
A: 确保你在 `研究指南` 文件夹中运行工具，或者使用 `--project-root` 参数指定正确的项目根目录。

### Q: 如何修改项目根目录？
A: 使用 `--project-root` 参数，例如：
```bash
python3 源码分析工具.py --project-root /path/to/ComfyUI
```

### Q: 输出文件保存在哪里？
A: 默认保存在 `研究指南` 文件夹中，除非你指定了绝对路径。

### Q: 如何查看工具的帮助信息？
A: 使用 `--help` 参数：
```bash
python3 源码分析工具.py --help
python3 学习辅助工具.py --help
```
