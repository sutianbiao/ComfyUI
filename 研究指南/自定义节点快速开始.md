## 📋 可用的自定义节点

### 1. MyBasicNode (我的基础节点)
- **功能**: 将输入数字乘以指定倍数
- **输入**: input_number (数字), multiplier (乘数)
- **输出**: result (计算结果)

### 2. ImageAdjustNode (图像调整)
- **功能**: 调整图像的亮度、对比度、饱和度
- **输入**: image (图像), brightness (亮度), contrast (对比度), saturation (饱和度)
- **输出**: adjusted_image (调整后的图像)

### 3. TextProcessorNode (文本处理)
- **功能**: 处理文本输入
- **输入**: text (文本), operation (操作类型)
- **输出**: processed_text (处理后的文本), text_length (文本长度)

### 4. ConditionalNode (条件判断)
- **功能**: 根据条件选择不同的输出
- **输入**: condition (条件), true_value (真值), false_value (假值)
- **输出**: output (选择的输出)

### 5. MathOperationNode (数学运算)
- **功能**: 执行基本的数学运算
- **输入**: a (第一个数字), b (第二个数字), operation (运算类型)
- **输出**: result (运算结果)

## 🔧 开发新节点

### 1. 创建新节点类

在 `my_nodes.py` 中添加新的节点类：

```python
class MyNewNode:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "input_param": ("FLOAT", {"default": 0.0}),
            }
        }
    
    RETURN_TYPES = ("FLOAT",)
    RETURN_NAMES = ("output",)
    FUNCTION = "my_function"
    CATEGORY = "MyCustomNodes"
    
    def my_function(self, input_param):
        # 你的处理逻辑
        result = input_param * 2
        return (result,)
```

### 2. 注册节点

在文件末尾添加节点映射：

```python
NODE_CLASS_MAPPINGS.update({
    "MyNewNode": MyNewNode
})

NODE_DISPLAY_NAME_MAPPINGS.update({
    "MyNewNode": "我的新节点"
})
```

### 3. 测试节点

在 `test_simple.py` 中添加测试：

```python
def test_new_node():
    node = MyNewNode()
    result = node.my_function(5.0)
    print(f"测试结果: {result[0]}")
```
