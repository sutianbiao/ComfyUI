# ComfyUI 快速调试指南

## 🚀 立即开始调试

### 1. 最简单的调试方法

#### 使用pdb断点调试
```python

# 或者使用Python 3.7+的简化方式：
breakpoint()
```

```bash

python3 main.py --listen 127.0.0.1 --port 8188
```

### 2. VS Code调试

#### 快速设置
1. 打开VS Code
2. 打开ComfyUI项目文件夹
3. 按 `F5` 或点击"运行和调试"
4. 选择"ComfyUI Debug (基础调试)"
5. 在代码中设置断点（点击行号左侧）
6. 开始调试

#### 调试配置
VS Code配置文件已创建在 `.vscode/launch.json`，包含5种调试配置：
- **基础调试**: 简单启动调试
- **完整功能**: 包含所有功能
- **自定义节点**: 调试自定义节点
- **性能分析**: CPU模式调试
- **从断点开始**: 立即进入调试模式

#### 5.2 性能调试
```python
# 添加性能监控
import time
import functools

def timing_decorator(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        end_time = time.time()
        print(f"函数 {func.__name__} 执行时间: {end_time - start_time:.4f}秒")
        return result
    return wrapper

@timing_decorator
def your_function():
    # 你的代码
    pass
```

### 7. 调试最佳实践

#### 7.1 分层调试
- **系统层**: 调试启动、配置、环境
- **网络层**: 调试HTTP请求、WebSocket
- **业务层**: 调试工作流、节点执行
- **数据层**: 调试模型加载、缓存

#### 7.2 渐进式调试
1. **先调试简单功能**: 从基础功能开始
2. **逐步增加复杂度**: 逐步调试复杂功能
3. **隔离问题**: 将问题隔离到最小范围
4. **验证修复**: 确保修复不会引入新问题

### 9. 高级调试技巧

#### 9.1 条件断点
```python
# 只在特定条件下触发断点
if some_condition:
    import pdb; pdb.set_trace()
```

#### 9.2 异常断点
```python
# 在异常时自动进入调试器
import pdb
import sys

def excepthook(type, value, traceback):
    pdb.post_mortem(traceback)

sys.excepthook = excepthook
```

#### 9.3 远程调试
