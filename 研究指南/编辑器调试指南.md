# ComfyUI 编辑器调试指南

## 🎯 在编辑器中直接调试ComfyUI

### 1. VS Code 调试（最推荐）

#### 1.1 快速开始调试
1. **打开VS Code**
2. **打开ComfyUI项目文件夹** (`/mnt/fde045dc-60c2-4db6-b37d-928569fbe4c0/work/workspace/github_2025/ComfyUI`)
3. **按 `F5` 或点击左侧"运行和调试"图标**
4. **选择"ComfyUI Debug (基础调试)"**
5. **在代码中点击行号左侧设置断点**（红色圆点）
6. **开始调试**

#### 1.2 调试配置说明
我已经为你创建了5种调试配置：

| 配置名称 | 用途 | 参数 |
|---------|------|------|
| **ComfyUI Debug (基础调试)** | 简单启动调试 | `--listen 127.0.0.1 --port 8188 --verbose` |
| **ComfyUI Debug (完整功能)** | 包含所有功能 | `--listen 0.0.0.0 --port 8188 --verbose --output-directory ./output` |
| **ComfyUI Debug (自定义节点)** | 调试自定义节点 | `--listen 127.0.0.1 --port 8188 --verbose --enable-cors-header *` |
| **ComfyUI Debug (性能分析)** | CPU模式调试 | `--listen 127.0.0.1 --port 8188 --verbose --cpu --disable-cuda-malloc` |
| **ComfyUI Debug (从断点开始)** | 立即进入调试模式 | `--listen 127.0.0.1 --port 8188 --verbose` |

#### 1.3 调试界面说明
- **变量窗口**: 查看当前作用域的所有变量

### 3. 调试步骤详解

#### 3.1 启动调试
1. **打开VS Code**
2. **打开main.py文件**
3. **在第530行点击设置断点**（🔍 调试断点1）
4. **按F5开始调试**
5. **选择"ComfyUI Debug (基础调试)"**

#### 3.2 调试过程
1. **程序会在断点处暂停**
2. **查看变量窗口**，观察 `asyncio_loop` 参数
3. **按F10单步执行**，观察每行代码的执行
4. **在监视窗口添加表达式**，如 `args.listen`、`args.port`
5. **按F5继续执行**到下一个断点

#### 3.3 调试技巧
- **F10**: 单步执行（不进入函数）
- **F11**: 单步执行（进入函数内部）
- **Shift+F11**: 跳出当前函数
- **F5**: 继续执行到下一个断点
- **Shift+F5**: 停止调试

### 5. 高级调试技巧

#### 5.1 条件断点
```python
# 只在特定条件下触发断点
if some_condition:
    import pdb; pdb.set_trace()
```

#### 5.2 日志断点
```python
# 在断点处执行代码而不停止
# 在VS Code中：右键断点 → 编辑断点 → 添加日志消息
print(f"调试信息: 变量值 = {variable}")
```

#### 5.3 异常断点
1. **在VS Code中**: 断点窗口 → 添加异常断点
2. **选择异常类型**: 如 `ZeroDivisionError`、`AttributeError`
3. **当异常发生时自动暂停**
