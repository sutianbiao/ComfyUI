## 🔄 详细数据流转换

### 1. 输入阶段
```
文本: "A cat playing with a ball"
图像: first_frame.jpg (可选)
参数: steps=20, cfg=7.5, seed=42
```

### 2. 条件编码
```
文本编码: [1, 77, 768] → [1, 77, 1280]
图像编码: [1, 3, 512, 512] → [1, 4, 64, 64]
条件组合: 正负条件 + 图像条件
```

### 3. 噪声生成
```
噪声形状: [1, 4, 25, 64, 64]
- 1: 批次大小
- 4: 潜在通道数
- 25: 视频帧数
- 64x64: 潜在空间分辨率
```

### 4. 扩散采样
```
UNet处理: 3D卷积 + 注意力机制
去噪过程: 20步迭代去噪
输出: [1, 4, 25, 64, 64] 去噪后潜在表示
```

### 5. VAE解码
```
输入: [1, 4, 25, 64, 64] 潜在表示
解码: [1, 3, 25, 512, 512] RGB视频
变换: [25, 3, 512, 512] 独立帧序列
```

### 6. 最终输出
```
视频帧: 25帧 512x512 RGB图像
帧率: 6 FPS
时长: 4.2秒
格式: MP4视频文件
```

## 🎯 关键节点说明

### LoadImage节点
- **功能**: 加载首帧图像（图像到视频）
- **输出**: [1, 3, H, W] RGB图像

### CLIPTextEncode节点
- **功能**: 文本条件编码
- **输出**: [1, 77, 1280] 条件向量

### VideoVAEEncode节点
- **功能**: 图像编码到潜在空间
- **输出**: [1, 4, H/8, W/8] 潜在表示

### EmptyLatentImage节点
- **功能**: 创建空潜在张量
- **输出**: [1, 4, T, H/8, W/8] 噪声张量

### KSampler节点
- **功能**: 扩散采样去噪
- **输出**: [1, 4, T, H/8, W/8] 去噪潜在表示

### VideoVAEDecode节点
- **功能**: 潜在空间解码为视频帧
- **输出**: [T, 3, H, W] 视频帧序列

### SaveImage节点
- **功能**: 保存视频帧为图像序列
- **输出**: 视频帧文件

## ⚡ 性能优化点

### 内存优化
```
分块处理: 长视频分块解码
时序重叠: 确保帧间连续性
GPU管理: 动态加载/卸载模型
```

### 质量优化
```
CFG调节: 7.5-12.0 控制条件强度
步数调整: 20-50步平衡质量与速度
采样器选择: Euler, DPM++等
```

### 速度优化
```
模型量化: 减少内存占用
并行处理: 多帧并行解码
缓存机制: 复用计算结果
```
